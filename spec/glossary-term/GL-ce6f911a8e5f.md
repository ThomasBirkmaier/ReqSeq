Datei oder Dokument, das festhält, wie eine Prüfung verlaufen ist, zum Beispiel eine Ergebnisdatei im Standardformat, ein Protokoll oder ein ausführlicher Bericht. Wo Belege liegen, legt die Organisation fest. Das Tool verwaltet Belege nicht; ein Nachweis verweist auf seinen Beleg. Bei automatischen Tests kann die Ergebnisdatei zugleich der Nachweis sein.

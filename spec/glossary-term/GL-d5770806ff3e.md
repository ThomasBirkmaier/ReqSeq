Angabe, die per ID auf ein Element zeigt: im Text oder in einer Markdown-Property eines Elements ([SR-127](reqseq:40ba988e-5199-44e9-a141-2804ea8ab350?version=n2:81bc991c71c9d81c)), dann mit Fassung, oder außerhalb des Tools, zum Beispiel in einem Test oder Nachweis. Eine Verbindung, die das Metamodell als Beziehungsart oder als Property mit Wertart Beziehung führt, ist eine Beziehung.

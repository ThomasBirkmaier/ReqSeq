Die grafische Oberfläche des [Tools](reqseq:6ad4f973-fdb9-461f-8dc4-b73619ba1dac?version=n2:2427cdd2079ee312), die die [Kommandozeile](reqseq:f5c404b5-7886-4c69-af41-5ecc43b71f52?version=n2:2556c6eb1781011b) mit `reqseq ui` als Server auf dem eigenen Rechner startet und die im Browser oder in der [Desktop-Hülle](reqseq:8cde6c0b-d69c-4972-b892-af0dbfa92a09?version=n2:4a161bba37dcff33) bedient wird ([D-083](reqseq:3fcc9c21-164a-4fa1-9d69-2ff8e055c094?version=n2:ab1a775d09c8134c)). Sie ist kein Zugang; Zugänge sind Kommandozeile, API und MCP-Server. Nicht der [HTML-Export](reqseq:7f240c30-80c6-476d-bc9c-0215a0fef867?version=n2:7e08d73bbf3cc65a), der ebenfalls im Browser gelesen wird.

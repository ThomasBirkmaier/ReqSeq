ID aus einer anderen Quelle, zum Beispiel von einem Kunden oder aus einem anderen Werkzeug, in einer eigenen Property mit der Bedeutung Kennung ([D-017](reqseq:6adc4fbb-fe6a-4dfa-b9b6-8ccf0e589cf2?version=n2:9c1373bcb7c5100f)). Eine Kennung ist je Typ eindeutig. Das Tool findet ein Element auch über seine Kennung und zeigt sie neben der Kurz-ID.

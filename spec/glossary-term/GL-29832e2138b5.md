Ein Element wird abgelöst, indem sein Status ungültig wird; optional zeigt ein Nachfolger mit Supersedes auf das abgelöste Element ([D-045](reqseq:6adc6923-8957-4ae9-8e6c-dc5cd1d097c8?version=n2:04e934b66316908b)). Das Tool löscht keine Elemente. Für Ablösen heißt es nicht „ersetzen“: Ersetzen gibt es nur zwischen einer Variante und dem Kern.

Ordner, den die Arbeitsbereichs-Datei mit einem Namen führt und in dem Elemente oder das Metamodell liegen; das Haupt-Repository ist der Ordner mit der Arbeitsbereichs-Datei. Meist ist ein Repository ein eigenes Git-Repository; es kann auch ein Unterordner eines Git-Repositories sein, wie die Spec des Tools, oder ohne Git stehen. Ohne Git hat eine Fassung kein Datum, und es lässt sich keine Baseline anlegen ([SR-050](reqseq:6adc6c99-2467-4946-b797-59d3c80b7a8c?version=n2:6d2a5b63871f3598) AK7); in einem flachen Klon fehlen das Datum und die Kriterienschlüssel älterer Fassungen ([SR-031](reqseq:6adc6c43-5d42-4c01-8c55-f332cc90a529?version=n2:5bd00d7b96750aef) AK11). Rechte gibt es nur je Git-Repository ([D-016](reqseq:6adc4fba-93c0-402a-817f-2b480d68a0f7?version=n2:e42ff7f25de20c08)); Repositories im selben Git-Repository trennen kein Need-to-know.

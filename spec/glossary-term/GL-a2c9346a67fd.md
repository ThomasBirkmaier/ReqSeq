In der App: die Stelle, an der eine Angabe eines geöffneten Elements steht, zum Beispiel Titel, Status unter dem Titel ([SR-243](reqseq:c5145675-e32e-4a6a-94cb-514a03896ace?version=n2:aace6af7fe0c2710) AK2), Kurz-ID, Text, eine Property-Box oder eine Gruppe von Beziehungen ([SR-128](reqseq:a7cbad8f-9c67-4b20-b61b-409101e9bfab?version=n2:7cc1b134f8291c92) AK1, [SR-155](reqseq:bd19f379-6b5b-4eca-a60a-66b31b5c1ec2?version=n2:819cb1f08c0d7fd7) AK1).

In der Suche: ein Teil der Elemente, auf den sich eine Suche beschränken lässt: Titel, Text, IDs, alle Properties oder eine einzelne Property ([SR-216](reqseq:de0a3aaf-ac81-4b33-84dd-b63b43b3ad96?version=n2:22ba985d2f2c4daf)).

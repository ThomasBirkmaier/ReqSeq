title: Importfassung
area: fachlich
---

Fassung, die die zuletzt importierte Lieferung für ein Element ergibt. Nur der Import schreibt sie, und sie zählt nicht zur Fassung. Weicht die Fassung später von ihr ab, wurde das Element seit dem Import geändert.

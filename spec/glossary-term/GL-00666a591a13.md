title: Importfassung
area: fachlich
---

Fassung eines Elements direkt nach seinem letzten Import. Nur der Import schreibt sie, und sie zählt nicht zur Fassung. Weicht die Fassung später von ihr ab, wurde das Element seit dem Import geändert.

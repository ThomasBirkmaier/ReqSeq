title: Liste von Elementen

english-term: list

Eine Ausgabe von Elementen mit einer Zeile je Element, zum Beispiel die Liste aller Elemente, eine gefilterte Liste oder die Liste der Suchtreffer. Im [HTML-Export](reqseq:7f240c30-80c6-476d-bc9c-0215a0fef867?version=n2:7e08d73bbf3cc65a): die Liste der Elemente eines Typs auf einer eigenen Seite ([SR-233](reqseq:74bc69b0-f7d1-4ad2-8d2f-ae9a561cde2f?version=n2:86ca3045d5c06ecc)).

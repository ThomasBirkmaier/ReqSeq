title: "Von außen geänderte Dateien übernehmen"
akzeptanzkriterien:
  - "Gegeben eine Element-Datei wird mit einem anderen Editor geändert, wenn sie gespeichert wird, dann zeigt das Tool den neuen Inhalt nach höchstens 2 Sekunden."
  - "Gegeben ein Pull ändert 1.000 Dateien, wenn er abgeschlossen ist, dann sind Suche, Beziehungen und Status nach höchstens 10 Sekunden aktuell."
  - "Gegeben eine Element-Datei wird außerhalb des Tools gelöscht, wenn das Tool die Änderung bemerkt, dann behandelt es Beziehungen auf das Element wie ein fehlendes Ziel (D-045)."

Wenn sich eine Datei im Arbeitsbereich außerhalb des Tools ändert, muss das Tool den neuen Inhalt ohne Neustart übernehmen.

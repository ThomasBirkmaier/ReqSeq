title: "Wiederholten Import abgleichen"
akzeptanzkriterien:
  - "Gegeben eine neue Lieferung derselben Quelle, wenn sie importiert wird, dann zeigt das Tool vorher neue, geänderte und weggefallene Requirements getrennt an."
  - "Gegeben ein Requirement mit gleichem IDENTIFIER, wenn es importiert wird, dann aktualisiert das Tool das vorhandene Element und legt kein zweites an."
  - "Gegeben ein weggefallenes Requirement, wenn importiert wird, dann kennzeichnet das Tool es nur und ändert weder Status noch Datei sonst."
  - "Gegeben ein importiertes Element wurde lokal geändert und die neue Lieferung ändert es ebenfalls, wenn importiert wird, dann zeigt das Tool es vorher als Konflikt und übernimmt die Lieferung dafür erst nach einer Wahl je Element."

Wenn eine Lieferung derselben Quelle erneut importiert wird, muss das Tool vorhandene Elemente aktualisieren und neue, geänderte und weggefallene Requirements vorher zeigen.

title: "Verweise von außen auflösen"
akzeptanzkriterien:
  - "Gegeben ein Verweis aus einem anderen Werkzeug mit UUID oder Kurz-ID, wenn er über API, Kommandozeile oder MCP-Server aufgelöst wird, dann liefert das Tool das Element mit Titel, Text, Status und aktueller Fassung."
  - "Gegeben ein Verweis mit Fassung, wenn er aufgelöst wird, dann meldet das Tool zusätzlich, ob die Fassung noch aktuell ist."
  - "Gegeben eine unbekannte oder mehrdeutige Kurz-ID, wenn sie aufgelöst wird, dann meldet das Tool das mit eindeutigem Fehlercode."

---

Das Tool muss Verweise aus anderen Werkzeugen über UUID oder Kurz-ID mit optionaler Fassung auflösen, damit jedes Requirement nur an einer Stelle gepflegt wird.

title: "Kurz-ID bilden"
akzeptanzkriterien:
  - "Gegeben ein Element, wenn seine ID angezeigt wird, dann erscheint das Präfix seines Typs und eine Kurzform aus mindestens 6 Zeichen vom Ende der UUID."
  - "Gegeben zwei Elemente, deren UUIDs auf dieselben 6 Zeichen enden, wenn ihre IDs angezeigt werden, dann verlängert das Tool beide Kurzformen, bis sie sich unterscheiden."
  - "Gegeben eine Kurz-ID wird in der Anzeige verlängert, wenn die Dateien geprüft werden, dann ist kein Dateiname geändert."

Das Tool muss jedes Element mit einer Kurz-ID aus dem Präfix seines Typs und dem Ende seiner UUID anzeigen, die im Arbeitsbereich eindeutig ist.

  - "Gegeben ein Metamodell, das eine Property mit der Bedeutung Gültigkeit kennzeichnet, wenn die Sicht einer Variante berechnet wird, dann wertet das Tool diese Property aus."
  - "Gegeben eine Bedeutung ist im Metamodell keinem Schlüssel zugeordnet, wenn die zugehörige Funktion aufgerufen wird, dann meldet das Tool, welche Zuordnung fehlt."

Das Tool muss die in D-012 genannten Bedeutungen kennen und sie über eine Kennzeichnung im Metamodell beliebigen Typen, Properties und Beziehungsarten zuordnen lassen.

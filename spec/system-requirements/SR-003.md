title: "Elemente unabhängig von Ordnern finden"
akzeptanzkriterien:
  - "Gegeben eine Element-Datei in einem beliebigen Unterordner eines eingebundenen Repositories, wenn der Arbeitsbereich geöffnet wird, dann erscheint das Element im Tool."
  - "Gegeben eine Markdown-Datei ohne Frontmatter mit `id` und `type`, wenn der Arbeitsbereich geöffnet wird, dann zählt sie nicht als Element und bleibt unverändert."
  - "Gegeben eine Element-Datei wird in einen anderen Ordner verschoben, wenn der Arbeitsbereich neu gelesen wird, dann bleiben alle Beziehungen auf das Element gültig."

Das Tool muss alle Element-Dateien in allen Ordnern der Repositories des Arbeitsbereichs erkennen, unabhängig von der Ordnerstruktur.

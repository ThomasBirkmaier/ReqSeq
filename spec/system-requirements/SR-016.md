title: "Unbekannte Properties erhalten und melden"
akzeptanzkriterien:
  - "Gegeben eine Element-Datei mit einer Property, die das Metamodell nicht kennt, wenn der Arbeitsbereich geöffnet wird, dann zeigt das Tool zu diesem Element einen Hinweis mit dem Schlüssel der Property."
  - "Gegeben ein solches Element, wenn es im Tool bearbeitet und gespeichert wird, dann bleibt die unbekannte Property mit ihrem Wert unverändert in der Datei."
  - "Gegeben ein Element mit einem Typ, den das Metamodell nicht kennt, wenn der Arbeitsbereich geöffnet wird, dann zeigt das Tool das Element mit einem Hinweis und lässt es nur lesen."

---

Wenn eine Element-Datei Properties oder einen Typ enthält, die das Metamodell nicht kennt, muss das Tool sie unverändert erhalten und als Hinweis melden.

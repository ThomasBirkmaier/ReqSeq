title: "Baseline als Datei festhalten"
akzeptanzkriterien:
  - "Gegeben ein Paket oder eine Auswahl, wenn eine Baseline angelegt wird, dann entsteht eine YAML-Datei mit Name, Datum, dem aktuellen Commit je beteiligtem Repository und ID und Fassung jedes enthaltenen Elements."
  - "Gegeben Elemente der Auswahl haben nicht committete Änderungen, wenn eine Baseline angelegt werden soll, dann lehnt das Tool das ab und nennt diese Elemente."
  - "Gegeben eine Baseline, wenn sie angelegt wird, dann fragt das Tool nach keinem Anlass und keiner Zustimmung."
  - "Gegeben die Baseline-Datei, wenn sie geschrieben ist, dann führt das Tool selbst keinen Commit aus."
  - "Gegeben eine Auswahl über eine Variante, wenn eine Baseline angelegt wird, dann nennt die Baseline-Datei diese Variante."

Das Tool muss jederzeit eine Baseline einer Auswahl als Datei mit ID und Fassung jedes Elements und dem Commit jedes beteiligten Repositories anlegen.

akzeptanzkriterien:
  - "Gegeben eine Arbeitsbereichs-Datei nennt für das Metamodell ein eigenes Repository, wenn der Arbeitsbereich geöffnet wird, dann liest das Tool das Metamodell von dort."
  - "Gegeben das Metamodell-Repository ist nur lesend zugänglich, wenn mit den Elementen gearbeitet wird, dann stehen alle Funktionen außer dem Ändern des Metamodells zur Verfügung."
  - "Gegeben das Metamodell liegt als Ordner im Haupt-Repository, wenn der Arbeitsbereich geöffnet wird, dann arbeitet das Tool genauso."

Das Tool muss das Metamodell sowohl aus einem Ordner im Haupt-Repository als auch aus einem eigenen Repository lesen können.

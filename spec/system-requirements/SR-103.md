title: "Geänderte Kern-Requirements seit der Baseline einer Variante zeigen"
akzeptanzkriterien:
  - "Gegeben ein Kern-Requirement ohne Gültigkeit hat sich seit der neuesten Baseline von Variante A geändert, wenn die Hinweise berechnet werden, dann nennt das Tool es an A mit beiden Fassungen."
  - "Gegeben eine neue Baseline von A, wenn die Hinweise erneut berechnet werden, dann erscheint es nicht mehr."
  - "Gegeben eine Variante ohne Baseline, wenn die Hinweise berechnet werden, dann zeigt das Tool dazu keinen Hinweis."

Das Tool muss an jeder Variante die übernommenen Kern-Requirements zeigen, die sich seit ihrer neuesten Baseline geändert haben.

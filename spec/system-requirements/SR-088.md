akzeptanzkriterien:
  - "Gegeben eine Element-Datei wurde kopiert, wenn der Arbeitsbereich gelesen wird, dann meldet das Tool beide Dateien mit der gemeinsamen UUID."
  - "Gegeben Beziehungen auf diese UUID, wenn sie angezeigt werden, dann kennzeichnet das Tool sie als mehrdeutig."
  - "Gegeben doppelte UUIDs, wenn über die Kommandozeile geprüft wird, dann endet die Prüfung mit Exit-Code 1."

Wenn zwei Element-Dateien dieselbe UUID tragen, muss das Tool beide als doppelt melden und keine davon von selbst ändern.

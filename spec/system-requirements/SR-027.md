title: "Hinweis bestätigen"
akzeptanzkriterien:
  - "Gegeben ein Hinweis auf eine veraltete Beziehung, wenn er bestätigt wird, dann schreibt das Tool die aktuelle Fassung des Ziels in die Beziehung und ändert sonst nichts an der Datei."
  - "Gegeben mehrere ausgewählte Hinweise, wenn sie gemeinsam bestätigt werden, dann gilt das für jeden einzeln."
  - "Gegeben ein Hinweis wurde bestätigt, wenn die Datei mit Git verglichen wird, dann ist die neue Fassung als normale Änderung sichtbar und kann im Merge Request geprüft werden."

Wenn ein Mensch einen Hinweis auf eine geänderte Fassung bestätigt, muss das Tool die neue Fassung in die betroffene Datei schreiben.

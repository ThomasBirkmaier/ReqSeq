title: "Fehlenden Zugriff anzeigen"
akzeptanzkriterien:
  - "Gegeben das Ziel einer Beziehung liegt in einem Repository, das lokal fehlt, wenn die Beziehung angezeigt wird, dann zeigt das Tool nur die Kurz-ID und den Vermerk, dass das Ziel nicht zugänglich ist."
  - "Gegeben ein solches Ziel, wenn Kette, Abdeckung oder Nachweisgrad berechnet werden, dann kennzeichnet das Tool das Ergebnis als unvollständig."
  - "Gegeben ein solches Ziel, wenn im Arbeitsbereich weitergearbeitet wird, dann blockiert das Tool keine Funktion."

---

Wenn das Ziel einer Beziehung lokal nicht vorhanden ist, muss das Tool die Beziehung nur mit der Kurz-ID des Ziels als nicht zugänglich anzeigen und sonst normal weiterarbeiten.

title: "Element mit Pflichtfeldern zuerst anlegen"
akzeptanzkriterien:
  - "Gegeben ein Typ ist gewählt, wenn ein neues Element angelegt wird, dann zeigt das Tool zuerst nur Titel, Text und die Pflicht-Properties des Typs."
  - "Gegeben Pflicht-Properties sind leer, wenn gespeichert wird, dann speichert das Tool trotzdem und zeigt einen Hinweis."
  - "Gegeben ein gespeichertes Element, wenn es erneut geöffnet wird, dann lassen sich alle weiteren Properties des Typs ergänzen."

Das Tool muss beim Anlegen eines Elements zuerst nur die Pflichtfelder abfragen und das Speichern auch mit leeren Pflichtfeldern erlauben.

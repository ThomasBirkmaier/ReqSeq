  - "Gegeben ein Requirement mit der Gültigkeit Variante A und Variante B, wenn die Sichten berechnet werden, dann gilt es nur für diese beiden."
  - "Gegeben eine Variante wird abgelöst, wenn die Gültigkeiten angezeigt werden, dann zeigt das Tool zu jedem Requirement mit dieser Variante einen Hinweis."

Das Tool muss an jedem Requirement eine Gültigkeit als Liste von Varianten führen, wobei eine leere Liste für alle gilt.

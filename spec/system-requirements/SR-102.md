title: "Dateien stabil schreiben"
akzeptanzkriterien:
  - "Gegeben eine Element-Datei, wenn eine Property geändert und gespeichert wird, dann zeigt der Vergleich mit Git nur die Zeilen dieser Property als geändert."
  - "Gegeben eine von Hand geschriebene Datei mit eigener Reihenfolge der Schlüssel, wenn sie im Tool gespeichert wird, dann bleibt die Reihenfolge erhalten."
  - "Gegeben zwei Branches ergänzen am selben Element verschiedene Beziehungen, wenn sie mit Git zusammengeführt werden, dann steht jede Beziehung auf eigenen Zeilen und ein Konflikt lässt sich mit den üblichen Werkzeugen lösen."

Wenn das Tool ein Element speichert, muss es nur die Zeilen der Datei ändern, deren Inhalt sich geändert hat.

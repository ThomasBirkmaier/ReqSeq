acceptance-criteria:
  - "Gegeben API und MCP-Server laufen, wenn die offenen Ports geprüft werden, dann lauscht die API nur auf Loopback-Adressen (127.0.0.1 und, wo vorhanden, ::1), und der MCP-Server öffnet keinen Port."
  - "Gegeben ein anderer Rechner im selben Netz, wenn er die API aufruft, dann kommt keine Verbindung zustande."
  - "Gegeben die Einstellungen und Optionen des Tools, wenn sie geprüft werden, dann öffnet keine API oder MCP-Server für andere Rechner."
  - "Gegeben die API läuft, wenn eine Anfrage ohne das Token kommt, das die API beim Start in die Datei `api.json` im Ordner des Zwischenspeichers schreibt, oder mit einem Host, der nicht eine Loopback-Adresse oder `localhost` mit dem Port der API nennt, oder mit einem Origin-Kopf, wie ihn ein Browser sendet, dann lehnt die API sie ab und führt keinen Befehl aus."

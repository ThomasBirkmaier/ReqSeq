title: Mindestzahl einer Beziehung über die Ableitungskette erfüllen
spec-id: SR-181
rationale: "Bei der Prüfung von SR-144 (PR #957) hat sich gezeigt, dass die Mindestzahl „derives-from SR → Need, min 1“ (#838 Q4) auch System Requirements als Lücke meldet, die nur ein anderes SR verfeinern und deren Ableitungskette über dieses SR bei einem Need endet (SR-146, SR-147, SR-159, SR-161, SR-163). Traceability verlangt, dass sich jedes Requirement auf seine Quelle zurückführen lässt; das leistet die Ableitungskette über das verfeinerte SR. Direkte Links zusätzlich wären redundant und müssten bei jeder Änderung des Eltern-SRs mitgepflegt werden. Die Mindestzahl und ihre Kennzahl in der Matrix sollen erhalten bleiben. In einer Varianten-Sicht zählen nur die Elemente dieser Sicht, wie Varianten sonst behandelt werden. Damit die Hinweise der eigenen Spec verschwinden, muss `spec/metamodel/spec-model.yaml` das Limit nach der Umsetzung zusätzlich kennzeichnen; das ist eine eigene Aufgabe."
requirement-type: functional
acceptance-criteria:
  - key: hg89
    text: Gegeben das Metamodell legt mindestens eine Beziehung „derives-from“ von einem System Requirement auf einen Need fest und kennzeichnet diese Mindestzahl als über die Ableitungskette erfüllbar, wenn SR-A das SR-B verfeinert, SR-B sich von einem Need ableitet und der Bestand geprüft wird, dann erscheint für SR-A kein Hinweis zur Anzahl.
  - key: d79b
    text: Gegeben dieselbe Konstellation wie in AK1, aber ohne Kennzeichnung, wenn der Bestand geprüft wird, dann erscheint für SR-A der Hinweis aus SR-152 AK2, denn das Tool zählt dann nur direkte Beziehungen.
  - key: hcmy
    text: Gegeben eine gekennzeichnete Mindestzahl, wenn sie für ein Element geprüft wird, dann folgt das Tool von diesem Element aus aufwärts allen Beziehungen mit der Bedeutung Ableitung, gleich welcher Art und über Elemente jedes Typs, und zählt die verschiedenen Elemente des Ziel-Typs, die es direkt oder über die Ableitungskette erreicht; die Mindestzahl ist erfüllt, wenn diese Zahl mindestens die Mindestzahl ist.
  - key: d2y3
    text: Gegeben ein Element der Ableitungskette oder ein erreichtes Ziel hat einen als ungültig gekennzeichneten Status oder ist nicht verfügbar, wenn die Ableitungskette verfolgt wird, dann endet sie dort, und dieses Element zählt nicht als erreichtes Ziel; eine Beziehung auf eine ältere Fassung trägt die Ableitungskette weiter.
  - key: xmq5
    text: Gegeben die Ableitungskette führt in einen Zyklus, wenn der Bestand geprüft wird, dann endet die Prüfung, und es zählen nur die bis dahin erreichten Ziele; den Zyklus selbst meldet die Prüfung wie bisher (SR-022).
  - key: f7d6
    text: Gegeben eine gekennzeichnete Mindestzahl, wenn ein Element sie weder direkt noch über die Ableitungskette erreicht und der Bestand geprüft wird, dann erscheint für dieses Element derselbe Hinweis wie in SR-152 AK2 mit Element, Beziehungsart, Ziel-Typ, Anzahl und Mindestzahl und der Angabe, dass auch über die Ableitungskette gezählt wurde; jedes Element der Kette wird für sich nach dieser Regel geprüft, und der Hinweis „ohne Parent“ (SR-022) bleibt davon unberührt.
  - key: hs83
    text: Gegeben eine Zeile der Traceability-Matrix, die die Mindestzahl nur über die Ableitungskette erfüllt, wenn die Matrix angezeigt wird, dann ist die Zelle nicht als Lücke, sondern als indirekt erfüllt gekennzeichnet und nennt die über die Ableitungskette erreichten Ziele mit Kurz-ID und Titel, und die Zeile zählt im Anteil über der Spalte als erfüllt (SR-153).
  - key: rv3w
    text: Gegeben ein Metamodell, das eine Höchstzahl als über die Ableitungskette erfüllbar kennzeichnet, wenn das Metamodell gelesen wird, dann meldet das Tool einen Fehler zum Metamodell mit Datei und Zeile.
  - key: gzs3
    text: Gegeben derselbe Bestand, wenn er über App, Kommandozeile, API oder MCP geprüft oder die Matrix abgefragt wird, dann liefert das Tool dieselben Hinweise, Zellzustände und Anteile (D-029).
  - key: rzcv
    text: Gegeben eine Prüfung oder Matrix in der Sicht einer Variante, wenn die Ableitungskette verfolgt wird, dann zählen nur Elemente dieser Sicht; ein Element, das die Variante ausschließt oder ersetzt, unterbricht die Ableitungskette.

Das Tool muss eine Mindestzahl im Metamodell als über die Ableitungskette erfüllbar kennzeichnen lassen und eine so gekennzeichnete Mindestzahl bei der Prüfung des Bestands und in der Traceability-Matrix auch dann als erfüllt werten, wenn das Element die Ziele nur über seine Ableitungskette erreicht.

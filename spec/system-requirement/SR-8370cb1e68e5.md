acceptance-criteria:
  - Gegeben der Cursor steht in einer Zelle einer Tabelle, wenn Tab oder Shift+Tab gedrückt wird, dann steht er in der nächsten beziehungsweise vorigen Zelle; nach der letzten Zelle legt Tab eine neue Zeile an.
  - Gegeben eine Tabelle wurde bearbeitet, wenn der Cursor sie verlässt, dann sind ihre Spalten in der Datei mit Leerzeichen bündig ausgerichtet, und die Tabelle ist weiter gültiges Markdown mit GitHub-Erweiterungen.
  - Gegeben der Cursor steht in einer Tabelle, wenn ein Befehl zum Einfügen oder Entfernen einer Zeile oder Spalte über die Befehlszeile aufgerufen wird, dann ändert das Tool die Tabelle so an der Stelle des Cursors.

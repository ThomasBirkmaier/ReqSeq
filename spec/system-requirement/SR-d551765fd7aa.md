title: Richtung nachträglich gezeichneter Verbindungen im Graphen erkennbar machen
spec-id: SR-160
rationale: Ein Hinweis aus einer Durchsicht des Graphen (SR-111) als Wunsch für nach 1.0 im Paket Später parken. Eine Kante, die nach der Auslegung gezeichnet wird, etwa ein Verweis aus dem Text eines Parents auf das Element, läuft von einem unteren zu einem oberen Knoten oder zwischen zwei Knoten einer Ebene, und nichts zeigt, welches Ende die Quelle ist, obwohl bei jeder anderen Kante das Ziel oben liegt.
requirement-type: functional
acceptance-criteria:
  - Gegeben der Graph eines Elements mit einer Kante, deren Ziel tiefer als ihre Quelle oder auf derselben Ebene liegt, wenn er angezeigt wird, dann ist an der Kante erkennbar, welches Ende die Quelle und welches das Ziel ist, etwa durch eine Pfeilspitze.

Das Tool muss im Graphen eines Elements (SR-111) an jeder Kante, deren Ziel nicht über ihrer Quelle liegt, erkennbar machen, welches Ende die Quelle ist.

title: Lücken der Nachweisführung melden
spec-id: SR-230
rationale: Agents ohne Vorwissen legten Requirements und Tests an, schrieben die Testergebnisse in einen Ordner, der kein Nachweisort war, und hielten 0 % Nachweisgrad für fertig, weil keine Prüfung des Arbeitsbereichs die Lücke meldete.
requirement-type: functional
acceptance-criteria:
  - key: qymg
    text: Gegeben ein Arbeitsbereich mit mindestens einem Requirement und ohne Nachweisort, wenn er ganz geprüft wird, dann meldet das Tool an der Arbeitsbereichs-Datei eine Warnung, die den Eintrag für einen Nachweisort nennt; in einer auf geänderte Elemente beschränkten Prüfung (SR-092) entfällt sie.
  - key: k09q
    text: Gegeben ein Arbeitsbereich mit mindestens einem Nachweisort und Requirements mit gültigem Status, deren Nachweismethode Test ist und deren Nachweisstatus im Kern offen ist, wenn er ganz geprüft wird, dann meldet das Tool an der Arbeitsbereichs-Datei einen einzigen Befund mit dem Schweregrad Info, mit ihrer Zahl und dem Aufruf, der genau sie auflistet; in einer beschränkten Prüfung entfällt er. Die Nachweismethode ist Test, wenn die Property mit der Bedeutung Nachweismethode den Wert mit dem Schlüssel `test` oder keinen Wert trägt; ordnet das Metamodell die Bedeutung keiner Property zu, zählt jedes Requirement.
  - key: z4yt
    text: Gegeben eine JUnit-Datei wird ergänzt (SR-029) und die ergänzte Datei liegt außerhalb aller Nachweisorte, wenn das Ergänzen endet, dann meldet das Tool eine Warnung, dass ihre Ergebnisse nicht zählen, bis sie in einem Nachweisort liegt; die Datei ist ergänzt, und der Exit-Code ist derselbe wie ohne diese Warnung.
  - key: x4g5
    text: Gegeben ein Arbeitsbereich wird angelegt (SR-014 AK1), wenn das Anlegen gelingt, dann nennt die Arbeitsbereichs-Datei den Ordner `evidence` im Haupt-Repository als Nachweisort.

Das Tool muss beim Prüfen des Arbeitsbereichs und beim Ergänzen von Testergebnissen melden, wenn Nachweise nicht zählen können oder Requirements ohne Nachweis sind, damit ein fehlender Nachweis nicht unbemerkt bleibt.

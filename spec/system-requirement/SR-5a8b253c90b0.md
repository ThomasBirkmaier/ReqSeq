    text: "Gegeben eine Auswahl (SR-101), wenn die Abdeckung berechnet wird (CLI, API, MCP: `evidence.coverage`), dann nennt die Ausgabe je Ebene auch die Zahl der Elemente ohne Children und, bei Requirements, die Zahl der Elemente ohne Nachweis, jede wählbar wie die anderen Zahlen (AK2), bei einer Ebene ohne solche Elemente mit 0; je Ebene stehen die Angaben „ohne“ vor den Angaben „mit“: in der Textausgabe der Kommandozeile als Zeilen, im JSON der Kommandozeile, der API und des MCP-Servers als Reihenfolge der Angaben, wie der Befehlskatalog sie führt."

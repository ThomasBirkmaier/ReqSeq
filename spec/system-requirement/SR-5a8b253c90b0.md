acceptance-criteria:
  - "Gegeben eine Auswahl (SR-101), wenn die Abdeckung berechnet wird, dann zeigt das Tool für jede Ebene, wie viele Requirements Children haben und wie viele einen Nachweis."
  - "Gegeben eine Zahl der Abdeckung, wenn sie angeklickt oder abgefragt wird, dann liefert das Tool die zugehörigen Requirements, auch die ohne Abdeckung."
  - "Gegeben ein Ziel liegt in einem nicht zugänglichen Repository, wenn die Abdeckung berechnet wird, dann ist das Ergebnis als unvollständig gekennzeichnet."
  - "Gegeben Requirements mit einem als ungültig gekennzeichneten Status, wenn die Abdeckung berechnet wird, dann zählen sie nicht mit."
  - Gegeben eine Auswahl ohne gewählte Variante, wenn die Abdeckung berechnet wird, dann zählen nur Requirements, Children und Nachweise des Kerns.

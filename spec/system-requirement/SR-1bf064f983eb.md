  - "Gegeben ein Metamodell, das eine Property mit der Bedeutung Akzeptanzkriterien kennzeichnet, wenn der Nachweisstatus berechnet wird, dann zählt das Tool die Einträge dieser Property als Akzeptanzkriterien des Requirements."

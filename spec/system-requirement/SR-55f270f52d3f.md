  - key: p4gn
    text: Gegeben eine Änderung im Editor, wenn eine Sekunde lang keine Eingabe folgt oder das Element verlassen wird, dann steht die Änderung in der Datei.
  - key: dmrq
    text: Gegeben geänderte und gespeicherte Eingaben, wenn Rückgängig oder Wiederholen gewählt wird (Ctrl+Z und Ctrl+Shift+Z, unter Windows auch Ctrl+Y, unter macOS mit Cmd), dann stellt das Tool den vorigen oder nächsten Inhalt seit dem Öffnen des Elements her, im Editor und in der Datei.
  - key: ptsm
    text: Gegeben die App, wenn sie geprüft wird, dann gibt es keinen Knopf und keinen Dialog zum Speichern.
  - key: znzt
    text: Gegeben eine Änderung im Editor, wenn Ctrl+S gedrückt wird, unter macOS Cmd+S, dann steht sie sofort in der Datei.
  - key: phcy
    text: Gegeben die Datei lässt sich nicht schreiben, wenn das Tool speichern will, dann bleibt die Eingabe im Editor und die Statuszeile nennt den Grund; beim ersten Versuch, das Fenster zu schließen, bleibt es offen.

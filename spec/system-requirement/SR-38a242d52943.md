acceptance-criteria:
  - Gegeben die App unter Windows oder Linux, wenn sie im hellen oder im dunklen Modus angezeigt wird, dann hat die Titelleiste die Farben des übrigen Fensters.
  - Gegeben der Modus wird umgeschaltet, wenn die App angezeigt wird, dann folgt die Titelleiste sofort.
  - Gegeben eine solche Titelleiste, wenn das Menü aufgerufen wird, dann ist es weiterhin erreichbar.

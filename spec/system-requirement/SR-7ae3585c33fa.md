acceptance-criteria:
  - Gegeben ein Element ist in der App sichtbar, wenn es über MCP geändert wird, dann zeigt die App den neuen Inhalt nach höchstens 2 Sekunden und hebt das Element kurz hervor.
  - Gegeben die Hervorhebung wurde gezeigt, wenn 3 Sekunden vergangen sind, dann bleibt keine Markierung stehen.
  - Gegeben das Element ist mit ungespeicherten Änderungen offen, wenn es von außen geändert wird, dann gilt die Regel für Konflikte bei offenem Editor und es geht keine Eingabe verloren.

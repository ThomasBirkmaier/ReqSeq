acceptance-criteria:
  - Gegeben der Modus ist an, wenn ein Agent über MCP ein Element liest oder ändert, dann zeigt die App dieses Element nach höchstens 1 Sekunde.
  - Gegeben der Modus ist aus, wenn ein Agent arbeitet, dann ändert sich die Ansicht nicht. Beim Start ist der Modus aus.
  - Gegeben der Modus ist an, dann zeigt die Statuszeile das an.
  - Gegeben ein Agent oder Skript, wenn es den Modus über CLI, API oder MCP einschalten will, dann geht das nicht. Ein- und Ausschalten geht nur in der App, per Befehl und per Tastenkürzel.
  - Gegeben der Modus ist an und der Nutzer hat ungespeicherte Eingaben, wenn ein Agent ein anderes Element liest, dann wechselt die App die Ansicht nicht, bis die Eingabe gespeichert ist.
  - Gegeben der Modus ist an, wenn die App einem Agent folgt, dann öffnet das Tool dafür keine Netzwerkverbindung.

  - Gegeben ein Requirement mit Gültigkeit [A, B] wird in der App bearbeitet, wenn der Editor offen ist, dann zeigt der Editor die Varianten A und B, für die es gilt.
  - Gegeben ein Kern-Requirement, das in Variante A durch ein eigenes Requirement ersetzt und für Variante B ausgeschlossen ist, wird in der App bearbeitet, wenn der Editor offen ist, dann nennt der Editor A und B.
  - Gegeben dasselbe Kern-Requirement, wenn es mit `element.get` über CLI, API oder MCP abgefragt wird, dann nennt das Ergebnis A als ersetzende und B als ausschließende Variante.

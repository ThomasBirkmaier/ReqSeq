acceptance-criteria:
  - Gegeben ein Metamodell mit eigenen Statuswerten, wenn der Status eines Elements gesetzt wird, dann bietet das Tool nur die Werte an, die der Typ des Elements hat; einen anderen Wert lehnt `element.setStatus` (App, CLI, API, MCP) ab und schreibt nichts.
  - "Gegeben eine Element-Datei mit einem Status, den der Typ des Elements nicht hat, wenn der Bestand geprüft oder die Hinweise abgefragt werden (App, CLI, API, MCP: `workspace.check`, `hint.list`), dann meldet das Tool eine Warnung mit Element und Status und ändert die Datei nicht."
  - "Gegeben ein Element ohne Status, wenn der Bestand geprüft wird (App, CLI, API, MCP: `workspace.check`), dann meldet das Tool eine Warnung, außer sein Typ hat nur ungültige Statuswerte: dann gibt es dazu keinen Befund, das Element gilt als gültig (D-030, D-045), und die Prüfung meldet zum Typ einmal eine Info."

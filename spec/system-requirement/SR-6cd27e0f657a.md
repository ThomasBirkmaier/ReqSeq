title: Befehle über Anfangsbuchstaben aufrufen
spec-id: SR-121
rationale: "In der Befehlszeile (Cmd+Shift+P) soll zum Beispiel die Eingabe l-a-e den Befehl list all elements finden. Zugestimmt ist dem Vorschlag: feste Kürzel für die häufigsten Befehle, unscharfe Suche über Anfangsbuchstaben für alles andere, eine einmal genutzte Buchstabenfolge bleibt an erster Stelle (ThomasBirkmaier/ReqSeq-archive#404)."
requirement-type: functional
acceptance-criteria:
  - Gegeben die Befehlszeile mit den Befehlen, wenn die Anfangsbuchstaben der Wörter eines Befehls getippt werden, zum Beispiel „lae“ für „List all elements“, und für diese Buchstabenfolge kein anderer Befehl gelernt ist (AK2), dann steht dieser Befehl an erster Stelle und Enter führt ihn aus.
  - Gegeben eine Buchstabenfolge wurde für einen Befehl genutzt, wenn sie wieder getippt wird, dann steht dieser Befehl wieder an erster Stelle.
  - Gegeben einer der häufigsten Befehle, wenn er in der Befehlszeile angezeigt wird, dann steht sein festes Tastenkürzel daneben.

Das Tool muss die häufigsten Befehle über feste Tastenkürzel im Stil von Emacs und jeden anderen Befehl über die Anfangsbuchstaben seiner Wörter aufrufen lassen.

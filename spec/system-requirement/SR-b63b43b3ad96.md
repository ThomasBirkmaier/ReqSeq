title: Suche auf gewählte Felder beschränken
spec-id: SR-216
rationale: Wer nur in einem Teil der Elemente sucht, etwa in den Akzeptanzkriterien, bekommt ohne Beschränkung Treffer aus Titel, Text und anderen Properties, die er erst aussortieren muss. Standard bleibt die Suche über alle Felder. Die Felder wählt man in der Befehlszeile wie andere feste Werte (SR-215). Die Kennung gehört zu den IDs und hat wie dort keinen Ausschnitt. Angaben, die das Metamodell nicht kennt (SR-016), findet nur „alle Properties“; ein unbekannter Schlüssel wird abgelehnt, damit ein Tippfehler auffällt. In Filtern und Perspektiven sucht die Bedingung Textsuche weiter in allen Feldern, ebenso die Suche innerhalb einer Liste (SR-124 AK3); eine Bedingung auf eine einzelne Property prüft dort, ob ihr Wert eine Zeichenfolge enthält, ohne unscharfe Suche. Beziehungen werden nicht durchsucht.
requirement-type: functional
acceptance-criteria:
  - key: wf2k
    text: Gegeben eine Suche, die auf Felder beschränkt ist, zum Beispiel auf die Akzeptanzkriterien, wenn gesucht wird, dann findet das Tool genau die Elemente, bei denen jeder Suchbegriff in mindestens einem der gewählten Felder vorkommt, unscharf und in jeder Groß- und Kleinschreibung wie in SR-068 AK2. Ein Element steht nicht deshalb weiter vorn, weil ein Suchbegriff auch in einem nicht gewählten Feld vorkommt, und ein Treffer über eine ID steht nur dann zuerst, wenn die IDs gewählt sind.
  - key: r9jg
    text: Gegeben eine Suche über App, Kommandozeile, API oder MCP-Server, wenn sie als Felder Titel, Text, IDs (UUID, Kurz-ID, Kennung), alle Properties oder den Schlüssel einer Property des Metamodells nennt, die keine Beziehungen hält und nicht der Titel ist, dann sucht das Tool dort; „alle Properties“ umfasst auch die Namen von Typ und Status und Angaben, die das Metamodell nicht kennt. Eine Property mit festen Werten wird über die Namen ihrer Werte gefunden. Sind alle Properties und eine einzelne Property gewählt, sucht das Tool wie mit allen Properties. Nennt die Suche eine Property, die Beziehungen hält, oder einen Schlüssel, den das Metamodell nicht kennt, lehnt das Tool sie mit einer Meldung ab, die den Schlüssel nennt. Die Schlüssel `title`, `text`, `id` und `properties` meinen immer die Felder Titel, Text, IDs und alle Properties, auch wenn eine Property oder eine Beziehungsart des Metamodells so heißt; eine solche Property lässt sich nicht einzeln wählen. Nennt die Suche sonst den Schlüssel der Property mit der Bedeutung Titel oder den Schlüssel einer Beziehungsart, lehnt das Tool sie ebenfalls mit einer Meldung ab, die den Schlüssel nennt, beim Schlüssel der Titel-Property mit dem Hinweis auf `title`.
  - key: s99w
    text: Gegeben ein Arbeitsbereich, wenn die wählbaren Felder abgefragt werden, in der App in der Feldwahl (AK6) oder über Kommandozeile, API oder MCP-Server, dann liefert das Tool Titel, Text, IDs, alle Properties und jede Property nach AK2, die ein Typ der Elemente des Arbeitsbereichs hat, jedes mit seinem Namen aus dem Metamodell und seinem Schlüssel. Eine Property, deren Schlüssel `title`, `text`, `id` oder `properties` lautet, liefert es nicht einzeln (AK2).
  - key: hpd4
    text: Gegeben eine Suche ohne gewählte Felder, wenn gesucht wird, dann sucht das Tool in allen Feldern wie in SR-068.
  - key: zq8s
    text: "Gegeben eine auf Felder beschränkte Suche, wenn ein Treffer gezeigt wird, dann stammen Fundort und Ausschnitt (SR-174) nur aus den gewählten Feldern, in der Reihenfolge aus SR-174 AK3: im Text, wenn er gewählt ist und ein Suchbegriff dort vorkommt, sonst in der ersten gewählten Property in der Reihenfolge des Metamodells. Der Titel ist nur hervorgehoben, wenn er gewählt ist. Ein Treffer nur im Titel, in einer ID, in der Kennung oder im Namen von Typ oder Status hat keinen Ausschnitt."
  - key: t56j
    text: "Gegeben die Suche in der Befehlszeile, wenn Ctrl+Enter (unter macOS Cmd+Enter) gedrückt oder in der Zeile unter den Treffern auf den Hinweis zur Feldwahl geklickt wird, dann zeigt die Befehlszeile die Felder nach AK3 als Treffer, jedes mit seinem Namen und seinem Schlüssel daneben, und grenzt sie beim Tippen mit unscharfer Suche ein. Enter oder ein Klick auf einen Treffer setzt das Feld als Marke vor den Suchbegriff; nach „alle Properties“ steht keine Marke einer einzelnen Property mehr. Markiert ist zuerst der Treffer, der zum Suchbegriff zurückführt: „Search in N fields“, ohne Marke „Search all fields“. Der Suchbegriff bleibt erhalten."
  - key: vd3h
    text: Gegeben Marken der Felder in der Eingabe der Suche, wenn auf das × einer Marke geklickt wird, dann entfällt sie; wenn in leerer Eingabe die Rücktaste gedrückt wird, beim Suchbegriff oder in der Feldwahl, entfällt die letzte Marke (SR-134 AK4). Escape führt aus der Feldwahl mit den Marken zum Suchbegriff zurück.
  - key: gg4w
    text: Gegeben eine Suche in der Befehlszeile mit Marken, wenn ein Suchbegriff getippt wird, dann kommen die Treffer beim Tippen (SR-183) nur aus den gewählten Feldern und sind die ersten der Liste der Suchtreffer mit denselben Feldern.
  - key: v450
    text: "Gegeben die Suche in der Befehlszeile, wenn sie den Suchbegriff oder die Felder fragt, dann steht unter den Treffern die Zeile aus SR-210 in derselben Höhe: beim Suchbegriff die Zusammenfassung von „Search elements“ aus dem Befehlskatalog, in der Feldwahl Name und Beschreibung des Arguments `fields`; die zweite Textzeile nennt die Tasten des Schritts, beim Suchbegriff Ctrl+Enter (unter macOS Cmd+Enter) für die Feldwahl."
  - key: yq3n
    text: Gegeben eine auf Felder beschränkte Suche, wenn die Liste der Suchtreffer geöffnet wird, dann nennt sie unter ihrer Überschrift die gewählten Felder mit ihren Namen, ohne gewählte Felder nichts. Zwei Suchen mit demselben Suchbegriff und verschiedenen Feldern sind zwei Listen. Die Felder sind kein Filterschritt, „Clear all list filters“ lässt sie stehen. Wird die App geschlossen und wieder geöffnet (SR-115 AK4), ist die Liste mit denselben Feldern wieder da. Kennt das Metamodell eine gewählte Property nicht mehr, zeigt die Liste statt der Treffer die Meldung des Tools (AK2). Eine neue Suche beginnt ohne gewählte Felder.
  - key: dhq2
    text: Gegeben dieselbe Suche mit denselben Feldern, wenn sie über App, Kommandozeile, API oder MCP-Server ausgeführt wird, dann liefert das Tool dieselben Treffer mit denselben Fundorten und Ausschnitten.

Das Tool muss eine Suche auf gewählte [Felder](reqseq:f2d8545d-fa41-4fe7-b5cd-a2c9346a67fd?version=n2:d78ded2d4829cf23) der Elemente beschränken lassen: Titel, Text, IDs, alle [Properties](reqseq:50b5de45-fe86-4668-86fc-70093ecee7fe?version=n2:2a7b4ec07a5b9b0d) oder einzelne Properties.

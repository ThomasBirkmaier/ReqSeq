acceptance-criteria:
  - "Gegeben importierte Elemente mit Stellungnahme, wenn sie an die Quelle exportiert werden (zum Beispiel `reqseq reqif export --mapping reqif/kunde-a.yaml --statements`), dann enthält die Datei jedes Element mit seinem ursprünglichen IDENTIFIER und der Stellungnahme als Attribut laut Zuordnung. Exportiert werden alle Elemente mit der Quelle der Zuordnung, durch eine Auswahl eingrenzbar, auch solche ohne Stellungnahme (leeres Attribut, in der Ausgabe gezählt), und von ihren Werten nur die Stellungnahme: als STRING oder, wenn die Zuordnung es so nennt, als XHTML. Die Datei hat einen einzigen, eigenen SPEC-OBJECT-TYPE mit nur dem Attribut der Stellungnahme, nicht die Typen der Quelle (dafür SR-158); ein Import in ReqSeq nimmt aus einer solchen Datei keine Stellungnahme und meldet jedes Objekt als Verlust."
  - Gegeben dieser Export, wenn er gegen das Schema von ReqIF 1.2 geprüft wird, dann ist er gültig.

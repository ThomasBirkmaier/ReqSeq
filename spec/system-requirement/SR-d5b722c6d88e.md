title: Ausgelieferte App lädt nur ihren eigenen Code
spec-id: SR-209
rationale: "Die Angriffsflächen ohne Requirement aus der Liste zu #1429 werden als Draft aufgenommen, mit den empfohlenen Antworten auf die offenen Fragen. Linux ist bei der Prüfung des App-Archivs ausgenommen, weil Electron sie nur unter macOS und Windows bietet. Die offenen Punkte nach dem Review werden wie empfohlen geklärt: AK2 gilt für den Start als App, weil die mitgelieferte Kommandozeile dasselbe Programm als Node nutzt (runAsNode); AK3 nennt, was nach dem Start gelingen muss."
requirement-type: constraint
acceptance-criteria:
  - Gegeben die Auslieferung für macOS oder Windows, wenn ihr App-Archiv nach dem Packen verändert wurde, dann startet die App nicht.
  - Gegeben die Auslieferung, wenn die App mit der Umgebungsvariable `NODE_OPTIONS`, mit Argumenten zum Debuggen oder mit Code außerhalb ihres App-Archivs gestartet wird, dann lädt sie diesen Code nicht.
  - Gegeben die Auslieferung, wenn die mitgelieferte Kommandozeile oder der MCP-Server gestartet wird, dann starten sie und führen Befehle aus.

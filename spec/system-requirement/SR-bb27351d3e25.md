title: Kontextmenü eines Elements in Listen, Graph und Paketen
spec-id: SR-197
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-08: Wer nur die Maus gewohnt ist, soll per Rechtsklick ein klassisches Kontextmenü bekommen, im Editor und in der ganzen App, als eigenes Menü im Stil der App mit einer kurzen, festen Auswahl von Befehlen je Stelle (D-075)."
requirement-type: functional
acceptance-criteria:
  - Gegeben ein Element als Zeile einer Liste, als Suchtreffer, als Knoten im Graphen, als Eintrag einer Paketseite als Kopf einer Zeile der Matrix oder als verbundenes Element in einer Zelle der Matrix, wenn darauf mit der rechten Maustaste geklickt wird, dann enthält das Kontextmenü „Show element“, „Show graph“, „Show neighbourhood“, „Show affected elements“, „Create relation“ und „Set status“ für dieses Element, an jeder dieser Stellen in derselben Reihenfolge.
  - Gegeben ein geteiltes Fenster, wenn „Show element“ aus dem Kontextmenü eines Eintrags gewählt wird, dann öffnet sich das Element im Bereich, in dem der Eintrag steht, wie beim Öffnen des ausgewählten Eintrags per Tastatur.

Die App muss überall, wo ein Element als Eintrag erscheint, per Rechtsklick auf diesen Eintrag dasselbe Kontextmenü mit den Befehlen für dieses Element öffnen.

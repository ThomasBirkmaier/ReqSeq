title: Kontextmenü eines Elements in Listen, Graph und Paketen
spec-id: SR-197
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-08: Wer nur die Maus gewohnt ist, soll per Rechtsklick ein klassisches Kontextmenü bekommen, im Editor und in der ganzen App, als eigenes Menü im Stil der App mit einer kurzen, festen Auswahl von Befehlen je Stelle (D-075). Links im Element (AK3, AK4): Entscheidung des Produktverantwortlichen, 2026-11-08 (#1181): Links zu verbundenen Elementen in einem geöffneten Element behalten das Menü des Feldes, das Menü des Elements gilt nur an den Stellen aus AK1. Entscheidung des Produktverantwortlichen, 2026-11-11: Die Zeile der Parents hat wie gebaut das Menü des Buffers, weil sie keine Angabe des Elements zeigt."
requirement-type: functional
acceptance-criteria:
  - Gegeben ein Element als Zeile einer Liste, der Übersicht oder der Umgebung, als Suchtreffer, als Knoten im Graphen, als Eintrag einer Paketseite, als Kopf einer Zeile der Matrix oder als verbundenes Element in einer Zelle der Matrix, wenn darauf mit der rechten Maustaste geklickt wird, dann enthält das Kontextmenü „Show element“, „Show graph“, „Show neighbourhood“, „Show affected elements“, „Create relation“ und „Set status“ für dieses Element, an jeder dieser Stellen in derselben Reihenfolge.
  - Gegeben ein geteiltes Fenster, wenn „Show element“ aus dem Kontextmenü eines Eintrags gewählt wird, dann öffnet sich das Element im Bereich, in dem der Eintrag steht, wie beim Öffnen des ausgewählten Eintrags per Tastatur.
  - Gegeben ein verbundenes Element in einem geöffneten Element, in einer Gruppe von Beziehungen oder in einer Property-Box mit Wertart Beziehung, wenn darauf mit der rechten Maustaste geklickt wird, dann öffnet sich nicht das Kontextmenü aus AK1, sondern das des Feldes (SR-196).
  - Gegeben eine Zeile in einem Buffer, der die Ausgabe eines Befehls zeigt, die kein anderer Buffer zeigt, zum Beispiel von „List hints“ oder „Show affected elements“, oder ein Titel in der Zeile der Parents (SR-107 AK1), wenn darauf mit der rechten Maustaste geklickt wird, dann öffnet sich das Kontextmenü des Buffers (SR-194 AK6).

Die App muss überall, wo ein Element als Eintrag erscheint (AK1), per Rechtsklick auf diesen Eintrag dasselbe Kontextmenü mit den Befehlen für dieses Element öffnen.

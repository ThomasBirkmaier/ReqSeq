title: Vom Wert einer Property zur Liste der Elemente mit diesem Wert
spec-id: SR-132
rationale: "Entscheidung des Produktverantwortlichen, 2026-10-27: Ein Klick auf eine Property wie topic soll einen Buffer mit allen Elementen öffnen, die denselben Wert haben, ähnlich wie in Logseq; bei Freitext-Properties klappt das so nicht, das ist zu berücksichtigen. Eine Property ist ein Wert in der Datei des Elements, keine eigene Seite wie in Logseq; die Liste ist deshalb eine gewöhnliche gefilterte Liste nach SR-069 und SR-124, so wie ein Paket eine Seite mit seinen Elementen ist (D-062). Welche Properties sich dafür eignen, gilt wie beim Filtern nach SR-124."
requirement-type: functional
acceptance-criteria:
  - Gegeben ein geöffnetes Element mit einer Property mit auswählbaren Werten, zum Beispiel „topic“, wenn auf ihrem Wert der Befehl zum Anzeigen der Elemente mit diesem Wert gewählt wird, über die Befehlszeile, ein Kürzel oder einen Klick, dann öffnet sich ein Buffer mit der Liste aller Elemente des Arbeitsbereichs, die diesen Wert haben.
  - Gegeben ein Auswahlwert aus dem Metamodell, ein Freitext mit wenigen verschiedenen Werten wie „topic“ oder der Status, wenn die Liste geöffnet wird, dann enthält sie genau die Elemente mit diesem Wert, bei einer Property mit mehreren Werten mit dem gewählten, und es sind dieselben Elemente, die Kommandozeile, API und MCP-Server für die Bedingung Property gleich Wert liefern.
  - Gegeben eine Property mit Beziehungen, zum Beispiel die Pakete, wenn die Liste für eines ihrer Ziele geöffnet wird, dann enthält sie die Elemente mit demselben Ziel, zum Beispiel alle Elemente des Pakets.
  - Gegeben eine Property mit langem Freitext, zum Beispiel die Akzeptanzkriterien oder die Begründung, wenn das Element angezeigt wird, dann bietet das Tool für ihren Wert keine Liste an, weder per Befehl noch per Kürzel noch per Klick.
  - Gegeben die Liste der Elemente mit einem Wert, wenn ein weiterer Filter gewählt wird, zum Beispiel nur System Requirements oder ein Status, dann grenzt er die Liste weiter ein wie jede gefilterte Liste.

Das Tool muss vom Wert einer Property eines geöffneten Elements die Liste aller Elemente öffnen lassen, die diesen Wert haben, als gefilterte Liste, die sich weiter filtern lässt.

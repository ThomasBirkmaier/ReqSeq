acceptance-criteria:
  - Gegeben eine neue Lieferung derselben Quelle, wenn sie mit `reqseq reqif analyze` gelesen oder importiert wird, dann zeigt das Tool vorher neue, geänderte und weggefallene Requirements getrennt an. Der Abgleich geht über Quelle und IDENTIFIER der Quelle; geändert heißt, die Lieferung ergibt für das Element ohne die Herkunfts-Properties andere Werte als seine Importfassung.
  - Gegeben ein Requirement mit gleicher Quelle und gleichem IDENTIFIER, wenn es importiert wird, dann aktualisiert das Tool das vorhandene Element und legt kein zweites an.
  - Gegeben ein weggefallenes Requirement, wenn importiert wird, dann kennzeichnet das Tool es nur in der Ausgabe von Analyse und Import und ändert weder Status noch Datei sonst; das Element bekommt keine Property dafür.
  - Gegeben ein importiertes Element, dessen Fassung nicht mehr seiner Importfassung entspricht, und die neue Lieferung ändert es ebenfalls, wenn importiert wird, dann zeigt das Tool es vorher als Konflikt und übernimmt die Lieferung dafür erst nach einer Wahl je Element („übernehmen“ oder „behalten“). Fehlt die Wahl für einen Konflikt, lehnt der Import ganz ab und nennt die Konflikte.

requirement-type: functional
acceptance-criteria:
  - key: c4pp
    text: "Gegeben ein Text als XHTML mit Überschriften, Listen, Tabellen und Hervorhebungen, wenn er importiert wird, dann stehen sie als Markdown in der Element-Datei. Beispiel: h1 bis h3, ul und ol auch verschachtelt, eine einfache Tabelle, strong und em. Eine Tabelle, die Markdown nicht fassen kann (Absätze in einer Zelle, rowspan, colspan), wird vereinfacht, wo kein Inhalt verloren geht (Zeilenumbruch in der Zelle als `<br>`), sonst bleibt der Text erhalten und der Verlust steht in der Liste (SR-053)."
  - key: tvd2
    text: Gegeben ein eingebettetes Bild, wenn es importiert wird, dann liegt es als Datei neben dem Element und der Text verweist darauf. Das Bild ist die Datei, auf die `<xhtml:object data=…>` verweist, neben der ReqIF-Datei; sie wird so neben das Element kopiert wie ein in der App eingefügtes Bild. Fehlt sie, ist das ein Verlust. Ein Bildpfad, der aus dem Ordner der ReqIF-Datei hinausführt (absolut, über `..` oder über einen Link) oder eine Adresse mit Schema nennt, wird nicht gelesen und ist ein Verlust.
  - key: xzp8
    text: Gegeben ein XHTML-Element ohne Gegenstück in Markdown (zum Beispiel eine Farbe über `style`), wenn es importiert wird, dann erscheint es in der Liste der Verluste (SR-053).

  - key: m800
    text: Gegeben ein offenes Element ohne ungespeicherte Eingaben, wenn seine Datei außen geändert wird, dann zeigt das Tool den neuen Inhalt und der Cursor bleibt an seiner Stelle im Text.
  - key: ydc8
    text: Gegeben ein offenes Element mit ungespeicherten Eingaben, wenn seine Datei außen geändert wird, dann speichert das Tool nicht, zeigt beide Inhalte und lässt mit den Befehlen „Keep my input“ und „Take the file“ wählen, welcher gilt.
  - key: v420
    text: Gegeben ein offenes Element, wenn seine Datei außen gelöscht wird, dann bleibt der Inhalt im Editor sichtbar, ein Vermerk nennt die Löschung, das Element lässt sich nur noch lesen, und das Tool legt die Datei nicht von selbst wieder an.

title: Änderung von außen bei offenem Element
spec-id: SR-106
requirement-type: functional
acceptance-criteria:
  - Gegeben ein offenes Element ohne ungespeicherte Eingaben, wenn seine Datei außen geändert wird, dann zeigt das Tool den neuen Inhalt und der Cursor bleibt an seiner Stelle im Text.
  - Gegeben ein offenes Element mit ungespeicherten Eingaben, wenn seine Datei außen geändert wird, dann speichert das Tool nicht, zeigt einen Hinweis mit beiden Fassungen und lässt wählen, welche gilt.
  - Gegeben ein offenes Element, wenn seine Datei außen gelöscht wird, dann bleibt der Inhalt im Editor sichtbar und ein Hinweis nennt die Löschung.

Wenn sich die Datei eines geöffneten Elements außerhalb des Tools ändert, darf das Tool keine Eingabe verlieren und keine fremde Änderung überschreiben.

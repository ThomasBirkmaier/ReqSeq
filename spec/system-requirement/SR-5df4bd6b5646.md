title: Nicht genannte Typen und Attribute weglassen
spec-id: SR-169
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-02: Lieferungen mit vielen Typen und Attributen, oft ohne LONG-NAME, sollen sich importieren lassen, ohne jeden nicht gebrauchten Eintrag einzeln wegzulassen (#573)."
requirement-type: functional
acceptance-criteria:
  - "Gegeben eine Zuordnung, die alles Nicht-Genannte weglässt (zum Beispiel `omit-others: true`), über `reqseq reqif save-mapping` oder in der YAML-Datei, und eine Lieferung mit SPEC-OBJECT-TYPEs, SPEC-RELATION-TYPEs und Attributen, die die Zuordnung nicht nennt, wenn sie mit `reqseq reqif analyze export.reqif --mapping reqif/doors.yaml` gelesen oder importiert wird, dann listet das Tool keinen davon als ohne Zuordnung, und der Import lehnt nicht mit `reqif.unmapped` ab."
  - "Gegeben dieselbe Zuordnung und Lieferung, wenn sie gelesen oder importiert wird, dann meldet das Tool in der Ausgabe von Analyse und Import jedes so weggelassene Attribut, SPEC-OBJECT und jede so weggelassene SPEC-RELATION als Verlust, wie bei einem Eintrag mit `omit: true` (SR-053)."
  - Gegeben eine solche Zuordnung, die ein Attribut einer Auswahl-Property zuordnet, wenn ein Wert seiner Aufzählung weder zugeordnet noch weggelassen ist, dann listet das Tool den Wert nach SR-055 als ohne Zuordnung; das Weglassen des Nicht-Genannten gilt nur für Typen und Attribute.
  - Gegeben eine Zuordnung, die das Weglassen des Nicht-Genannten nicht festlegt, wenn eine Lieferung mit nicht genannten Typen oder Attributen gelesen oder importiert wird, dann listet das Tool sie nach SR-055 als ohne Zuordnung.
  - Gegeben dieselbe Datei und dieselbe Zuordnung, wenn die Analyse oder der Import über App, Kommandozeile, API oder MCP ausgeführt wird, dann liefert das Tool dasselbe Ergebnis.

Das Tool muss eine Zuordnung annehmen, die festlegt, dass jeder Typ und jedes Attribut der Quelle, das sie nicht nennt, weggelassen wird, und das so Weggelassene als Verlust melden.

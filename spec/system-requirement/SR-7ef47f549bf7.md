title: Lokale Pfade über API und MCP-Server auf die Repositories begrenzen
spec-id: SR-142
rationale: "Entscheidung des Produktverantwortlichen, 2026-10-29: Ein Agent soll über API oder MCP-Server keine Dateien außerhalb des Arbeitsbereichs lesen oder schreiben können, etwa durch Anweisungen, die in Element-Texten versteckt sind. Die Kommandozeile behält freie Pfade, weil zum Beispiel eine Pipeline in einen Zielordner außerhalb schreibt (SR-062). Das ist eine Ausnahme zu SR-080 AK2."
requirement-type: constraint
acceptance-criteria:
  - Gegeben ein lokaler Pfad außerhalb der Repositories des Arbeitsbereichs, wenn ein Befehl ihn über API oder MCP-Server zum Lesen oder Schreiben erhält, dann lehnt das Tool den Befehl ab, nennt den Grund und liest oder schreibt nichts.
  - Gegeben ein lokaler Pfad innerhalb eines Repositories des Arbeitsbereichs, wenn ein Befehl ihn über API oder MCP-Server erhält, dann führt das Tool den Befehl aus.
  - Gegeben derselbe Pfad außerhalb der Repositories, wenn der Befehl über die Kommandozeile ausgeführt wird, dann nimmt das Tool ihn an.

requirement-type: functional
acceptance-criteria:
  - Gegeben eine Überschrift im Text, wenn der Abschnitt mit dem Befehl „Fold section“ oder per Klick auf ein Zeichen zum Einklappen eingeklappt wird, das nur links der Überschrift erscheint, solange der Mauszeiger über ihr steht, dann zeigt der Editor bis zur nächsten Überschrift derselben oder höheren Ebene nur einen dezenten Hinweis auf den verborgenen Text, und die Datei bleibt unverändert.
  - Gegeben ein eingeklappter Abschnitt, wenn er mit „Unfold section“ oder einem Klick auf den Hinweis ausgeklappt oder der Cursor hineinbewegt wird, dann ist der Text wieder sichtbar.
  - Gegeben ein Text mit Überschriften, wenn der Befehl „Go to heading“ aufgerufen wird, dann bietet die Befehlszeile die Überschriften mit unscharfer Suche an, und die Wahl setzt den Cursor dorthin.

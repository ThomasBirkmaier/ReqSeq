  - "Gegeben ein Element, wenn es abgelöst wird, dann setzt das Tool den gewählten als ungültig gekennzeichneten Status und auf Wunsch am Nachfolger eine Beziehung Supersedes auf das abgelöste Element."
  - Gegeben ein abgelöstes Element, wenn Beziehungen einer Beziehungsart aus Elementen ohne ungültigen Status darauf bestehen, dann zeigt das Tool zu jeder einen Hinweis, außer zur Beziehung Supersedes, die ein Nachfolger auf das abgelöste Element hat; Verweise und Properties mit Wertart Beziehung bekommen diesen Hinweis nicht.
  - "Gegeben ein abgelöstes Element mit Nachfolger, wenn es angezeigt wird, dann nennt das Tool jeden Nachfolger, ohne dass das abgelöste Element eine eigene Beziehung darauf hat."

Das Tool muss ein Element ablösen lassen, indem es einen als ungültig gekennzeichneten Status setzt und auf Wunsch am Nachfolger eine Beziehung Supersedes auf das abgelöste Element setzt.

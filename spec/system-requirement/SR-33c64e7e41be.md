title: Fundstelle im Suchtreffer zeigen
spec-id: SR-174
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-05: Wunsch im Paket Später geparkt. Ein Treffer soll sich beurteilen lassen, ohne jedes gefundene Element einzeln zu öffnen. Entscheidung des Produktverantwortlichen, 2026-11-07: Der Ausschnitt ist eine Zeile von höchstens 120 Zeichen mit hervorgehobener Fundstelle, einer je Treffer an der ersten Fundstelle, keiner für Treffer nur im Titel oder in einer ID; er kommt immer, über alle Zugänge gleich, und SR-098 gilt weiter."
requirement-type: functional
acceptance-criteria:
  - Gegeben ein Suchbegriff, der im Text eines Elements gefunden wird, wenn gesucht wird (zum Beispiel `reqseq element search "Fundstelle"`), dann nennt das Tool beim Treffer den Text als Fundort und zeigt eine Zeile von höchstens 120 Zeichen aus dem sichtbaren Text ohne Markdown-Zeichen, die die Fundstelle enthält und hervorhebt.
  - Gegeben ein Suchbegriff, der nur in einer Property gefunden wird, wenn gesucht wird, dann nennt das Tool beim Treffer die Property und zeigt eine Zeile von höchstens 120 Zeichen aus ihrem Wert, die die Fundstelle enthält und hervorhebt; hat die Property mehrere Werte, stammt der Ausschnitt aus dem Wert mit der Fundstelle.
  - "Gegeben die Suchbegriffe werden an mehreren Stellen eines Elements gefunden, wenn gesucht wird, dann zeigt das Tool genau einen Ausschnitt je Treffer, an der ersten Fundstelle: im Text, wenn sie dort vorkommt, sonst in der ersten Property in der Reihenfolge des Metamodells."
  - Gegeben ein Suchbegriff, der nur im Titel oder in einer ID gefunden wird, wenn gesucht wird, dann zeigt das Tool beim Treffer keinen Ausschnitt; ein Treffer im Titel ist im Titel hervorgehoben.
  - Gegeben dieselbe Suche, wenn sie über App, Kommandozeile, API oder MCP ausgeführt wird, dann liefert das Tool dieselben Treffer mit denselben Fundorten und Ausschnitten.

Das Tool muss zu jedem Suchtreffer im Text oder in einer Property nennen, wo gefunden wurde, und einen kurzen Ausschnitt um die Fundstelle zeigen.

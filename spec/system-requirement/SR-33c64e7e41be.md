  - Gegeben ein Suchbegriff, der im Text eines Elements vorkommt, wenn gesucht wird, dann zeigt das Tool beim Treffer das Feld und einen kurzen Ausschnitt des Textes, der den Begriff enthält.
  - Gegeben ein Suchbegriff, der nur in einer Property vorkommt, wenn gesucht wird, dann nennt das Tool beim Treffer die Property und zeigt einen kurzen Ausschnitt ihres Werts, der den Begriff enthält.

title: Bilder in der Vorschau zeigen
spec-id: SR-184
requirement-type: functional
acceptance-criteria:
  - Gegeben ein Bild im Text, das relativ auf eine Datei im Arbeitsbereich verweist, wenn der Cursor nicht in seiner Zeile steht, dann zeigt der Editor das Bild an Stelle des Quelltexts, höchstens so breit wie die Textspalte.
  - Gegeben der Cursor steht in der Zeile des Bildes, wenn der Text angezeigt wird, dann ist der Quelltext sichtbar und das Bild steht darunter.
  - Gegeben ein Bild, dessen Adresse ins Netz, aus dem Arbeitsbereich hinaus oder auf eine data:-Adresse zeigt, wenn der Text angezeigt wird, dann lädt das Tool nichts und zeigt den Quelltext mit einem dezenten Hinweis.
  - Gegeben die Bilddatei fehlt oder ist kein lesbares Bild, wenn der Text angezeigt wird, dann zeigt der Editor den Quelltext mit einem dezenten Hinweis.

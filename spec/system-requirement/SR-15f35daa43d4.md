title: Anlegen und Ändern zur Probe
spec-id: SR-246
rationale: Eine Oberfläche oder ein Agent zeigt die Befunde vor dem Speichern, ohne eine Datei zu schreiben und wieder zurückzunehmen. Die Probe ist eine Angabe am Befehl und nicht wie bei der Mehrfachänderung (SR-071) der Normalfall, weil vorhandene Aufrufe von Anlegen und Ändern weiter schreiben sollen. Fehler, die erst beim Schreiben entstehen, etwa ein voller Datenträger, kann eine Probe nicht zeigen. ID, Kurz-ID und Datei, die eine Probe des Anlegens nennt, bekommt ein späteres Anlegen nicht, weil es eine neue UUID vergibt (SR-002).
requirement-type: functional
acceptance-criteria:
  - key: x516
    text: "Gegeben ein Arbeitsbereich, wenn ein Element zur Probe angelegt oder geändert wird (CLI, API, MCP: `element.create`, `element.update`), dann ist danach jede Datei und jeder Ordner in den Repositories des Arbeitsbereichs unverändert, kein Ordner ist neu, und `element.list` und `element.get` liefern dasselbe wie vor der Probe."
  - key: x4c8
    text: Gegeben eine Eingabe, die der Befehl ohne Probe ablehnt, bevor er schreibt, zum Beispiel eine ungültige Eingabe (D-012), ein erwarteter Prüfwert, der nicht zum Inhalt der Datei passt (SR-166 AK2), oder ein Schreibbefehl, den das Tool ablehnt (SR-011 AK3 und AK4), wenn sie zur Probe ausgeführt wird, dann lehnt das Tool sie mit demselben Fehler ab.
  - key: pwg2
    text: Gegeben eine Eingabe, die der Befehl ohne Probe annimmt, wenn sie zur Probe ausgeführt wird, dann nennt die Ausgabe das Element, die Befunde und beim Ändern die Zahl der direkt betroffenen Elemente (SR-024 AK2) wie ohne Probe.
  - key: y5vf
    text: Gegeben eine Eingabe, die der Befehl ohne Probe annimmt, wenn sie zur Probe ausgeführt wird, dann ist die Ausgabe als Probe gekennzeichnet, nennt die Dateien, die der Befehl schreiben würde (beim Anlegen die Datei in dem Ordner, in dem das Anlegen ohne Probe sie anlegt, SR-064 AK5; bei einer Änderung, die nichts ändert, keine), und keine geschriebene Datei, und der Antwortsatz sagt, dass nichts geschrieben wurde.
  - key: wy8y
    text: Gegeben ein Element wird zur Probe geändert, dann nennt die Ausgabe den Prüfwert der Datei, wie sie gelesen wurde; ein folgendes Ändern ohne Probe, das diesen Prüfwert erwartet, lehnt das Tool nicht wegen des Prüfwerts ab.
  - key: tcxn
    text: Gegeben ein Element wird zur Probe angelegt, wenn danach nach der ID, der Kurz-ID oder der Datei gefragt wird, die die Ausgabe nennt, dann gibt es im Arbeitsbereich kein solches Element.
  - key: jbkb
    text: Gegeben ein Element wird zur Probe mit der Angabe angelegt, die folgende Kennung zu vergeben (SR-245), dann nennt die Ausgabe die Kennung, die das Anlegen ohne Probe in diesem Augenblick vergäbe.
  - key: skjx
    text: Gegeben eine Probe über die lokale API oder den MCP-Server, wenn danach `workspace.activity` abgefragt wird, dann nennt es nach einer Probe des Änderns das Element als gelesen, nicht als geändert, und nach einer Probe des Anlegens denselben Zugriff wie davor, ohne früheren Zugriff keinen.

Das [Tool](reqseq:6ad4f973-fdb9-461f-8dc4-b73619ba1dac?version=n2:2427cdd2079ee312) muss das Anlegen und das Ändern eines [Elements](reqseq:6ad4f967-cd5c-4742-9496-c32698d7e56d?version=n2:5b3b2eb814e1b440) auf Wunsch zur [Probe](reqseq:f3bb8284-a03c-485f-bcf2-9d465bf2a570?version=n2:979ab944c9b6ec1e) ausführen: mit allen Prüfungen und der Ausgabe des Befehls, ohne in einem [Repository](reqseq:62da75c7-9827-47d1-9566-5bf509291b94?version=n2:a0761b06955a7b20) des [Arbeitsbereichs](reqseq:6adc68be-cdfe-4197-a3a9-4c86ffa232a7?version=n2:1fbe0ef1dbe8ddc1) eine Datei oder einen Ordner anzulegen oder zu ändern.

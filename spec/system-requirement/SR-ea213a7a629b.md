title: Referenz für jede Funktion in allen Zugängen
spec-id: SR-139
rationale: Annahme der Doku-Strategie mit einer Dokumentation für Nutzer, die erzeugt und geprüft wird, und ihrer Aufnahme in die Spezifikation als Need mit wenigen System Requirements. Die Referenz listet auch die Tastenkürzel der App mit ihrer Wirkung, aus der Tastenbelegung erzeugt. Das Akzeptanzkriterium hat er auf einer Entscheidungskarte angenommen.
requirement-type: functional
acceptance-criteria:
  - Gegeben eine Funktion des Tools, wenn ihre Referenzseite geöffnet wird, dann zeigt sie Titel, Zusammenfassung, Eingaben und Ausgaben sowie den Aufruf in App, Kommandozeile, API und MCP.
  - Gegeben ein Befund oder ein Fehler eines Befehls, wenn sein Code in der Referenz nachgeschlagen wird, dann nennt die Referenz Ursache und Abhilfe.
  - Gegeben die Dateiformate und das Standardmodell des Tools, wenn die Referenz geöffnet wird, dann beschreibt sie jedes Dateiformat sowie jeden Elementtyp, jede Property, jede Beziehungsart und jeden Statuswert des Standardmodells.
  - Gegeben eine geänderte Beschreibung einer Funktion, eines Befunds oder Fehlers, eines Dateiformats oder des Standardmodells, wenn die Dokumentation gebaut wird, dann zeigt die Referenz die geänderte Beschreibung, ohne dass eine Seite von Hand geändert wird.
  - Gegeben die Tastenkürzel der App, wenn die Referenz geöffnet wird, dann zeigt sie jedes Kürzel für Windows und Linux sowie für macOS mit seiner Wirkung, und ein geändertes Kürzel erscheint nach dem nächsten Bau der Dokumentation, ohne dass eine Seite von Hand geändert wird.
  - Gegeben ein Befehl, den es nur in der App gibt (SR-080 AK1), wenn die Referenz geöffnet wird, dann nennt die Tastenreferenz der Dokumentation ihn mit seinem Namen und, wenn er eines hat, seinem Kürzel.

Das Tool muss eine Referenz mitliefern, die für jede Funktion den Aufruf in App, Kommandozeile, API und MCP auf einer Seite zeigt, jeden Befund und jeden Fehler eines Befehls mit Ursache und Abhilfe erklärt, die Dateiformate und das Standardmodell beschreibt und die Tastenkürzel der App mit ihrer Wirkung auflistet. Die Referenz wird aus den Beschreibungen erzeugt, die das Tool selbst verwendet.

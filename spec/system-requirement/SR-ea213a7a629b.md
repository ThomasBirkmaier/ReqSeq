Das Tool muss eine Referenz mitliefern, die für jede Funktion den Aufruf in App, Kommandozeile, API und MCP auf einer Seite zeigt, jede Prüfmeldung mit Ursache und Abhilfe erklärt, die Dateiformate und das Standardmodell beschreibt und die Tastenkürzel der App mit ihrer Wirkung auflistet. Die Referenz wird aus den Beschreibungen erzeugt, die das Tool selbst verwendet.

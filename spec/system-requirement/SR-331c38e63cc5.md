    text: Gegeben ein Element, wenn seine betroffenen Elemente abgefragt werden, dann liefert das Tool alle Elemente, die direkt oder über die Kette eine Beziehung oder einen Verweis darauf haben, mit Weg und Abstand.

    text: "Gegeben ein Element wurde inhaltlich geändert, wenn es gespeichert wird, dann zeigt das Tool die Zahl der direkt betroffenen Elemente an (App: Meldung nach dem Speichern, nach automatischem Speichern einmal und erst wieder, wenn sich die Zahl ändert, und nach Ctrl+S, unter macOS Cmd+S, jedes Mal; CLI, API, MCP: im Ergebnis von `element.update`)."
  - key: jt0q
    text: Gegeben eine Änderung nur an Status oder Titel, wenn das Element gespeichert wird, dann zeigt das Tool keine betroffenen Elemente an.
  - key: vzjd
    text: Gegeben Datensätze zur alten Fassung eines geänderten Requirements, wenn die betroffenen Elemente abgefragt werden, dann erscheinen auch diese Datensätze.

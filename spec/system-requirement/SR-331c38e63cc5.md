title: "Betroffene Elemente einer Änderung zeigen"
spec-id: "SR-024"
requirement-type: functional
acceptance-criteria:
  - "Gegeben ein Element, wenn seine betroffenen Elemente abgefragt werden, dann liefert das Tool alle Elemente, die direkt oder über die Kette eine Beziehung oder einen Verweis darauf haben, mit Weg und Abstand."
  - "Gegeben ein Element wurde inhaltlich geändert, wenn es gespeichert wird, dann zeigt das Tool die Zahl der direkt betroffenen Elemente an."
  - "Gegeben eine Änderung nur an Status oder Titel, wenn das Element gespeichert wird, dann zeigt das Tool keine betroffenen Elemente an."
  - "Gegeben Datensätze zur alten Fassung eines geänderten Requirements, wenn die betroffenen Elemente abgefragt werden, dann erscheinen auch diese Datensätze."

Wenn ein Element inhaltlich geändert wird, muss das Tool alle Elemente zeigen, die von der Änderung betroffen sind.

acceptance-criteria:
  - Gegeben eine Pipeline ruft die Kommandozeile mit einem Zielordner auf, wenn sie läuft, dann schreibt sie eine Datei im Format JSON Lines mit einem Element je Zeile. Ihr Name enthält den Commit des Haupt-Repositorys, mit dem Zusatz `-dirty`, außer jedes vorhandene Repository hat einen bekannten Commit und keine Änderungen ohne Commit an den Dateien, aus denen die Daten stammen. Die Datei nennt den Commit jedes vorhandenen Repositorys und kennzeichnet, wenn ein Repository des Arbeitsbereichs auf diesem Rechner fehlt. Eine vorhandene Datei dieses Namens ersetzt sie nur, wenn es eine Datei der Daten je Stand ist, sonst lehnt sie ab. Hat das Haupt-Repository keinen Commit, etwa ohne Git, schreibt sie nichts und meldet das.
  - "Gegeben mehrere solche Dateien, wenn ein externes Werkzeug sie liest, dann kann es sie ohne Zugriff auf das Tool auswerten."

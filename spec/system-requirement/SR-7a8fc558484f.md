  - key: tfcb
    text: Gegeben ein Element wird bearbeitet, wenn eine Beziehung gesetzt wird, dann bietet das Tool nur Beziehungsarten an, die das Metamodell für diesen Typ erlaubt.
  - key: bcvf
    text: Gegeben eine Beziehungsart ist gewählt, wenn das Ziel gesucht wird, dann zeigt die Suche nur Elemente erlaubter Ziel-Typen.
  - key: skrd
    text: Gegeben eine Beziehung würde einen Zyklus in den Ableitungen bilden, wenn sie gesetzt wird, dann speichert das Tool sie und zeigt einen Hinweis, der jedes Element des Zyklus mit der Zeile seiner Beziehung nennt.
  - key: r039
    text: "Gegeben eine Beziehung, deren Art das Metamodell für den Typ der Quelle oder des Ziels nicht erlaubt, wenn sie gesetzt werden soll (App, CLI, API, MCP: `relation.add`, `element.create`), dann lehnt das Tool das ab, nennt Quelle, Ziel und Beziehungsart und schreibt nichts."
  - key: q66b
    text: "Gegeben ein Element mit einer Beziehung, wenn sie entfernt wird (App, CLI, API, MCP: `relation.remove`), dann fehlt sie in der Datei der Quelle, und sonst ändert sich nichts."
  - key: fcfh
    text: "Gegeben zwei Elemente, wenn eine Beziehung mit einem von beiden als Quelle gesetzt wird (App, CLI, API, MCP: `relation.add`), auch wenn in der App das andere geöffnet ist, dann steht sie in der Datei der Quelle, und keine andere Datei ist geändert."

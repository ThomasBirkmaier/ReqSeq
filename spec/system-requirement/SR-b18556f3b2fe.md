title: Properties als Boxen bearbeiten
spec-id: SR-104
requirement-type: functional
acceptance-criteria:
  - Gegeben ein geöffnetes Element, wenn es angezeigt wird, dann erscheint jede gefüllte Property als Box unter dem Text und keine leere.
  - Gegeben ein Typ mit einer Property, die am Element fehlt, wenn sie per Befehlszeile oder Kürzel hinzugefügt wird, dann erscheint eine leere Box mit dem Cursor darin.
  - Gegeben eine Property mit festen Werten im Metamodell, wenn sie bearbeitet wird, dann bietet die Vervollständigung nur diese Werte an.
  - Gegeben eine Box wird geleert, wenn gespeichert wird, dann entfernt das Tool die Property aus der Datei und die Box verschwindet.

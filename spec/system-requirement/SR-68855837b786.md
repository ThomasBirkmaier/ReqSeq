title: Version, Build und Arbeitsbereich abfragen
spec-id: SR-161
rationale: Ein Befehl soll die wichtigen Angaben zum Tool an einer Stelle bündeln, etwa für einen Fehlerbericht. Der Befehl heißt „About ReqSeq“ statt „Show tool info“, weil man ihn unter diesem Namen aus anderen Werkzeugen kennt. Die Liste der Angaben in AK1 und AK2 ist bestätigt.
requirement-type: functional
acceptance-criteria:
  - key: hbxy
    text: "Gegeben eine Installation, wenn „About ReqSeq“ aufgerufen wird (CLI, API, MCP: `tool.info`), dann liefert das Tool die Version der Kommandozeile und des MCP-Servers, den Build mit Commit, Build-Datum, Plattform und Architektur, die Version von Node und den geöffneten Arbeitsbereich mit Pfad, Namen, Repositories und Zahl der Elemente."
  - key: ttck
    text: Gegeben die Ausgabe von „About ReqSeq“, wenn sie geliefert wird, dann nennt sie auch den Lizenzhinweis des Tools und die Lizenzen der mitgelieferten Fremdkomponenten, verweist auf die mitgelieferte Dokumentation (SR-141) und nennt die Adressen der Online-Dokumentation und der Releases nur als Text, ohne eine Netzverbindung zu öffnen.
  - key: x2b3
    text: Gegeben eine Auslieferung, wenn der Befehl „About ReqSeq“ aufgerufen wird, dann ist die gelieferte Version die Version dieser Auslieferung.
  - key: r14d
    text: Gegeben die Angaben von „About ReqSeq“ außer dem Pfad des Arbeitsbereichs, wenn sie über Kommandozeile, API oder MCP-Server derselben Installation abgefragt werden, dann liefert das Tool in allen Zugängen dieselben Werte (D-029).

Das Tool muss einen Befehl „About ReqSeq“ bieten, der die Version des Tools, seinen Build und den geöffneten Arbeitsbereich an einer Stelle liefert.

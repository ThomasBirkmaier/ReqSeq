Das Tool muss Filter mit Namen als Datei im Repository speichern. Wird ein Filter unter einem Namen gespeichert, den es schon gibt, ersetzt er diesen Filter; das Tool schreibt nur die geänderten Angaben, Kommentare und alles andere bleiben stehen. Namen von Filtern vergleicht das Tool ohne Rücksicht auf Groß- und Kleinschreibung und Unicode-Normalform; die Datei behält den Namen, wie er zuletzt gespeichert wurde.

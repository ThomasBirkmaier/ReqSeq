Das Tool muss Filter mit Namen als Datei im Repository speichern. Wird ein Filter unter einem Namen gespeichert, den es schon gibt, ersetzt er diesen Filter; das Tool ändert nur die Zeilen der geänderten Angaben, Kommentare auf unveränderten Zeilen und alles andere bleiben stehen. Namen von Filtern vergleicht das Tool ohne Rücksicht auf Groß- und Kleinschreibung und Unicode-Normalform; in der Datei steht der Name, wie er zuletzt gespeichert wurde.

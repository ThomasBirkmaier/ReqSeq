title: Titel aus mehreren Attributen der Quelle
spec-id: SR-167
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-02: Werkzeuge wie StrictDoc, DOORS und Polarion legen Überschriften in `ReqIF.ChapterName` und Requirements in `ReqIF.Name` im selben SPEC-OBJECT-TYPE ab; eine Zuordnung soll deshalb mehrere Attribute für den Titel nennen können (#573)."
requirement-type: functional
acceptance-criteria:
  - Gegeben eine Zuordnung, die für den Titel zuerst `ReqIF.ChapterName` und dann `ReqIF.Name` nennt, über `reqseq reqif save-mapping` oder in der YAML-Datei, und eine Lieferung, in der ein SPEC-OBJECT nur `ReqIF.ChapterName` und ein anderes desselben Typs nur `ReqIF.Name` mit Wert hat, wenn sie importiert wird (zum Beispiel `reqseq reqif import --file sample2.reqif --mapping reqif/strictdoc.yaml --delivery "Lieferung 1"`), dann ist der Titel des ersten Elements der Wert von `ReqIF.ChapterName` und der des zweiten der Wert von `ReqIF.Name`.
  - Gegeben ein SPEC-OBJECT, das mehrere der genannten Attribute mit Wert hat, wenn importiert wird, dann ist sein Titel der Wert des Attributs, das die Zuordnung zuerst nennt, und das Tool meldet jedes weitere dieser Attribute mit Wert als Verlust (SR-053).
  - Gegeben ein SPEC-OBJECT, bei dem keines der genannten Attribute einen Wert hat, wenn importiert wird, dann bekommt das Element denselben Titel wie bei einer Zuordnung ohne Attribut für den Titel.
  - Gegeben dieselbe Datei und dieselbe Zuordnung, wenn der Import über App, Kommandozeile, API oder MCP ausgeführt wird, dann liefert das Tool dasselbe Ergebnis.

Das Tool muss in einer Zuordnung für den Titel mehrere Attribute der Quelle in einer Reihenfolge annehmen und den Titel jedes Elements aus dem ersten dieser Attribute übernehmen, das einen Wert hat.

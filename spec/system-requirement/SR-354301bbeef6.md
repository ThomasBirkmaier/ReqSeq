title: Einen Agent über MCP anschließen
spec-id: SR-227
rationale: Der Anschluss an einen Agent war nur mit handgeschriebenem JSON und absoluten Pfaden möglich. Die Liste der Clients ist fest; ein weiterer ist eine Spec-Änderung. Die genauen Vorlagen sind Daten des Tools; ihr Format wird gegen die Dokumentation der Clients geprüft.
requirement-type: functional
acceptance-criteria:
  - key: gvt5
    text: Gegeben der Befehl „Connect AI agent“, wenn er aufgerufen wird, dann wählt man den Client aus Claude Code, Claude Desktop, Cursor, VS Code, Codex CLI und Other, in der App als Schritt mit festen Werten (SR-215), sonst als Angabe; ohne Client nennt die Ausgabe die möglichen Werte.
  - key: fx6t
    text: Gegeben ein gewählter Client, wenn die Ausgabe gezeigt wird, dann ist sie für Claude Code, VS Code und Codex CLI ein Befehl für das Terminal, unter Windows für PowerShell, für Claude Desktop und Cursor ein JSON-Block mit dem Ort der Datei je System, in den er gehört, und für Other ein JSON-Block im allgemeinen Format `mcpServers` ohne Ort. Für Claude Code nennt sie darunter den Aufruf, der die Skill-Datei schreibt (SR-229 AK8).
  - key: cw0k
    text: Gegeben die Ausgabe, wenn sie gezeigt wird, dann nennt sie den absoluten Pfad des Startprogramms der Installation, die den Befehl ausführt, und den absoluten Pfad des Arbeitsbereichs, unter Windows in der Form mit `ReqSeq.exe`, `bin.js` und `ELECTRON_RUN_AS_NODE`, und sagt, dass der Aufruf gilt, solange das Tool an diesem Ort liegt; zwei Installationen liefern verschiedene Pfade (wie SR-161 AK5).
  - key: wvgw
    text: Gegeben die App läuft unter macOS von einem Ort, den das System nur für diesen Start vergibt, weil sie nicht verschoben wurde, wenn der Befehl ausgeführt wird, dann gibt er keinen Aufruf aus und sagt, die App zuerst nach `/Applications` zu verschieben.
  - key: qxzf
    text: Gegeben die Ausgabe für einen Client, wenn das darin genannte Programm mit den genannten Argumenten und Umgebungsvariablen gestartet wird, dann beantwortet der MCP-Server für diesen Arbeitsbereich `initialize`.
  - key: nq91
    text: Gegeben der Befehl, wenn er ausgeführt wird, dann legt er keine Datei an, ändert keine, auch keine des Clients, und baut keine Verbindung auf (SR-078).
  - key: cxxc
    text: "Gegeben die App, wenn der Client gewählt ist, dann zeigt sie die Ausgabe als Buffer (D-078): den [Antwortsatz](reqseq:d249a00b-83d2-4c62-b42a-f2c929b5ce27?version=n2:9e00b6ad928fc47b), darunter den Befehl oder JSON-Block, den „Copy field“ in die Zwischenablage legt, und den Satz, wie es weitergeht."

Das Tool muss für einen gewählten [Client](reqseq:7ecb6c50-e26f-4fde-a60b-540a5e33ddc4?version=n2:2a8258e3bd617d85) ausgeben, wie dieser den MCP-Server des Tools für den [Arbeitsbereich](reqseq:6adc68be-cdfe-4197-a3a9-4c86ffa232a7?version=n2:1fbe0ef1dbe8ddc1) startet, mit eingesetzten absoluten Pfaden, und dabei keine Datei anlegen oder ändern.

title: Einen Agent über MCP anschließen
spec-id: SR-227
rationale: Der Anschluss an einen Agent war nur mit handgeschriebenem JSON und absoluten Pfaden möglich. Die Liste der Clients ist fest; ein weiterer ist eine Spec-Änderung. Die genauen Vorlagen sind Daten des Tools; ihr Format wird gegen die Dokumentation der Clients geprüft. Der Eintrag für `.mcp.json` (AK7) dient Git-Repositories, die auf Rechnern ausgecheckt werden, auf denen ReqSeq erst danach installiert wird und der Pfad der Installation vorher nicht feststeht, etwa einem Cloud-Container mit Setup-Skript; die Einrichtung mit absoluten Pfaden bleibt daneben bestehen. Die Dokumentation von Claude Code legt das Arbeitsverzeichnis des gestarteten Servers nicht fest; der Eintrag setzt darum voraus, dass Claude Code im Ordner der Datei startet. Auch die Form für Windows (`cmd /c`) ist aus dem Verhalten des Starters abgeleitet, nicht aus der Dokumentation von Claude Code.

    text: Gegeben ein gewählter Client, wenn die Ausgabe gezeigt wird, dann ist sie für Claude Code, VS Code und Codex CLI ein Befehl für das Terminal, unter Windows für PowerShell, für Claude Desktop und Cursor ein JSON-Block mit dem Ort der Datei je System, in den er gehört, und für Other ein JSON-Block im allgemeinen Format `mcpServers` ohne Ort. Für Claude Code, Cursor, VS Code, Codex CLI und Other nennt sie darunter den Aufruf, der die Skill-Datei schreibt (SR-229 AK8), als Befehl für das Terminal, unter Windows für PowerShell; für Claude Desktop nennt sie ihn nicht.
  - key: cw0k
    text: Gegeben die Ausgabe, wenn sie gezeigt wird, dann nennt sie, außer im Eintrag nach AK7, den absoluten Pfad des Startprogramms der Installation, die den Befehl ausführt, und den absoluten Pfad des Arbeitsbereichs, unter Windows statt des Startprogramms den absoluten Pfad von `runtime\node.exe` der Installation mit dem absoluten Pfad von `lib\dist\bin.js` als erstem Argument, ohne Umgebungsvariable, und sagt, dass der Aufruf gilt, solange das Tool an diesem Ort liegt; zwei Installationen liefern verschiedene Pfade (wie SR-161 AK4).
  - key: wvgw
    text: Gegeben die [Desktop-Hülle](reqseq:8cde6c0b-d69c-4972-b892-af0dbfa92a09?version=n2:4a161bba37dcff33) läuft unter macOS von einem Ort, den das System nur für diesen Start vergibt, weil sie nicht verschoben wurde, wenn der Befehl aus ihrer Installation ausgeführt wird, dann gibt er keinen Aufruf aus und sagt, die Desktop-Hülle zuerst nach `/Applications` zu verschieben.
  - key: qxzf
    text: Gegeben die Ausgabe für einen Client, wenn das darin genannte Programm mit den genannten Argumenten und Umgebungsvariablen gestartet wird, bei jeder Form des Eintrags nach AK7 auf einem System, für das sie gilt, in dem Ordner, den AK7 nennt, und mit dem Startprogramm dieser Installation als `reqseq` im Suchpfad, dann beantwortet der MCP-Server für diesen Arbeitsbereich `initialize`.
  - key: nq91
    text: Gegeben der Befehl, wenn er ausgeführt wird, dann legt er keine Datei an, ändert keine, auch keine des Clients, und baut keine Verbindung auf (SR-078).
  - key: bq8m
    text: Gegeben der Client Claude Code, wenn die Ausgabe gezeigt wird, dann nennt sie zusätzlich zum Befehl nach AK2 einen Eintrag für die Datei `.mcp.json` in der Wurzel des Git-Repositorys, ohne Git im Ordner des Arbeitsbereichs, wie D-079 diesen Ordner für die Skill-Datei bestimmt, und diesen Ordner außerhalb des Eintrags mit seinem absoluten Pfad. Der Eintrag startet `reqseq` ohne Pfad mit `mcp`, `--workspace` und dem Pfad des Arbeitsbereichs relativ zu diesem Ordner, mit `/` als Trennzeichen und `.` für den Ordner selbst, ohne Umgebungsvariable. Die Ausgabe nennt den Eintrag zweimal, je als vollständiges JSON-Objekt mit `mcpServers` und darin `reqseq`, und kennzeichnet, welches für macOS und Linux gilt und welches für Windows; das für Windows startet `cmd` mit `/c` und `reqseq` als ersten Argumenten. Enthält der relative Pfad ein Leerzeichen oder eines der Zeichen `&`, `^`, `%`, `<`, `>`, `|`, `!`, `"`, `(`, `)`, `,`, `;`, `=` oder `\`, fehlt das für Windows, und die Ausgabe sagt warum. Sie sagt, wofür der Befehl nach AK2 passt (diese Installation auf diesem Rechner) und wofür der Eintrag (ein Git-Repository, das auf Rechnern ausgecheckt wird, auf denen `reqseq` im Suchpfad liegt und Claude Code in diesem Ordner startet), dass der Server aus dem Eintrag auf einem Rechner ohne `reqseq` im Suchpfad nicht startet und dort der Befehl nach AK2 gilt, dass der Eintrag einen vorhandenen Server namens `reqseq` in der Datei ersetzt und die übrigen bleiben, und dass ein zweiter Arbeitsbereich im selben Git-Repository einen anderen Namen braucht. In der Lage von AK4 nennt sie auch den Eintrag nicht.

Das Tool muss für einen gewählten [Client](reqseq:7ecb6c50-e26f-4fde-a60b-540a5e33ddc4?version=n2:2a8258e3bd617d85) ausgeben, wie dieser den MCP-Server des Tools für den [Arbeitsbereich](reqseq:6adc68be-cdfe-4197-a3a9-4c86ffa232a7?version=n2:1fbe0ef1dbe8ddc1) startet, mit eingesetzten absoluten Pfaden, für Claude Code zusätzlich als Eintrag ohne absolute Pfade für die Datei `.mcp.json` des Git-Repositorys, in dem der Arbeitsbereich liegt, und dabei keine Datei anlegen oder ändern.

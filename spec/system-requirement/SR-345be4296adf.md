requirement-type: functional
acceptance-criteria:
  - Gegeben eine Baseline, deren festgehaltene Fassungen dem Inhalt der Elemente beim festgehaltenen Commit entsprechen, wenn die Baseline geprüft wird, dann meldet das Tool kein Element.
  - Gegeben ein Element, dessen in der Baseline festgehaltene Fassung von der Fassung seines Inhalts beim festgehaltenen Commit seines Repositories abweicht, wenn die Baseline geprüft wird, dann meldet das Tool dieses Element mit seiner ID, der festgehaltenen Fassung und der Fassung beim Commit.
  - Gegeben dieselbe Baseline, wenn sie über App, CLI, API oder MCP-Server geprüft wird, dann ist das Ergebnis überall gleich (D-029).

Das Tool muss eine Baseline prüfen, indem es für jedes Element die in der Baseline festgehaltene Fassung gegen seinen Inhalt beim festgehaltenen Commit seines Repositories neu berechnet, und jedes Element melden, dessen festgehaltene Fassung nicht übereinstimmt.

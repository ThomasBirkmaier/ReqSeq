  - Gegeben ein Export mit einer Liste wegzulassender Properties (zum Beispiel eine Property wie `comment` für interne Kommentare), wenn er erstellt wird, dann fehlen diese Properties in der Datei.

  - "Gegeben die wegzulassenden Properties, wenn sie festgelegt werden, dann speichert das Tool sie in der Zuordnung der Quelle (SR-054) und verwendet sie bei späteren Lieferungen wieder."

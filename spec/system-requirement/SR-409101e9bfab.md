title: Feld mit einem Griff kopieren
spec-id: SR-128
rationale: "Entscheidung des Produktverantwortlichen, 2026-10-26: Jedes Feld soll sich schnell kopieren lassen; zur Wahl standen Kopieren per Klick auf das Feld, ein ganz dezenter Knopf neben jedem Feld oder ein Kontextmenü. Gewählt ist der dezente Knopf mit einem Befehl dazu: Ein einfacher Klick setzt den Cursor zum Bearbeiten und kopiert daher nicht, ein Kontextmenü widerspräche der Grundregel des weißen Blatts."
requirement-type: functional
acceptance-criteria:
  - Gegeben ein geöffnetes Element, wenn der Mauszeiger über einem Feld steht oder der Fokus darin liegt, zum Beispiel Titel, Kurz-ID, Text oder eine Property-Box, dann erscheint am rechten Rand des Feldes ein sehr dezentes Symbol zum Kopieren, sonst ist es nicht zu sehen.
  - Gegeben das Symbol zum Kopieren wird angeklickt, wenn danach an anderer Stelle eingefügt wird, dann wird der Wert des Feldes als Text eingefügt, bei mehreren Werten einer je Zeile, und das Tool bestätigt das Kopieren kurz in der Statuszeile.
  - Gegeben der Cursor steht in einem Feld, wenn der Befehl „Copy field“ über die Befehlszeile oder sein Kürzel aufgerufen wird, dann kopiert das Tool den Wert dieses Feldes.
  - Gegeben ein Feld wird einfach angeklickt, wenn danach eingefügt wird, dann hat das Tool nichts in die Zwischenablage gelegt, denn der Klick setzt den Cursor zum Bearbeiten.

acceptance-criteria:
  - key: wsy4
    text: Gegeben je ein Rechner mit Windows 11, macOS 26 und Ubuntu 24.04 ohne installierte Laufzeit, wenn die Auslieferung installiert wird, also ihr Archiv in einen beliebigen Ordner entpackt wird (einen Installer gibt es nicht) und die einmaligen Schritte der mitgelieferten Installationsanleitung für das System ausgeführt sind, dann antwortet nach `reqseq ui` die ausgegebene Adresse, und ihre Seite lädt in Chromium, Firefox und WebKit, ohne dass eine Anfrage scheitert oder die Konsole des Browsers einen Fehler nennt.
  - key: m4f9
    text: Gegeben die Auslieferung, wenn sie geprüft wird, dann enthält sie Kommandozeile, MCP-Server, Web-Oberfläche und die Laufzeit, auf der sie laufen, für alle drei Systeme, und kein Electron.
  - key: ys5r
    text: Gegeben die entpackte Auslieferung für Windows, macOS und Linux, wenn sie geprüft wird, dann enthält sie die Desktop-Hülle, unter macOS als `ReqSeq.app`, unter Windows als `ReqSeq.exe` und unter Linux als `ReqSeq` im entpackten Ordner, und das Startprogramm der Kommandozeile liegt unter macOS in `ReqSeq.app/Contents/Resources/bin/reqseq`, unter Windows in `bin\reqseq.cmd` und unter Linux in `bin/reqseq` des entpackten Ordners; aus einem Terminal aufgerufen, nennt das Startprogramm auf `--version` die Version der Auslieferung, ohne dass eine Laufzeit installiert ist.
  - key: g4xk
    text: Gegeben die Installationsanleitung für Linux, wenn sie gelesen wird, dann nennt sie für Ubuntu 24.04 das Paket `libwebkit2gtk-4.1-0` als Voraussetzung nur der Desktop-Hülle, nicht als Schritt der Installation (AK1, SR-078 AK2), und sagt, dass `reqseq ui` ohne dieses Paket im Browser läuft und die Desktop-Hülle ohne es nach SR-252 AK8 endet.

Das [Tool](reqseq:6ad4f973-fdb9-461f-8dc4-b73619ba1dac?version=n2:2427cdd2079ee312) muss mit [Kommandozeile](reqseq:f5c404b5-7886-4c69-af41-5ecc43b71f52?version=n2:2556c6eb1781011b), MCP-Server, [Web-Oberfläche](reqseq:c89b295d-c3d5-49af-b6fd-c7444cdbb5ec?version=n2:8dfd92227dd91b55) und [Desktop-Hülle](reqseq:8cde6c0b-d69c-4972-b892-af0dbfa92a09?version=n2:4a161bba37dcff33) für Windows, macOS und Linux ausgeliefert werden, mit allem, was sie zum Laufen brauchen, außer einem Browser und der Web-Engine des Betriebssystems, die die Desktop-Hülle nutzt.

acceptance-criteria:
  - Gegeben ein Element, wenn eine Person den Status Approved setzt, dann hält das Tool die Version des Elements in diesem Moment in der Datei fest.
  - Gegeben ein Element im Status Approved, dessen Version sich seitdem geändert hat, wenn der Arbeitsbereich geprüft wird, dann meldet das Tool einen Hinweis mit der festgehaltenen und der aktuellen Version; der Status bleibt unverändert.
  - Gegeben ein Arbeitsbereich ohne Git, ein Export oder eine Baseline, wenn geprüft wird, dann meldet das Tool den Hinweis ebenso.

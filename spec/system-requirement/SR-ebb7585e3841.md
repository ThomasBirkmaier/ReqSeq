spec-id: SR-187
requirement-type: functional
acceptance-criteria:
  - Gegeben der Cursor steht in einem Listeneintrag, wenn Tab oder Shift+Tab gedrückt wird, dann rückt das Tool den Eintrag mit seinen Untereinträgen eine Ebene ein beziehungsweise aus.
  - Gegeben der Cursor steht in einer Zeile oder einem Listeneintrag, wenn Alt+Pfeil nach oben oder unten gedrückt wird, dann verschiebt das Tool die Zeile, bei einem Listeneintrag mit seinen Untereinträgen, um einen Platz in diese Richtung.
  - Gegeben ein Listeneintrag, wenn er mit der Maus an eine andere Stelle derselben Liste gezogen wird, dann steht er mit seinen Untereinträgen dort in der Datei.
  - Gegeben eine dieser Änderungen, wenn danach Rückgängig gewählt wird, dann ist sie in einem Schritt zurückgenommen.

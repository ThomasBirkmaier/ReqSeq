acceptance-criteria:
  - Gegeben der Cursor steht in einem Listeneintrag und kein Menü am Cursor ist offen, wenn Tab oder Shift+Tab gedrückt wird, dann rückt das Tool den Eintrag mit seinen Untereinträgen eine Ebene ein beziehungsweise aus; außerhalb von Listen und Tabellen gehen Tab und Shift+Tab weiter zum nächsten beziehungsweise vorigen Feld.
  - Gegeben der Cursor steht in einer Zeile oder einem Listeneintrag, wenn Alt+Pfeil nach oben oder unten gedrückt wird, unter macOS Option+Pfeil (SR-145), dann verschiebt das Tool die Zeile, bei einem Listeneintrag mit seinen Untereinträgen, um einen Platz in diese Richtung.
  - Gegeben ein Listeneintrag, wenn er mit der Maus an eine andere Stelle derselben Liste gezogen wird, dann steht er mit seinen Untereinträgen dort in der Datei.
  - Gegeben eine dieser Änderungen, wenn danach Rückgängig gewählt wird, dann ist sie in einem Schritt zurückgenommen.

requirement-type: functional
acceptance-criteria:
  - Gegeben ein Repository, das in der Workspace-Datei als variantenunabhängig gekennzeichnet ist, und ein Datensatz ohne Angabe einer Variante zu einem seiner Elemente, wenn der Status berechnet wird, dann zählt er für den Kern und für jede Variante, für die das Element gilt.
  - Gegeben ein Repository ohne diese Kennzeichnung, wenn der Status berechnet wird, dann zählt ein Datensatz ohne Angabe einer Variante nur für den Kern.

Das Tool muss Repositories zulassen, die in der Workspace-Datei als variantenunabhängig gekennzeichnet sind, und deren Datensätze ohne Variante in jeder Sicht zählen lassen.

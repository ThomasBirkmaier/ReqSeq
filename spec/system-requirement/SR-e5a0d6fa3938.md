title: Elemente der Paketseite filtern
spec-id: SR-182
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-06: Auch auf der Paketseite soll sich die gezeigte Liste der Elemente filtern lassen, so wie jede andere Liste."
requirement-type: functional
acceptance-criteria:
  - Gegeben ein geöffnetes Paket, wenn ein Filter nach Typ, Status, Property, Text oder ein gespeicherter Filter gewählt wird, dann stehen unter Titel und Text nur die Elemente des Pakets, die die Bedingung erfüllen, und jeder weitere Filter grenzt sie weiter ein wie in SR-124.
  - Gegeben eine gefilterte Paketseite, wenn sie gezeigt wird, dann nennt die Überschrift ihrer Elemente die gewählten Filter und die Anzahl der gezeigten Elemente, und Titel, Text sowie Abdeckung und Nachweisgrad des ganzen Pakets bleiben wie ohne Filter.
  - Gegeben eine gefilterte Paketseite, wenn der letzte Filter oder alle Filter aufgehoben werden, dann zeigt sie die Elemente des Pakets mit den Filtern davor beziehungsweise alle Elemente des Pakets.
  - Gegeben ein Filter auf der Paketseite, wenn er gewählt oder aufgehoben wird, dann ändert das Tool keine Datei.

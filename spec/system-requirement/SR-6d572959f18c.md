title: Listen stufenweise filtern
spec-id: SR-124
rationale: "Entscheidung des Produktverantwortlichen, 2026-10-26: Die kaskadierten Filter sind gewünscht: ein Paket wählen, dann nur System Requirements, dann nur solche mit bestimmten Eigenschaften. Es fehlt, danach weiter filtern zu können: Nach dem Filtern auf einen Status steht zum Beispiel die Property topic nicht mehr zur Wahl. Akzeptanzkriterien eignen sich vermutlich nicht, weil jedes Element andere hat und die Auswahl sonst sehr groß würde (#425)."
requirement-type: functional
acceptance-criteria:
  - Gegeben eine gefilterte Liste, wenn ein weiterer Filter gewählt wird, zum Beispiel erst ein Paket, dann nur System Requirements, dann ein Status, dann enthält die Liste nur die Elemente, die alle gewählten Bedingungen erfüllen.
  - "Gegeben eine gefilterte Liste, wenn nach einer Property gefiltert wird, dann bietet das Tool jede Property der Elemente in der Liste an, deren Werte sich auswählen lassen: Auswahlwerte aus dem Metamodell, Status, Beziehungen wie Pakete und Freitext mit wenigen verschiedenen Werten, zum Beispiel „topic“, auch nach Typ und Status."
  - Gegeben eine Property mit langem Freitext, zum Beispiel die Akzeptanzkriterien, wenn nach einer Property gefiltert wird, dann bietet das Tool sie nicht zur Auswahl an; solchen Text grenzt die Suche in der aktuellen Liste ein.

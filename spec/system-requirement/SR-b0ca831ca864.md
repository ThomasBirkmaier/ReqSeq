acceptance-criteria:
  - Gegeben mehrere geöffnete Buffer, wenn Ctrl+P gedrückt wird, dann lässt sich jeder Buffer und jedes Element über die Befehlszeile mit unscharfer Suche wählen, zuletzt genutzte zuerst.
  - Gegeben die App, wenn sie geprüft wird, dann gibt es keine Tab-Leiste.
  - Gegeben ein Buffer, wenn das Fenster per Befehl geteilt wird, dann zeigen zwei Bereiche zwei Buffer nebeneinander, zum Beispiel Element und Graph.
  - Gegeben die App wird geschlossen, wenn sie wieder geöffnet wird, dann sind die zuletzt offenen Buffer wieder da.

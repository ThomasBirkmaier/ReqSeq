  - "Gegeben eine Beziehung auf ein Element in einem anderen Repository, die in der Datei der Quelle einen Titel trägt (Angabe `title`), wenn der Bestand geprüft wird (App, CLI, API, MCP: `workspace.check`), dann meldet das Tool eine Warnung mit Datei und Zeile, auch wenn die Quelle einen ungültigen Status hat."

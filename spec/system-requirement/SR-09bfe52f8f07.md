requirement-type: functional
acceptance-criteria:
  - Gegeben ein importiertes Element, wenn es gespeichert wird, dann enthält es Quelle, IDENTIFIER der Quelle, Datum des Imports, Name der Lieferung und Importfassung als Properties. Lieferung und Datum nennen den Import, der das Element zuletzt geschrieben hat.
  - Gegeben importierte Elemente, wenn nach Quelle gefiltert wird (zum Beispiel `reqseq element list` mit dem Filter `source = "Kunde A"`), dann liefert das Tool genau die Elemente dieser Quelle.
  - Gegeben ein importiertes Element wird geändert, wenn es angezeigt wird, dann bleibt die Herkunft unverändert sichtbar. Die Herkunfts-Properties schreibt nur der Import; ein anderer Befehl, der sie ändern will, wird abgelehnt.
  - Gegeben das Standardmodell, wenn es geprüft wird, dann hat jeder seiner Typen die Herkunfts-Properties; nennt eine Zuordnung einen Typ des Metamodells ohne sie, lehnt der Import ab und nennt den Typ.

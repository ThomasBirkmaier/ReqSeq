spec-id: "SR-052"
requirement-type: interface
acceptance-criteria:
  - Gegeben ein Paket mit Requirements und Beziehungen untereinander, wenn es exportiert wird (zum Beispiel `reqseq reqif export --output s6.reqif` mit dem Paket Stufe-6 als Auswahl), dann entsteht eine Datei, die gegen das Schema von ReqIF 1.2 gültig ist. Sie enthält jedes Element der Auswahl, auch Needs und Decisions, in einer flachen SPECIFICATION in der Reihenfolge der Liste.
  - Gegeben der Export, wenn er geprüft wird, dann ist der IDENTIFIER jedes Requirements „_“ gefolgt von seiner UUID und jede Beziehung ist als SPEC-RELATION enthalten.
  - "Gegeben eine exportierte Datei, wenn sie in einen leeren Arbeitsbereich mit demselben Metamodell importiert wird, dann stimmen Titel, Text, Properties und Beziehungen mit dem Original überein; die Herkunfts-Properties, die der Import ergänzt (SR-057), zählen beim Vergleich nicht. Weil sie zur Fassung zählen, ändern sich die Fassungen der importierten Elemente; der Import trägt in ihre Beziehungen die neuen Fassungen der importierten Ziele ein, sodass keine Beziehung als veraltet gilt. Dafür enthält der Export den Text als XHTML und zusätzlich als STRING-Attribut `reqseq-markdown`. Eine Datei des Tools (REQ-IF-TOOL-ID `reqseq`) braucht keine Zuordnung von Hand: der Import legt die Zuordnung eins zu eins an und speichert sie wie jede andere (SR-054)."

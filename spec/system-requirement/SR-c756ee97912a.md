acceptance-criteria:
  - key: wxtg
    text: Gegeben die Befehle des Tools, die sein Befehlskatalog führt (je Befehl ein Name und ein Schema für Eingabe und Ausgabe, aus dem alle Zugänge entstehen), wenn sie gegen App, Kommandozeile, API und MCP-Server geprüft werden, dann ist jede Funktion über jeden Zugang verfügbar, außer reiner Darstellung der App. Reine Darstellung ist der Zustand der Bedienung in der App, etwa Buffer, geteiltes Fenster, Befehlszeile und der Modus „Agent folgen“; Werte aus den Dateien des Arbeitsbereichs gehören nicht dazu. Einen Zugang oder den Dienst für die Dokumentation zu starten (`reqseq serve api`, `reqseq mcp`, `reqseq serve docs`) und die Dokumentation zu öffnen sind keine Funktionen in diesem Sinn.
  - key: bb1t
    text: Gegeben dieselbe Abfrage über zwei Zugänge, wenn sie ausgeführt wird, dann liefern beide dasselbe Ergebnis, außer bei einem lokalen Pfad außerhalb der Repositories des Arbeitsbereichs, den API und MCP-Server ablehnen (SR-142).
  - key: txbq
    text: Gegeben Kommandozeile, API und MCP-Server, wenn sie ohne grafische Oberfläche laufen, dann funktionieren sie vollständig.
  - key: dq1w
    text: Gegeben eine Einstellung oder ein Wert, den die App anzeigt und der nicht reine Darstellung ist, wenn er über Kommandozeile, API oder MCP-Server abgefragt wird, dann liefert das Tool ihn.

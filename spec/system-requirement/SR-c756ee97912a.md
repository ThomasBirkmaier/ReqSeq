acceptance-criteria:
  - Gegeben die Liste der Funktionen aus den System Requirements, wenn sie gegen App, Kommandozeile, API und MCP-Server geprüft wird, dann ist jede Funktion über jeden Zugang verfügbar, außer reiner Darstellung der App. Reine Darstellung ist der Zustand der Bedienung in der App, etwa Buffer, geteiltes Fenster, Befehlszeile und der Modus „Agent folgen“; Werte aus den Dateien des Arbeitsbereichs gehören nicht dazu.
  - Gegeben dieselbe Abfrage über zwei Zugänge, wenn sie ausgeführt wird, dann liefern beide dasselbe Ergebnis, außer bei einem lokalen Pfad außerhalb der Repositories des Arbeitsbereichs, den API und MCP-Server ablehnen (SR-142).
  - "Gegeben die Kommandozeile, wenn sie ohne grafische Oberfläche läuft, dann funktioniert sie vollständig."
  - Gegeben eine Einstellung oder ein Wert, den die App anzeigt und der nicht reine Darstellung ist, wenn er über Kommandozeile, API oder MCP-Server abgefragt wird, dann liefert das Tool ihn.

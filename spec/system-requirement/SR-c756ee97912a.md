acceptance-criteria:
  - key: wxtg
    text: Gegeben die Befehle des Tools, die sein Befehlskatalog führt (je Befehl ein Name und ein Schema für Eingabe und Ausgabe, aus dem alle Zugänge entstehen), wenn sie gegen Kommandozeile, API und MCP-Server geprüft werden, dann ist jede Funktion über jeden dieser Zugänge verfügbar. Einen Zugang, die Web-Oberfläche oder den Dienst für die Dokumentation zu starten (`reqseq serve api`, `reqseq mcp`, `reqseq ui`, `reqseq serve docs`) und die Dokumentation zu öffnen sind keine Funktionen in diesem Sinn.
  - key: bb1t
    text: Gegeben dieselbe Abfrage über zwei Zugänge, wenn sie ausgeführt wird, dann liefern beide dasselbe Ergebnis, außer bei einem lokalen Pfad außerhalb der Repositories des Arbeitsbereichs, den API und MCP-Server ablehnen (SR-142).
  - key: txbq
    text: Gegeben Kommandozeile, API und MCP-Server, wenn sie ohne grafische Oberfläche laufen, dann funktionieren sie vollständig.
  - key: hn1m
    text: Gegeben ein Wert aus dem Arbeitsbereich oder eine Einstellung des Tools, die die Web-Oberfläche zeigt, wenn er über Kommandozeile, API oder MCP-Server abgefragt wird, dann liefert das Tool ihn; was die Web-Oberfläche gerade zeigt und wie, ist keine Funktion und kein solcher Wert.

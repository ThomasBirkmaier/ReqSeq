spec-id: SR-168
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-02: Wer eine Zuordnung schreibt, braucht Datentyp, Mehrfachwerte und Aufzählungswerte jedes Attributs, um Property, Wertart und Werte zu wählen, ohne die XML-Datei zu lesen und ohne zweite Runde (#573)."
requirement-type: functional
acceptance-criteria:
  - Gegeben eine ReqIF-Datei mit Attributen ohne Zuordnung, wenn sie mit `reqseq reqif analyze export.reqif` gelesen oder der Import gestartet wird, dann nennt das Tool in der Liste aus SR-055 zu jedem dieser Attribute seinen Datentyp in der Datei (STRING, XHTML, INTEGER, REAL, DATE, BOOLEAN oder ENUMERATION) und ob es mehrere Werte haben kann (MULTI-VALUED).
  - Gegeben ein Attribut ohne Zuordnung vom Datentyp ENUMERATION, zum Beispiel `Priority` mit den Werten `1` bis `4`, wenn die Datei so gelesen wird, dann nennt das Tool in derselben Liste jeden Wert der Aufzählung, auch wenn für das Attribut noch keine Property gewählt ist.
  - Gegeben diese Liste, wenn die Zuordnung für jeden ihrer Einträge nach SR-055 AK2 vervollständigt wird, dann läuft der erneut gestartete Import ohne weitere Runde durch, auch für Attribute, die einer Auswahl-Property zugeordnet werden.
  - Gegeben dieselbe Datei und dieselbe Zuordnung, wenn die Analyse über App, Kommandozeile, API oder MCP ausgeführt wird, dann liefert das Tool dasselbe Ergebnis.

Das Tool muss zu jedem Attribut ohne Zuordnung seinen Datentyp, ob es mehrere Werte haben kann, und bei einer Aufzählung ihre Werte zeigen, sodass sich die Zuordnung in einer Runde schreiben lässt.

  - key: h09c
    text: Gegeben eine Element-Datei in einem beliebigen Unterordner eines eingebundenen Repositories, außer in `.git`, `node_modules`, einem eingebetteten Git-Repository, einem Ordner, den die Arbeitsbereichs-Datei ausnimmt, oder hinter einer Verknüpfung (Link), wenn der Arbeitsbereich geöffnet wird, dann erscheint das Element im Tool.
  - key: f4dt
    text: Gegeben eine Markdown-Datei ohne Frontmatter mit `id` und `type`, wenn der Arbeitsbereich geöffnet wird, dann zählt sie nicht als Element und bleibt unverändert.
  - key: twmf
    text: Gegeben eine Element-Datei wird in einen anderen Ordner verschoben, wenn der Arbeitsbereich neu gelesen wird, dann zeigen alle Beziehungen weiter auf das Element.

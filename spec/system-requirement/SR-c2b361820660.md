title: Kriterienschlüssel vergeben und erhalten
spec-id: SR-204
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-10: Tests nennen einzelne Akzeptanzkriterien. Eine Nummer würde nach dem Einfügen oder Verschieben still auf ein anderes Akzeptanzkriterium zeigen, und feste Nummern mit Lücken würden Nutzer für einen Fehler halten. Deshalb trägt jedes Akzeptanzkriterium einen festen Kriterienschlüssel, und angezeigt wird die Position."
requirement-type: functional
acceptance-criteria:
  - Gegeben ein Requirement, wenn es mit Akzeptanzkriterien angelegt wird oder seine Akzeptanzkriterien geändert und gespeichert werden (App, Kommandozeile, API, MCP), dann hat danach jedes von ihnen einen Kriterienschlüssel, den im Requirement kein anderes trägt; trugen vorher zwei denselben, bleibt er beim vorderen.
  - Gegeben ein Akzeptanzkriterium ohne Kriterienschlüssel, wenn eine andere Property des Elements geändert und gespeichert wird, dann bleiben die Zeilen der Akzeptanzkriterien in der Datei unverändert.
  - Gegeben Requirements mit Akzeptanzkriterien ohne Kriterienschlüssel, wenn für eine Auswahl die fehlenden Kriterienschlüssel vergeben werden (App, Kommandozeile, API, MCP), dann hat danach jedes ihrer Akzeptanzkriterien einen, vorhandene Kriterienschlüssel und die Fassungen sind unverändert, und das Tool nennt die Zahl der geänderten Elemente.
  - Gegeben die Akzeptanzkriterien eines Requirements werden als Ganzes neu gesetzt, auch beim wiederholten Import, und ein Eintrag ohne Kriterienschlüssel hat denselben Text wie ein bisheriges Akzeptanzkriterium, dessen Kriterienschlüssel kein anderer Eintrag mitbringt, wenn gespeichert wird, dann behält er diesen Kriterienschlüssel, auch an anderer Position; jeder bisherige Kriterienschlüssel geht an höchstens einen Eintrag, und ein Eintrag mit anderem Text bekommt einen neuen.
  - Gegeben ein Eintrag wird mit Kriterienschlüssel übergeben, wenn gespeichert wird, dann steht dieser Kriterienschlüssel in der Datei; hat er nicht die Form eines Kleinbuchstabens von a bis z, gefolgt von 3 bis 15 Kleinbuchstaben von a bis z oder Ziffern, ist er `true` oder `null`, oder trügen ihn nach der Änderung zwei Einträge, lehnt das Tool die Änderung ab und schreibt nichts.
  - Gegeben ein Akzeptanzkriterium wird über seine Nummer geändert, wenn gespeichert wird, dann behält es seinen Kriterienschlüssel.
  - Gegeben ein Akzeptanzkriterium wird im Editor umformuliert oder verschoben, wenn gespeichert wird, dann behält es seinen Kriterienschlüssel; wird es geteilt, behält der erste Teil ihn, und werden zwei zusammengeführt, behält das vordere seinen.
  - Gegeben Akzeptanzkriterien werden im Editor neu angelegt, dupliziert oder eingefügt, auch nach dem Ausschneiden und auch mehrere Zeilen auf einmal, wenn gespeichert wird, dann bekommt jedes von ihnen einen neuen Kriterienschlüssel, auch wenn sein Text dem eines bisherigen Akzeptanzkriteriums gleicht.
  - Gegeben eine Änderung an Akzeptanzkriterien ist schon gespeichert, wenn im Editor Rückgängig gewählt wird, dann tragen die Akzeptanzkriterien danach wieder ihre vorigen Kriterienschlüssel.
  - Gegeben ein Requirement mit einem Akzeptanzkriterium ohne Kriterienschlüssel, wenn der Bestand geprüft wird, dann meldet die Prüfung eine Warnung; tragen zwei Akzeptanzkriterien denselben Kriterienschlüssel, meldet sie einen Fehler, und ein Datensatz mit diesem Kriterienschlüssel zählt für keines der beiden.
  - Gegeben eine Element-Datei mit Kriterienschlüsseln, wenn sie in einem Texteditor geöffnet wird, dann ist der Kopf gültiges YAML, und jedes Akzeptanzkriterium steht darin als lesbarer Markdown-Text bei seinem Kriterienschlüssel.
  - Gegeben ein Requirement wird per ReqIF exportiert und wieder importiert, wenn der Import fertig ist, dann tragen seine Akzeptanzkriterien dieselben Kriterienschlüssel wie vorher.

Das Tool muss jedem Akzeptanzkriterium einen Kriterienschlüssel ([D-072](reqseq:3d5793a1-a4d5-493c-892b-c1b1dded5eca?version=n2:2b83f2d600f6b5fc)) geben und ihn bei jeder Änderung über App, Kommandozeile, API und MCP erhalten, solange das Akzeptanzkriterium besteht.

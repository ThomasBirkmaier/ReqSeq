title: "Metamodell-Änderungen ohne Umschreiben wirksam machen"
spec-id: "SR-015"
requirement-type: functional
acceptance-criteria:
  - "Gegeben eine Metamodell-Datei wird geändert, wenn sie gespeichert wird, auch durch Ersetzen der Datei, dann arbeiten die laufende App, die API und der MCP-Server nach höchstens 2 Sekunden mit dem neuen Metamodell, ohne Neustart."
  - "Gegeben der Anzeigename eines Typs wird geändert, wenn das Tool die Änderung übernimmt, dann ist keine Element-Datei verändert."
  - "Gegeben eine neue Pflicht-Property wird ergänzt, wenn das Tool die Änderung übernimmt, dann zeigt es für jedes Element ohne diese Property einen Hinweis und ändert keine Datei."
  - "Gegeben eine Änderung des Metamodells ändert, welche Properties eines Elements zur Fassung zählen, wenn das Tool die Änderung übernimmt, dann ändert es keine Datei und berechnet jede Fassung mit dem neuen Metamodell; Beziehungen, Verweise und Datensätze auf Elemente, deren Fassung sich dadurch ändert, gelten als veraltet, und der Hinweis auf eine veraltete Beziehung nennt für die gespeicherte Fassung kein Datum, aber Datum und Commit der letzten Änderung des Metamodells."

Wenn sich das Metamodell ändert, muss das Tool die Änderung übernehmen, ohne Element-Dateien von selbst umzuschreiben.

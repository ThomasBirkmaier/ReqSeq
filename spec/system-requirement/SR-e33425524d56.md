title: Höchstzahl von Listeneinträgen im Metamodell
spec-id: SR-167
rationale: "Entscheidung des Produktverantwortlichen, 2026-11-02: Das Metamodell soll festlegen können, wie viele Einträge eine Listen-Property höchstens hat, zum Beispiel höchstens drei Akzeptanzkriterien je System Requirement, und die Prüfung des Bestands soll Abweichungen melden (#632)."
requirement-type: functional
acceptance-criteria:
  - Gegeben das Metamodell legt für eine Property mit mehreren Einträgen, die keine Beziehung ist, eine Höchstzahl fest, wenn ein Element mehr Einträge hat und der Bestand über Kommandozeile, API, MCP oder App geprüft wird, dann erscheint ein Hinweis mit Element, Property, Anzahl und Höchstzahl.
  - Gegeben eine Property mit mehreren Einträgen, die keine Beziehung ist, ohne Höchstzahl im Metamodell, wenn der Bestand geprüft wird, dann darf ein Element beliebig viele Einträge haben, und es erscheint kein Hinweis zur Anzahl.

Das Tool muss im Metamodell eine Höchstzahl von Einträgen je Listen-Property zulassen und Elemente melden, die sie überschreiten.

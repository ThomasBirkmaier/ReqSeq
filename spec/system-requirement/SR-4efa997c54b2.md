title: Formatierung über ein Slash-Menü einfügen
spec-id: SR-129
rationale: "Entscheidung des Produktverantwortlichen, 2026-10-26: Der Editor soll ein Slash-Menü wie Logseq bekommen, das an Ort und Stelle aufgeht und Markdown-Optionen zeigt; ein Screenshot diente als kleines, nicht vollständiges Beispiel. Das Beispiel zeigt unter anderem Image link, Underline, Code block, Quote, Math block und Heading. Unterstreichen bietet das Menü nicht an, weil Markdown keine Unterstreichung kennt und die Datei reines Markdown bleibt (D-015)."
requirement-type: functional
acceptance-criteria:
  - "Gegeben der Editor, wenn „/“ getippt wird, dann öffnet sich am Cursor ein Menü mit den Markdown-Elementen: Überschriften, normaler Text, Liste, nummerierte Liste, Aufgabenliste, Zitat, Code-Block, Tabelle, Link, Verweis auf ein Element, Bild, Formelblock und Diagramm."
  - Gegeben das Menü ist offen, wenn weiter getippt wird, dann grenzt es die Einträge wie die Befehlszeile über Anfangsbuchstaben und unscharfe Suche ein, und Ctrl+N, Ctrl+P und die Pfeiltasten wählen einen Eintrag, Enter übernimmt ihn.
  - Gegeben das Menü ist offen, wenn Escape gedrückt wird, dann schließt es sich, und das „/“ bleibt so im Text, wie es getippt wurde.
  - Gegeben ein Eintrag wird übernommen, wenn die Datei danach in einem Texteditor geöffnet wird, dann steht an der Stelle reines Markdown nach CommonMark mit GitHub-Erweiterungen, und das „/“ mit dem Suchtext ist ersetzt.

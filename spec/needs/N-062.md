Mehrere Agenten müssen gleichzeitig mit dem Tool arbeiten können, ohne sich zu stören, zum Beispiel um Szenarien oder Use Cases durchzuspielen. Jeder Agent arbeitet dabei auf einer eigenen lokalen Kopie (D-002); den Abgleich übernimmt die Versionsverwaltung (D-014).

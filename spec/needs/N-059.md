title: "Prüfung auf veraltete Verweise im Merge Request"

thema: "Traceability und Ketten"
---

Im Merge Request muss sich automatisch prüfen lassen, ob noch Beziehungen, Verweise oder Nachweise auf eine alte Fassung eines Elements zeigen, bevor das Element wieder auf Approved gesetzt wird. Siehe D-025.

# spec/

The LogReq specification, exported from the Logseq graph ReqSeq by the `spec-export` skill (D-047). **Do not edit by hand.**

- `needs/N-xxx.md`, `system-requirements/SR-xxx.md`, `decisions/D-xxx.md`, `glossary/<term>.md`
- One Markdown file per element, YAML frontmatter, file name = ID (D-015, D-038). Property keys are the Logseq property names in lower case; values are quoted verbatim.
- `stages.json`: system requirements per stage (D-035).

The format is preliminary until the schemas of stage 0 (D-052) are merged; then the export follows `schemas/element.schema.json`.

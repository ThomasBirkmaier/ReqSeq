Die Agents arbeiten in Claude Code in der Cloud, mit eigener Umgebung und Setup-Skript. Eine Pipeline baut und testet das Tool auf Windows, macOS und Linux (D-003).

Der Laptop wird nur für den Export der Spec (D-047) und für die Abnahme der Stufen gebraucht.

Grund: Viele Agents können parallel arbeiten, ohne laufenden Laptop und ohne Zugriff auf lokale Daten.

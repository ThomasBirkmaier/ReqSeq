title: "Jedes Element ist eine eigene Markdown-Datei"
decision_status: "Accepted"
---

Jedes Element liegt als eigene Markdown-Datei vor.

Grund: Ein Element ist in sich abgeschlossen. Änderungen an verschiedenen Elementen geraten so nie in Konflikt, und jede Datei lässt sich mit üblichen Werkzeugen lesen, vergleichen und zusammenführen. Erfüllt N-039, konkretisiert D-024.

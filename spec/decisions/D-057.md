title: "Kennzeichen für die Fassung"
decision_status: "Accepted"
---

Jede Property trägt im Metamodell das Kennzeichen „zählt zur Fassung“. Die Fassung (D-013, D-027) wird über den Text und die gekennzeichneten Properties berechnet; eingebettete Bilder zählen immer mit. Im Standardmodell zählen Acceptance Criteria, Requirement Type und Validity; Title, Status, Package, Rationale und die Herkunft zählen nicht.

Grund: Sonst würde etwa jede neue Paket-Zuordnung alle Beziehungen auf das Element veralten lassen.

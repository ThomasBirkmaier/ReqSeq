title: "Auswertungen mit externen Werkzeugen"
decision_status: "Accepted"
---

Auswertungen baut das Tool nicht selbst. Dafür werden externe Werkzeuge wie Grafana genutzt. Das Tool stellt die Daten bereit.

Grund: Es gibt dafür bessere Werkzeuge. Das Tool bleibt Datenquelle und damit klein.

Bedingung: Alles, was ausgewertet wird, auch Nachweise, ist dauerhaft abgelegt und einem Stand zuordenbar. Nur so bleiben spätere Auswertungen über die Zeit ohne Umbau möglich. Wo Nachweise liegen, legt die Organisation fest (siehe D-007).

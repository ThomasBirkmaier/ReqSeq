Eine Baseline ist eine Datei mit Name, Datum, dem Commit je eingebundenem Repository und der Liste aus ID und Fassung jedes Elements im Paket. Das Tool schreibt die Datei, committet wird sie mit Git (D-036). Ein zusätzlicher Git-Tag ist erlaubt, aber nicht vorausgesetzt.

Grund: Ein Git-Tag friert nur ein ganzes Repository ein, kein Paket und nicht mehrere Repositories zusammen (N-027, N-035).

title: "Das Tool liest Git nur"
decision_status: "Accepted"
---

Das Tool liest Git, zum Beispiel für den Stand und das Datum einer Fassung, und schreibt nur Dateien. Committen, Branches, Pull, Push und Merge Requests laufen über das Git-Werkzeug, das jeder schon hat.

Grund: Für den Anfang die einfachste Lösung. Die Grenze aus D-014 bleibt sauber, und das Tool muss keine Konflikte beim Abgleich behandeln.

Folge: Eine Git-Bedienung im Tool gehört zur Erweiterung.

title: "Arbeitsbereich als Datei"

---

Eine Datei im Haupt-Repository nennt die Repositories des Arbeitsbereichs mit Name und Adresse. Jeder hat davon lokal nur die, auf die er Zugriff hat. Fehlt eines, gilt N-041.

Grund: So weiß das Tool, welche Repositories zusammengehören (N-035, N-049, D-021), ohne einen Server zu brauchen.

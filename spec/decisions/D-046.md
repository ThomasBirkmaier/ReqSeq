Der Code des Tools liegt in einem eigenen privaten Repository auf GitHub (logreq). Es ist ein Monorepo mit getrennten Paketen für Programmlogik, Kommandozeile, API, MCP-Server und App (D-004, D-025, D-029).

Das lokale Repository ReqSeq mit dem Mirror dieser Spec bleibt unverändert.

Grund: Die Agents brauchen einen Ort, an dem Code, Spec, Tests und Nachweise zusammen liegen. Das Repository ReqSeq hat keinen Server und enthält nur den Mirror.

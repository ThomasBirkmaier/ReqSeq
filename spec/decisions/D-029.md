title: "API und MCP-Server neben der App"

Neben der Desktop-App (D-003) und der Kommandozeile (D-025) gibt es eine API und einen MCP-Server. Alle nutzen dieselbe Programmlogik. Die Oberfläche hat keine eigene Logik.

Die API ist für Pipelines und automatische Tests da, der MCP-Server für KI-Agenten. Eine Funktion gilt erst als fertig, wenn sie über alle Zugänge geht.

Beide werden mit dem Tool ausgeliefert und laufen lokal auf der lokalen Kopie (D-002), auch offline (N-046).

Das Tool startet und steuert keine Agenten. Das geschieht außerhalb.

Grund: So lässt sich in der Entwicklung alles automatisch prüfen, bis hin zu ganzen Abläufen (N-057). Mit einer gemeinsamen Programmlogik können die Zugänge nicht auseinanderlaufen.

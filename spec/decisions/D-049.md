title: "Ein Issue je System Requirement"

---

Für jedes System Requirement gibt es genau ein Issue auf GitHub, je Stufe (D-035) dazu ein Sammel-Issue. Das Issue enthält ID, UUID, Akzeptanzkriterien im Wortlaut und Nachweismethode.

Arbeiten ohne eigenes System Requirement, zum Beispiel Gerüst oder Architektur, bekommen ein eigenes Issue mit dem Label enabler.

Grund: Jedes System Requirement hat genau einen Ort der Umsetzung. Das hält die Kette bis zum Test eindeutig (N-038).

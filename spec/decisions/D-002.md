decision_status: "Accepted"

Inhalte werden lokal bearbeitet und über Git abgeglichen (local-first, Docs-as-Code).

Grund: folgt direkt aus Git-Server mit Merge Requests und Reviews.

Folge: Auf der lokalen Kopie kann jeder alles ändern. Rechte greifen erst beim Zusammenführen per Merge Request. Siehe Rolle.

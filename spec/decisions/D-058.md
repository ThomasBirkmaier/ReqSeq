Eine Beziehung auf ein Element in einem anderen Repository enthält nur ID, Fassung und den Namen des Ziel-Repositories aus der Arbeitsbereichs-Datei (D-041), keinen Titel und keinen Text. Innerhalb eines Repositories steht der Titel mit in der Datei. Das gilt auch für Verweise: Ein Verweis auf ein Element in einem anderen Repository enthält ebenfalls den Namen des Ziel-Repositories.

Das Tool zeigt den Titel an, wenn das Ziel lokal vorhanden ist.

Grund: Im selben Repository hat jeder Zugriff auf beide Elemente. Zwischen Repositories würde ein Titel Inhalt in ein Repository mit anderem Need-to-know tragen (N-040, N-041). Nur mit dem Repository-Namen unterscheidet das Tool ein nicht zugängliches Ziel (N-041) von einem fehlenden (N-065). Der Repository-Name verrät keinen Inhalt.

title: "Unterschiede zeigt die Versionsverwaltung"
decision_status: "Accepted"
---

Bei einem veralteten Verweis oder Nachweis zeigt das Tool, dass er veraltet ist, und das Datum der alten Fassung (D-013).

Den Unterschied zwischen zwei Fassungen oder Baselines zeigen Git und der Git-Server (D-014, D-024). Eine Anzeige der Unterschiede im Tool gehört zur Erweiterung, nicht zum Basisumfang.

Ausnahmen: Den Unterschied einer Variante zum Kern (N-021) und die Änderungen bei einem wiederholten Import (N-043) zeigt das Tool selbst.

Grund: Git zeigt Unterschiede zwischen Markdown-Dateien (D-015) bereits zuverlässig. Das Tool bleibt klein.

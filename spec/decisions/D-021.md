title: "Das Metamodell gehört zum Stand"
decision_status: "Accepted"
---

Das Metamodell liegt als Textdateien in der Versionsverwaltung, wie die Elemente. Damit gehört es zu jedem Stand, und jede Baseline enthält das Metamodell, das damals galt. In einem Stand gilt genau ein Metamodell.

Bei mehreren Repositories liegt es in einem Repository, das die anderen einbinden. Ob das ein eigenes Repository ist oder ein Ordner im Haupt-Repository, legt die Organisation fest. Soll das Metamodell getrennt geschützt sein (N-025), liegt es in einem eigenen Repository, denn Rechte gibt es nur pro Repository (D-016).

Wer das Metamodell ändern darf, regeln die Rechte an diesem Repository (D-016).

Grund: Nur so bleiben Baselines unberührt (N-026). Kopien in jedem Repository würden auseinanderlaufen.

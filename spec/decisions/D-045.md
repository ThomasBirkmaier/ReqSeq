Das Tool bietet kein Löschen von Elementen, nur Ablösen: Der Status wird ungültig (D-044), und optional zeigt der Nachfolger mit Supersedes auf das abgelöste Element. Eine eigene Beziehung Superseded by gibt es nicht; die Richtung vom alten Element zum Nachfolger ergibt sich aus Supersedes.

Fehlt eine Datei trotzdem, etwa weil sie von Hand gelöscht wurde, behandelt das Tool das wie ein fehlendes Ziel (N-041) und meldet es bei der Prüfung des Bestands.

Grund: Beziehungen und Nachweise bleiben nachvollziehbar.

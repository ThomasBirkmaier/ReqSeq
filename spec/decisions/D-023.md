title: "Sichten sind an keine Rolle gebunden"
decision_status: "Accepted"
---

Jede Sicht steht allen offen. Das Tool kennt keine Sichten für bestimmte Rollen oder Stakeholder.

Nennt ein Need einen Stakeholder, zum Beispiel „Als Auditor“, sagt das nur, wer das Bedürfnis hat.

Grund: Das Tool verwaltet keine Benutzer (D-016). Feste Sichten pro Rolle würden das voraussetzen.

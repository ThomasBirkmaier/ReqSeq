Eine Beziehung auf ein Element in einem anderen Repository enthält nur ID, Fassung und den Namen des Ziel-Repositories aus der Arbeitsbereichs-Datei ([D-041](logreq:6adc6921-ddaf-4756-954c-0072d0fc0739?version=n1:e5c63949e3f1d81b)), keinen Titel und keinen Text. Innerhalb eines Repositories steht der Titel mit in der Datei. Das gilt auch für Verweise: Ein Verweis auf ein Element in einem anderen Repository enthält ebenfalls den Namen des Ziel-Repositories.

Das Tool zeigt den Titel an, wenn das Ziel lokal vorhanden ist.

Grund: Im selben Repository hat jeder Zugriff auf beide Elemente. Zwischen Repositories würde ein Titel Inhalt in ein Repository mit anderem Need-to-know tragen ([N-040](logreq:6adc4fbb-04b5-4bda-a110-17ed577eb713?version=n1:2956725ac86731ca), [N-041](logreq:6adc4fbc-3b1e-4eb7-8e67-c99900ac6b04?version=n1:60667922789ad44d)). Nur mit dem Repository-Namen unterscheidet das Tool ein nicht zugängliches Ziel ([N-041](logreq:6adc4fbc-3b1e-4eb7-8e67-c99900ac6b04?version=n1:60667922789ad44d)) von einem fehlenden ([N-065](logreq:6adc6938-28fa-42f6-b018-5bbf010cc58c?version=n1:643198d9c6d03ede)). Der Repository-Name verrät keinen Inhalt.

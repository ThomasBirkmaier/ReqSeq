title: "Agents arbeiten in der Cloud"

---

Die Agents arbeiten in Claude Code in der Cloud, mit eigener Umgebung und Setup-Skript. Eine Pipeline baut und testet das Tool auf Windows, macOS und Linux ([D-003](logreq:6ad39066-51e1-4f3a-8e17-b36e2db4dd01?version=n1:379da0e82ecf207a)).

Der Laptop wird nur für die Abnahme der Stufen gebraucht.

Grund: Viele Agents können parallel arbeiten, ohne laufenden Laptop und ohne Zugriff auf lokale Daten.

title: "Kennzeichen für die Fassung"
spec-id: "D-057"
---

Jede Property trägt im Metamodell das Kennzeichen „zählt zur Fassung“. Die Fassung ([D-013](reqseq:6adc4946-b44c-4ae1-8dbf-fb9e88b8c607?version=n1:0c3f2da31ca1ae9a), [D-027](reqseq:6adc58f6-3aa2-4478-b345-670b5cbb1127?version=n1:160385bf4b5c422a)) wird über den Text und die gekennzeichneten Properties berechnet; eingebettete Bilder zählen immer mit. Im Standardmodell zählen Acceptance Criteria, Requirement Type und Validity; Title, Status, Package, Rationale, Emergent und die Herkunft zählen nicht.

Grund: Sonst würde etwa jede neue Paket-Zuordnung alle Beziehungen auf das Element veralten lassen.

title: Skill-Datei für Agents
spec-id: D-079
---

ReqSeq legt für einen [Agent](reqseq:f872adef-c0d6-4968-836b-cc23fa3b7173?version=n2:17c9a424ad1f1dc9) eine Skill-Datei im offenen Format der Agent Skills an, an dem Ort, an dem Claude Code die Skills eines Repositorys sucht: `.claude/skills/managing-requirements/SKILL.md` in der Wurzel des Git-Repositorys, ohne Git im Ordner des Arbeitsbereichs. Weitere Orte für andere [Clients](reqseq:7ecb6c50-e26f-4fde-a60b-540a5e33ddc4?version=n2:2a8258e3bd617d85) kommen erst dazu, wenn feststeht, dass der Client sie liest; sie ändern diese Entscheidung. Eine vorhandene Datei dort ändert ReqSeq nur auf ausdrückliche Angabe, im Einklang mit [D-068](reqseq:12bb3e5a-c303-4774-9f3b-b61677923a73?version=n2:9c582351d88d2177).

Grund: Claude Code lädt Skills aus einem Unterordner erst, wenn der Agent dort eine Datei liest; ein Agent, der nur über den MCP-Server arbeitet, sähe einen Skill im Ordner `spec/` nie.

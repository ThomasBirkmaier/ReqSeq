title: Skill-Datei für Agents
spec-id: D-079
---

ReqSeq legt für einen Agent eine Skill-Datei im offenen Format der Agent Skills an, an dem Ort, an dem Claude Code die Skills eines Repositorys sucht: `.claude/skills/managing-requirements/SKILL.md` in der Wurzel des Git-Repositorys, ohne Git im Ordner des Arbeitsbereichs. Weitere Orte für andere Clients kommen erst dazu, wenn feststeht, dass der Client sie liest; sie ändern diese Entscheidung. Eine vorhandene Datei dort ändert ReqSeq nur auf ausdrückliche Angabe, im Einklang mit [D-068](reqseq:12bb3e5a-c303-4774-9f3b-b61677923a73?version=n2:553793df52ec58b3).

Grund: Claude Code lädt Skills aus einem Unterordner erst, wenn der Agent dort eine Datei liest; ein Agent, der nur über den MCP-Server arbeitet, sähe einen Skill im Ordner `spec/` nie.

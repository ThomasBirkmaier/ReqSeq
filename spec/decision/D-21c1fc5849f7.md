title: "Baseline als Datei"
spec-id: "D-039"
---

Eine Baseline ist eine Datei mit Name, Datum, dem Commit je eingebundenem Repository und der Liste aus ID und Fassung jedes Elements im Paket. Das Tool schreibt die Datei, committet wird sie mit Git ([D-036](reqseq:6adc691d-c3f6-4d51-a053-72a341032941?version=n1:d9ab6ac4aab20571)). Ein zusätzlicher Git-Tag ist erlaubt, aber nicht vorausgesetzt.

Die Baseline-Dateien liegen in einem festen Ordner des Arbeitsbereichs: in dem Ordner, den die Datei des Arbeitsbereichs für Baselines nennt, ohne Angabe im Ordner `baselines` des Haupt-Repositories. Dort finden alle Funktionen, die Baselines lesen, sie wieder. Das Dateiformat regelt eine ADR (Entscheidung des Produktverantwortlichen, 2026-10-29).

Grund: Ein Git-Tag friert nur ein ganzes Repository ein, kein Paket und nicht mehrere Repositories zusammen ([N-027](reqseq:6ad47f0e-0734-4f0d-8d66-06c23933693c?version=n1:d6faaaaf211489bd), [N-035](reqseq:6ad4f636-3b68-4ace-a3be-12ebdcba9b2a?version=n1:fb6a0af7414140ba)).

title: "Baseline als Datei"
spec-id: "D-039"
---

Eine Baseline ist eine Datei mit Name, Datum, dem Commit je beteiligtem Repository ([SR-050](reqseq:6adc6c99-2467-4946-b797-59d3c80b7a8c?version=n2:fb9d92b344170907)) und der Liste aus ID und Fassung jedes Elements der Auswahl, zum Beispiel eines Pakets, einer Variante oder eines Filters (Entscheidung des Produktverantwortlichen, 2026-11-09). Das Tool schreibt die Datei, committet wird sie mit Git ([D-036](reqseq:6adc691d-c3f6-4d51-a053-72a341032941?version=n2:c433f023b7b96248)). Ein zusätzlicher Git-Tag ist erlaubt, aber nicht vorausgesetzt.

Die Baseline-Dateien liegen in einem Ordner des Arbeitsbereichs: in dem Ordner, den die Datei des Arbeitsbereichs für Baselines nennt, ohne Angabe im Ordner `baselines` des Haupt-Repositories. Dort finden alle Funktionen, die Baselines lesen, sie wieder. Das Dateiformat regelt eine ADR (Entscheidung des Produktverantwortlichen, 2026-10-29).

Grund: Ein Git-Tag friert nur ein ganzes Repository ein, keine Auswahl und nicht mehrere Repositories zusammen ([N-027](reqseq:6ad47f0e-0734-4f0d-8d66-06c23933693c?version=n2:3d50558afdf39622), [N-035](reqseq:6ad4f636-3b68-4ace-a3be-12ebdcba9b2a?version=n1:fb6a0af7414140ba)).

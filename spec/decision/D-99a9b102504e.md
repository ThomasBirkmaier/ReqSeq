title: "Beziehungen über Repository-Grenzen nur mit ID"
spec-id: "D-028"
---

Eine Beziehung auf ein Element in einem anderen Repository enthält nur ID und Fassung, keinen Titel und keinen Text. Innerhalb eines Repositories steht der Titel mit in der Datei.

Das Tool zeigt den Titel an, wenn das Ziel lokal vorhanden ist.

Grund: Im selben Repository hat jeder Zugriff auf beide Elemente. Zwischen Repositories würde ein Titel Inhalt in ein Repository mit anderem Need-to-know tragen ([N-040](reqseq:6adc4fbb-04b5-4bda-a110-17ed577eb713?version=n1:ec82dab993b4b934), [N-041](reqseq:6adc4fbc-3b1e-4eb7-8e67-c99900ac6b04?version=n1:3f06f7d1100e3c6f)). So bleibt [N-048](reqseq:6adc50a4-1b5c-4e15-b1ce-ab8ea74f70b0?version=n1:0c42e42f057c09e4) so weit wie möglich erfüllt.

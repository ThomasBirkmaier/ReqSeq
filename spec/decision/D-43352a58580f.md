title: "Jedes Element ist eine eigene Markdown-Datei"
spec-id: "D-015"

Jedes Element liegt als eigene Markdown-Datei vor.

Grund: Ein Element ist in sich abgeschlossen. Änderungen an verschiedenen Elementen geraten so nie in Konflikt, und jede Datei lässt sich mit üblichen Werkzeugen lesen, vergleichen und zusammenführen. Erfüllt [N-039](logreq:6adc4ebc-49b9-4816-a28e-5ac4add9fdb2?version=n1:e6c91420e439fc1a), konkretisiert [D-024](logreq:6adc5a79-32fa-4834-88e9-f88d296ea3f1?version=n1:50860965e9a42da3).

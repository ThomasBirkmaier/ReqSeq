title: "Jedes Element ist eine eigene Markdown-Datei"
spec-id: "D-015"

Jedes Element liegt als eigene Markdown-Datei vor.

Grund: Ein Element ist in sich abgeschlossen. Änderungen an verschiedenen Elementen geraten so nie in Konflikt, und jede Datei lässt sich mit üblichen Werkzeugen lesen, vergleichen und zusammenführen. Erfüllt [N-039](reqseq:6adc4ebc-49b9-4816-a28e-5ac4add9fdb2?version=n1:7af09370137a7fdc), konkretisiert [D-024](reqseq:6adc5a79-32fa-4834-88e9-f88d296ea3f1?version=n1:cfec41db4d2067b9).

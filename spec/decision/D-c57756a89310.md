title: "API und MCP-Server neben der App"

Neben der Desktop-App ([D-003](logreq:6ad39066-51e1-4f3a-8e17-b36e2db4dd01?version=n1:379da0e82ecf207a)) und der Kommandozeile (D-025) gibt es eine API und einen MCP-Server. Alle nutzen dieselbe Programmlogik. Die Oberfläche hat keine eigene Logik.

Die API ist für Pipelines und automatische Tests da, der MCP-Server für KI-Agenten. Eine Funktion gilt erst als fertig, wenn sie über alle Zugänge geht.

Beide werden mit dem Tool ausgeliefert und laufen lokal auf der lokalen Kopie ([D-002](logreq:6ad39064-0c17-44eb-b1b3-069ebda57ac6?version=n1:ad1ea38cedbd2481)), auch offline ([N-046](logreq:6adc50a3-2395-4867-bc28-4ac6a3af2b01?version=n1:ab31a56a17b696dd)).

Das Tool startet und steuert keine Agenten. Das geschieht außerhalb.

Grund: So lässt sich in der Entwicklung alles automatisch prüfen, bis hin zu ganzen Abläufen ([N-057](logreq:6adc5c63-608a-4196-b8c0-3037e8876029?version=n1:b988dd9f8baa094e)). Mit einer gemeinsamen Programmlogik können die Zugänge nicht auseinanderlaufen.

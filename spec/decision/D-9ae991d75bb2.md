title: "Statuswerte kommen aus dem Metamodell"
spec-id: "D-030"
---

Welche Statuswerte es gibt, legt das Metamodell fest. Das Standardmodell bringt Draft, Approved und Obsolete mit. Eine Organisation kann eigene ergänzen, zum Beispiel für eine laufende Änderung.

Das Tool setzt den Status nie selbst. Ein Mensch ändert ihn, das Review läuft per Merge Request ([D-024](logreq:6adc5a79-32fa-4834-88e9-f88d296ea3f1?version=n1:50860965e9a42da3)). Ob eine Änderung erlaubt ist, entscheidet zum Beispiel ein CCB außerhalb des Tools, wie bei [D-006](logreq:6ad47f0f-552c-42de-aa78-27c9c18f3d6b?version=n1:823aa9257f46151a).

Grund: Die Abläufe unterscheiden sich je Organisation. Ein typischer Ablauf: Eine Änderung geht durch das CCB, der Status verlässt Approved, und wenn alle betroffenen Elemente angepasst sind, wird er wieder Approved.

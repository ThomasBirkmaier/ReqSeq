title: "Hinweise werden bestätigt"
spec-id: "D-042"
---

Ein Hinweis zu einer Beziehung ist erledigt, wenn jemand ihn bestätigt. Das Tool schreibt dann die aktuelle Fassung und, wenn das Ziel im selben Repository liegt, den aktuellen Titel des Ziels in die Beziehung. Wird ein Ziel nur umbenannt, gibt es keinen Hinweis; die gespeicherten Titel von Zielen im selben Repository schreibt das Tool neu, wenn es die Datei der Quelle das nächste Mal schreibt.

Für Kern-Requirements, die eine Variante nur übernimmt, vergleicht das Tool mit der neuesten Baseline der Variante ([SR-103](reqseq:6adc7b15-79d2-4271-82c8-bc6b138c3884?version=n2:6f68955bf7b6a502) AK4, [D-039](reqseq:6adc691f-cfbf-4934-9504-21c1fc5849f7?version=n2:c39ce145802bd72b)). Der Hinweis ist erledigt, sobald eine neue Baseline der Variante gezogen wird.

Bestätigen lassen sich nur Hinweise auf eine veraltete Beziehung oder einen veralteten Verweis. Ein Hinweis zu einem übernommenen Kern-Requirement endet mit einer neuen Baseline der Variante; jeder andere Hinweis endet, wenn seine Ursache behoben ist (Entscheidung des Produktverantwortlichen, 2026-11-10: so, wie das Tool es umsetzt).

Grund: Ohne Bestätigung würde die Liste der Hinweise nur wachsen ([N-022](reqseq:6ad3a4c6-cb89-4fc6-acdf-ff0c8aad33ed?version=n1:0d48a780647af98d), [N-058](reqseq:6adc6158-7236-41ca-b932-21c9c00a91a6?version=n1:29c588c894a97115)). Für übernommene Requirements gibt es keine Beziehung, in der eine Fassung stehen könnte.

Das [Metamodell](reqseq:6ad4f970-8cdb-4504-a076-156f65bcba67?version=n2:0824c5d4ad47f4a6) wird über Befehle geändert, die es in allen Zugängen gibt ([D-029](reqseq:6adc5c64-fe36-4191-85d8-c57756a89310?version=n2:b68c1780920b121b)), nicht über einen eigenen grafischen Editor; in der App startet man sie in der Befehlszeile oder per Kontextmenü an der Stelle im Graphen des Metamodells ([SR-130](reqseq:c4978584-9ee8-46f1-83f8-be0fc7a3f15e?version=n2:7144ed0dd0febdac)). Eine Definition lässt sich nur entfernen, wenn kein Element sie nutzt, und Wertart und mehrere Werte einer Property lassen sich nur ändern, solange kein Element einen Wert hat, weil das Tool Element-Dateien nicht von selbst umschreibt ([SR-015](reqseq:6adc6ba8-8828-412d-80eb-80ceb7965407?version=n2:f037f246bcf71c8f)). Den Schlüssel einer neuen Definition schlägt das Tool aus ihrem Namen vor; danach ist er fest ([D-043](reqseq:6adc6922-7314-49bd-bfed-ff5f8a7211b4?version=n2:d496a4c7295aafde)).

Über jede Änderung am Metamodell entscheidet ein Mensch; ein Agent schlägt sie vor und führt sie nur aus, um eine ausdrückliche Entscheidung auszuführen, wie beim Status ([D-030](reqseq:6adc615b-272a-4377-82e5-9ae991d75bb2?version=n2:5086a4bc7d6ff7de)).

Grund: Wer das Metamodell nicht in einem Texteditor ändern will, braucht einen Weg im Tool. Befehle werden gleich bedient wie alle anderen ([D-077](reqseq:7a120e78-ad90-4f95-b966-6017460b8538?version=n2:4713bc40e4274c0a)), und Agents nutzen dieselben Befehle statt der Dateien.

Der Code des Tools liegt in einem eigenen privaten Repository auf GitHub (logreq). Es ist ein Monorepo mit getrennten Paketen für Programmlogik, Kommandozeile, API, MCP-Server und App ([D-004](logreq:6ad39067-1a40-41da-8816-1d199c4712f1?version=n1:0d5bb8245e87590d), [D-025](logreq:6adc58f4-fbf7-4c3d-84da-de15d00286a2?version=n1:aa83cee4e109580c), [D-029](logreq:6adc5c64-fe36-4191-85d8-c57756a89310?version=n1:240f9a68d1d72cf8)).

Das lokale Repository ReqSeq mit dem Mirror dieser Spec bleibt unverändert.

Grund: Die Agents brauchen einen Ort, an dem Code, Spec, Tests und Nachweise zusammen liegen. Das Repository ReqSeq hat keinen Server und enthält nur den Mirror.

Der Code des Tools liegt in einem eigenen Repository auf GitHub (ReqSeq). Es ist ein Monorepo mit getrennten Paketen für Programmlogik, Kommandozeile, API, MCP-Server und App ([D-004](reqseq:6ad39067-1a40-41da-8816-1d199c4712f1?version=n1:eb1699e1d167cb5c), [D-025](reqseq:6adc58f4-fbf7-4c3d-84da-de15d00286a2?version=n1:ddba1713410acb43), [D-029](reqseq:6adc5c64-fe36-4191-85d8-c57756a89310?version=n1:6a8d5db3a8ae28c2)).

Das lokale Logseq-Repository ReqSeq mit dem Mirror dieser Spec bleibt unverändert.

Grund: Die Agents brauchen einen Ort, an dem Code, Spec, Tests und Nachweise zusammen liegen. Das Logseq-Repository ReqSeq hat keinen Server und enthält nur den Mirror.

title: "Statuswerte können ungültig sein"
spec-id: "D-044"
---

Jeder Statuswert trägt im Metamodell das Kennzeichen „ungültig“, im Standardmodell nur Obsolete. Ungültige Elemente zählen weder für die Abdeckung noch für den indirekten Nachweis. In der Kette bleiben sie sichtbar. Für ein Element mit ungültigem Status meldet das Tool keine veralteten Beziehungen und Verweise ([SR-025](reqseq:6adc6bda-9ea9-4808-ae5b-f86ff6950b20?version=n2:c7773e821c4d62b5) AK5; Entscheidung des Produktverantwortlichen, 2026-11-10), keine Abweichung von einer Mindest- oder Höchstzahl von Beziehungen ([SR-152](reqseq:6f3fa565-e6b7-4799-99b4-e8d0c814f71b?version=n2:1b115905ed41df07) AK5; Entscheidung des Produktverantwortlichen, 2026-11-04, #808) und keine Beziehung auf ein abgelöstes Ziel ([SR-072](reqseq:6adc6d8d-cbb4-448b-9e57-5a64496da4d2?version=n2:e5cf598fa906aaed) AK2; Entscheidung des Produktverantwortlichen, 2026-11-11); ein fehlendes Ziel bleibt ein Fehler ([SR-089](reqseq:6adc7aff-bdd5-4f2c-a7c1-04c2b5de9209?version=n2:db65fb35626d569a)).

Grund: Organisationen ergänzen eigene Statuswerte ([D-030](reqseq:6adc615b-272a-4377-82e5-9ae991d75bb2?version=n2:5086a4bc7d6ff7de)). Das Tool muss trotzdem wissen, welche Elemente nicht mehr zählen. Das Kennzeichen gehört zu den fest eingebauten Bedeutungen ([D-012](reqseq:6ad4ffaa-f5ad-494e-97eb-a4c77c54dccc?version=n2:c94085aee93eede7)).

title: Kommandozeile neben der Web-Oberfläche

Neben der [Web-Oberfläche](reqseq:c89b295d-c3d5-49af-b6fd-c7444cdbb5ec?version=n2:8dfd92227dd91b55) ([D-083](reqseq:3fcc9c21-164a-4fa1-9d69-2ff8e055c094?version=n2:ab1a775d09c8134c)) gibt es eine Kommandozeile. Beide nutzen dieselbe Programmlogik, ebenso API und MCP-Server ([D-029](reqseq:6adc5c64-fe36-4191-85d8-c57756a89310?version=n2:b68c1780920b121b)).

Die Kommandozeile ergänzt bei automatischen Tests die Fassung im Datensatz ([D-026](reqseq:6adc58f5-a349-4870-af2f-971ec1cee679?version=n2:7ad54b00f062ca52)), prüft Beziehungen, Verweise und das Metamodell, zum Beispiel in einem Merge Request, und legt die Daten je Stand für externe Auswertungen ab ([D-008](reqseq:6ad4a03f-d7cf-4b85-98da-3f4431f33fe7?version=n2:84d08b2dbd1bf992)).

Grund: Diese Aufgaben laufen ohne Oberfläche in einer Pipeline. Eine gemeinsame Programmlogik hält das Tool klein, weil nichts doppelt gebaut wird.

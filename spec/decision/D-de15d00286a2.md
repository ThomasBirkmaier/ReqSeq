Neben der Desktop-App ([D-003](reqseq:6ad39066-51e1-4f3a-8e17-b36e2db4dd01?version=n1:2c202c002c84d9fd)) gibt es eine Kommandozeile. Beide nutzen dieselbe Programmlogik, ebenso API und MCP-Server (D-029).

Die Kommandozeile ergänzt bei automatischen Tests die Fassung im Datensatz (D-026), prüft Beziehungen, Verweise und das Metamodell, zum Beispiel in einem Merge Request, und legt die Daten je Stand für externe Auswertungen ab (D-008).

Grund: Diese Aufgaben laufen ohne Oberfläche in einer Pipeline. Eine gemeinsame Programmlogik hält das Tool klein, weil nichts doppelt gebaut wird.

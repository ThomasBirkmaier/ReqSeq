title: "Kommandozeile neben der App"

Neben der Desktop-App ([D-003](reqseq:6ad39066-51e1-4f3a-8e17-b36e2db4dd01?version=n1:2c202c002c84d9fd)) gibt es eine Kommandozeile. Beide nutzen dieselbe Programmlogik, ebenso API und MCP-Server ([D-029](reqseq:6adc5c64-fe36-4191-85d8-c57756a89310?version=n2:3795ac071493804f)).

Die Kommandozeile ergänzt bei automatischen Tests die Fassung im Datensatz ([D-026](reqseq:6adc58f5-a349-4870-af2f-971ec1cee679?version=n2:f99d3d6f08b13a10)), prüft Beziehungen, Verweise und das Metamodell, zum Beispiel in einem Merge Request, und legt die Daten je Stand für externe Auswertungen ab ([D-008](reqseq:6ad4a03f-d7cf-4b85-98da-3f4431f33fe7?version=n2:84d08b2dbd1bf992)).

Grund: Diese Aufgaben laufen ohne Oberfläche in einer Pipeline. Eine gemeinsame Programmlogik hält das Tool klein, weil nichts doppelt gebaut wird.

Was das Tool bewusst nicht abdeckt ([D-008](logreq:6ad4a03f-d7cf-4b85-98da-3f4431f33fe7?version=n1:e6f4415854befb32), [D-014](logreq:6adc4eb0-23e6-4e81-9ae8-e964fba47a8d?version=n1:8f7cfedac1f63c16), [D-018](logreq:6adc5041-c67d-4bae-832e-562f4f79bb1e?version=n1:2b9ca25bd86ab842), [D-024](logreq:6adc5a79-32fa-4834-88e9-f88d296ea3f1?version=n1:50860965e9a42da3)), übernehmen vorhandene Werkzeuge. Für jedes gibt es im Code-Repository ein lauffähiges Beispiel mit Integrationstest: Git-Server mit Merge Requests, Pipeline, Testwerkzeuge mit JUnit-Ausgabe, Ablage für Belege, Grafana für Auswertungen, Pandoc für Dokumente und ReqIF-Beispieldateien.

Das Tool bekommt dafür keine eigenen Funktionen.

Grund: So wird das Tool im echten Ablauf geprüft, und die Beispiele dienen später als Anleitung.

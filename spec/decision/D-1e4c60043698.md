Was das Tool bewusst nicht abdeckt ([D-008](reqseq:6ad4a03f-d7cf-4b85-98da-3f4431f33fe7?version=n2:84d08b2dbd1bf992), [D-014](reqseq:6adc4eb0-23e6-4e81-9ae8-e964fba47a8d?version=n2:882381883f0fb18e), [D-018](reqseq:6adc5041-c67d-4bae-832e-562f4f79bb1e?version=n2:bc7a78d5782a0371), [D-024](reqseq:6adc5a79-32fa-4834-88e9-f88d296ea3f1?version=n2:aa2bf102dceb7774)), übernehmen vorhandene Werkzeuge. Für jedes gibt es im Code-Repository ein lauffähiges Beispiel mit Integrationstest: Git-Server mit Merge Requests, Pipeline, Testwerkzeuge mit JUnit-Ausgabe, Ablage für Belege, Grafana für Auswertungen, Pandoc für Dokumente und ReqIF-Beispieldateien.

Das Tool bekommt dafür keine eigenen Funktionen.

Grund: So wird das Tool im echten Ablauf geprüft, und die Beispiele dienen später als Anleitung.

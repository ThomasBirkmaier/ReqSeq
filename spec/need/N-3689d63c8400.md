title: "Mehrere Agenten parallel"

---

Mehrere Agenten müssen gleichzeitig mit dem Tool arbeiten können, ohne sich zu stören, zum Beispiel um Szenarien oder Use Cases durchzuspielen. Jeder Agent arbeitet dabei auf einer eigenen lokalen Kopie ([D-002](logreq:6ad39064-0c17-44eb-b1b3-069ebda57ac6?version=n1:ad1ea38cedbd2481)); den Abgleich übernimmt die Versionsverwaltung ([D-014](logreq:6adc4eb0-23e6-4e81-9ae8-e964fba47a8d?version=n1:8f7cfedac1f63c16)).

title: "Mehrere Agenten parallel"

topic: "Betrieb und Leistung"
---

Mehrere Agenten müssen gleichzeitig mit dem Tool arbeiten können, ohne sich zu stören, zum Beispiel um Szenarien oder Use Cases durchzuspielen. Jeder Agent arbeitet dabei auf einer eigenen lokalen Kopie ([D-002](reqseq:6ad39064-0c17-44eb-b1b3-069ebda57ac6?version=n1:9c540adec22e0e1f)); den Abgleich übernimmt die Versionsverwaltung ([D-014](reqseq:6adc4eb0-23e6-4e81-9ae8-e964fba47a8d?version=n1:ccbefd504788a8ce)).

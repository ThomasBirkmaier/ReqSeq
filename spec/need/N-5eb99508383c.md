Im Merge Request muss sich automatisch prüfen lassen, ob noch Beziehungen, Verweise oder Nachweise auf eine alte Fassung eines Elements zeigen, bevor das Element wieder auf Approved gesetzt wird. Siehe [D-025](logreq:6adc58f4-fbf7-4c3d-84da-de15d00286a2?version=n1:aa83cee4e109580c).

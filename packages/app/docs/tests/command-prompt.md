# Tests: Command prompt

Part of [Tests](../tests.md). The behaviour is in [Minibuffer and command prompt](../command-prompt.md).

- `test/create-element.spec.ts` runs "Create element" on a copy of `SR-069/filter` and compares each result with the CLI and the file (`[SR-064/AK-xjg5]` to `[SR-064/AK-cs9n]`: only the required properties are asked after the title, the element is saved with them empty and the hints are shown, and "Add property" offers the rest after reopening).
- `test/command-line.spec.ts` runs the command prompt on `fixtures/SR-069/filter` (SR-121 AK2: the command chosen for a typed text is first the next time, also after a restart of the app; SR-121 AK1: "lae" puts "List all elements" first and Enter runs it; SR-133 AK1: with nothing typed, in an element and in a list, the nine expected commands without use and then "All commands…" (`sr-133-prompt-element-light.png`); SR-133 AK3 with SR-134 AK1: Escape in the first argument of a command chosen in "All commands" goes back to that list; "Bulk update elements" is found only on a list and a package page, and with a metamodel file that is no YAML no write command is found; `[SR-071/AK-j9gx]` "Bulk update elements" on every element shows the preview and asks "No", first and marked, and "Yes, apply" with "Writes 10 elements, skips 4 elements" and that Ctrl+Enter writes (`sr-071-confirm-light.png`); a held Enter writes nothing there, Enter on "No" and Escape go back to the value with the preview open, Ctrl+Enter with "No" marked writes, and the same change again, which writes no element, asks nothing and says so; `[SR-223/AK-gvv1]` "Confirm hints" on an element keeps the element shown and says "Confirmed 1 hint; 1 file written." in the command line, whose click opens the output (`sr-223-write-answer-light.png`)).
- `test/command-help.spec.ts` runs the explanation line of the command prompt on `fixtures/SR-069/filter` in the light theme: the line two text lines high with the marked command's summary, its optional arguments and help at the right, changing with the mark, empty without a hit and wrapped and cut with "…" in a narrow window (`[SR-210/AK-gqgt]`, `sr-210-explanation-light.png`, `sr-210-explanation-narrow-light.png`), an asked argument's description and the keys of its step, as high (`[SR-210/AK-t8sc]`, `sr-210-argument-light.png`), an action's own description, a covered command's summary and none for an element of Go to (`[SR-210/AK-r2d2]`), the row "All commands…" with its sentence and Enter, Ctrl+H and Ctrl+Enter doing nothing, and Enter listing every command alphabetically, typed text searching and cleared text bringing it back (`[SR-210/AK-r2d2]`, `[SR-133/AK-w7wd]`, `sr-133-prompt-empty-light.png`, `sr-133-all-commands-light.png`), Ctrl/Cmd+Enter and Enter in a list step (`[SR-108/AK-ch3r]`), Backspace in an empty input back one step as Escape (`[SR-134/AK-fmf6]`), and the command help on Ctrl+H: its slide-in time, its width, the dimmed and blurred hits, its font, its texts and the call on the command line, F1 and its link (`[SR-210/AK-wz9v]`, `[SR-145/AK-tbrz]`, `sr-210-help-light.png`), an action's description, key, catalog commands by display and its keyboard reference entry (`[SR-210/AK-r2d2]`), the keys and the wheel that scroll it, the keys and the click that close it, shorter, the keys that do nothing, typing, and copying its text (`[SR-210/AK-pxr7]`, `[SR-122/AK-kjhn]`, `[SR-122/AK-h65p]`, `[SR-122/AK-n8p6]`, `[SR-145/AK-mk0f]`, `[SR-134/AK-fmf6]`, `[SR-202/AK-dcyp]`, `[SR-202/AK-fgd8]`), and with reduced motion no motion (`[SR-210/AK-b1r5]`); `test/card-motion.spec.ts` checks that the card does not rise again for it and only grows upwards (`[SR-182/AK-ggcp]`).
- `test/command-line-mouse.spec.ts` runs the command line by mouse on `fixtures/SR-069/filter` through Chromium's input (`[SR-202/AK-vvw8]`: a click on the left edge, the middle and the right edge of the line opens it empty, focused, with the rows of Ctrl/Cmd+Shift+P; `[SR-202/AK-fgd8]`: after a click on "All commands…" the wheel over the card reaches every command, alphabetically and more than two cards high, without moving the selection; `[SR-202/AK-dcyp]`: a click on "Filter list", then on "Status" and on a status, and on "Show workspace status" gives the question, the filtered list, the modeline and the result buffer that Enter gives); a press on a hit released over the line opens no prompt again; the prompt opened by a click, in light, is saved as `command-line-mouse-light.png`).
- `test/path-completion.spec.ts` (SR-143) completes typed paths on a fixture workspace with folders made in the test's home and a temporary folder: `[SR-143/AK-dfk5]` "Open workspace" and `~/pro`, a chosen folder completes the input and the prompt stays open; `[SR-143/AK-zhpy]` "Export ReqIF" with a relative, an absolute and a `~` output, which the export then writes into the home folder; `[SR-143/AK-r68p]` folders before the best-matching file, marked letters, and a light screenshot `test-results/electron/screenshots/path-completion-light.png`; `[SR-143/AK-hfz0]` a missing folder (Enter still takes the path) and, not on Windows, one without read rights; 10,000 entries listed after the separator key and narrowed by a letter, with the times as an annotation (`[SR-143/AK-rqjp]`, at most 100 ms each, is asserted in `test/perf/path-completion.spec.ts` of the performance suite, which types the same keys through `test/support/path-prompt.ts` and records the times, because the times are evidence only on the reference machine, ADR-0011, #1128); `[SR-143/AK-gdy1]` dot names only after a typed ".".
- `test/workspaces.spec.ts` runs "Open workspace" on two fixture workspaces, with a list of recent workspaces seeded in the test's cache folder (`LaunchOptions.recent`; `[SR-131/AK-y2k4]`: the list, the most recent first, the open one marked, narrowed as typed; `[SR-131/AK-cssj]`: the chosen workspace in the same window, and "Go to" finds only its elements; `[SR-131/AK-f722]`: a root that is gone marked "not found", choosing it keeps the open workspace; `[SR-131/AK-w8h0]`: the same list after a restart without a workspace, `LaunchOptions.withoutWorkspace`; `[SR-131/AK-nkm5]`: text typed in an element of the first workspace is in its file when the second opens, from the prompt and from File > Open Workspace with the dialog answered in main; `[SR-131/AK-sxyz]`: a typed folder inside the second workspace opens it, first in the list afterwards, and a folder without a workspace opens nothing).
- `test/connect-agent.spec.ts` runs "Connect AI agent" (SR-227) on a fixture workspace: `[SR-227/AK-cw0k]` compares the app's `server` with the CLI's on the app's Electron and has it answer `initialize`; `[SR-227/AK-cxxc]` the client step with the six clients and the buffer for Claude Code with the CLI's answer, block and next step, Ctrl/Cmd+Shift+C puts the block on the clipboard (the machine's clipboard is written back), the screenshot `connect-agent-light.png`, and, in a window 480 px wide, no part of the buffer wider than its column (#2169); `[SR-225/AK-rqcg]` a start without a workspace that asks the recent workspace, opens it and then asks the client, and the label that names "Create workspace" without a recent workspace.

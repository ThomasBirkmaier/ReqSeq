# Tests: Editor

Part of [Tests](../tests.md). The behaviour is in [Editor (SR-065)](../editor.md).

- `test/editor.spec.ts` runs the editor on the built app (`[SR-065/AK-z3qg]` live preview and source on the cursor line, `[SR-065/AK-m5px]` typed text saved and read back as CommonMark with GitHub extensions by micromark, undo, drafts saved when another buffer is shown (`[SR-105/AK-p4gn]`), no request). `test/autosave.spec.ts` checks saving without a save command on `fixtures/SR-069/filter`: `[SR-105/AK-p4gn]` the file a second after the last key and at once on leaving (another buffer, Go to, Close buffer, Close all buffers), `[SR-105/AK-dmrq]` undo and redo of the text, a text box and a choice after they were saved and after another buffer was shown, `[SR-105/AK-ptsm]` no save button and no dialog, `[SR-105/AK-phcy]` a read-only file keeps the input, the modeline names the reason and the first close keeps the window open; it takes the screenshots of `not saved` in light and dark. `test/editor-screenshots.spec.ts` takes the screenshots of `verification/SR-065/`. `test/folding.spec.ts` folds and opens sections and jumps to headings (`[SR-191/AK-twyq]` "Fold section" up to the next heading of the level, the toggle under the pointer, the file unchanged, `[SR-191/AK-wyyz]` "Unfold section", a click on the hint and "Go to heading" into the fold, `[SR-191/AK-hgpr]` the headings in the prompt, a fuzzy query, the cursor on the chosen one; `[SR-193/AK-qhkh]` `[SR-193/AK-wyfx]` Tab on a heading folds and unfolds with the focus and the file unchanged, `[SR-193/AK-vh54]` Tab off a heading indents a list item and adds a table row); it writes `folded-section.png`. `test/neighbourhood.spec.ts` also has `[SR-193/AK-qhkh]` `[SR-193/AK-n5jp]`: Tab, Right and Left on the selected tree row. `test/typography.spec.ts` measures the column of a text with a long paragraph, a long word, a wide table and code (`[SR-192/AK-wvh6]` at most 72 zeros wide and centred in a window of 1400 px, `[SR-192/AK-s3tb]` the full width without a sideways scroll at 420 px, the table scrolling in its own box, `[SR-192/AK-hyxb]` the faces of code, text, headings and tables). `test/renderer-crash.spec.ts` kills the renderer process while a conflict holds input back (#270) and reads the page loaded again through the main process, because Playwright gives up a page whose renderer crashed.
- `test/criterion-keys.spec.ts` edits the acceptance criteria of a requirement with keys on `fixtures/SR-069/filter` (the metamodel gets the meaning `acceptance-criteria`) and reads each save with `element get`: `[SR-204/AK-syqv]` reword, Alt+Down, a split, a merge and an emptied line; `[SR-204/AK-pks0]` a new line with the text of a criterion, two lines pasted, and a line cut and pasted back; `[SR-204/AK-gnnw]` undo after a save, also after another buffer was shown.
- `test/criterion-references.spec.ts` shows the references of the acceptance criteria on `fixtures/SR-069/filter` (the metamodel gets the meaning `acceptance-criteria`; without `identifier`, the references use the short ID) and compares them with `element get`: `[SR-205/AK-npsp]` the marks at the line ends, the bare key of a key two criteria carry, and the mark of a new line after its save; `[SR-205/AK-zvtb]` "Copy criterion reference" from the context menu of a line and from the command prompt, read from the system clipboard. It writes the light screenshots `criterion-keys-light.png` and `criterion-reference-menu-light.png`.
- `test/affected-count.spec.ts` changes the text of "Show wind speed" on `fixtures/SR-024/affected` (`[SR-024/AK-mf7x]`): autosave says `Saved SR-00b001 Show wind speed: 2 elements directly affected`, the CLI's `element update` gives `affected: 2` for the next change, and the light screenshot `sr-024-affected-light.png` is written; leaving the element for another one says the same (`[SR-024/AK-mf7x]`); a change of only the title after it says `Saved SR-00b001 Show wind speed now` without a number (`[SR-024/AK-jt0q]`).
- `test/outside-changes.spec.ts` and `test/outside-conflict.spec.ts` change a shown element through MCP, the CLI and the file system (`[SR-116/AK-w091]`, `[SR-116/AK-g84w]`, `[SR-106/AK-m800]`; `[SR-106/AK-ydc8]` both choices with the file checked after each, `[SR-106/AK-v420]` a deleted file, `[SR-116/AK-vf1x]` an MCP change under input) and take the screenshots of the block "On disk" in light and dark.

# Keys

Part of the [`@reqseq/app` README](../README.md).

The user documentation lists these keys on its generated page "Keyboard shortcuts" (SR-139 AK5), from `shortcutReference` (`shortcut-reference.ts`): the actions' shortcuts (`actions.ts`), the letters after the prefix (`bindings.ts`), and the tables next to the handlers that have no action, `PROMPT_KEYS` (`prompt-keys.ts`), `LIST_KEYS` and `HISTORY_KEYS` (`keys.ts`), `GRAPH_KEYS` (`graph-nav.ts`), `ELEMENT_KEYS` (`element-keys.ts`) and `PREFIX_KEYS` (`bindings.ts`). A new key of a handler goes into its table, whose test ties it to the handler.

| Keys (Ctrl, or Cmd on macOS; on macOS the physical Ctrl key with a letter is never one of these shortcuts: it stays the editor's and the lists' key, so Ctrl+P there moves the caret or the selection and never jumps) | |
| --- | --- |
| Ctrl/Cmd+Shift+P | Command prompt: the app's actions that apply to the shown buffer (filter, sort, close, ...); without a workspace only "Open workspace" |
| Ctrl/Cmd+P | Go to an open buffer (the most recent first, so Enter goes back) or to an element (SR-115 AK1): after the open buffers the elements shown last that are no longer open, newest first (the recent elements of the overview, with the names the overview read or they were shown with; the prompt asks core nothing when it opens, so the search of the typed text is not queued behind reads; one that a read finds gone, in the overview or in its buffer, is left out until the overview reads it again, #681), then the hits of `element.search` for the typed text. Enter typed before the hits of the text have arrived waits for them and opens the first one (SR-119 AK1: Ctrl+P, text, Enter). The physical Ctrl+P in a list with a selected row moves the selection instead, on every platform (SR-122 AK5); with no row selected it jumps on Linux and Windows. On macOS only Cmd+P jumps, always; the physical Ctrl+P never does (product owner decision, 2026-10-27, #543). "Go to element or buffer" in the command prompt always jumps |
| Ctrl/Cmd+Shift+F | Search elements |
| Ctrl/Cmd+K, then a letter (macOS ⌘K) | The prefix key (SR-109 AK3, SR-121 AK3; the assumption of #472, `bindings.ts`): E "Create element", R "Create relation", T "Set status", H "Confirm hints", L "List all elements", O "Show overview", F "Filter list by type", S "Sort list", B "Close buffer", where the command applies (the four write commands not in a read-only workspace); the letter bare or with Ctrl/Cmd held. After half a second without a key the minibuffer shows the possible next keys with their commands; Escape ends it. The command prompt shows the key next to the command („Ctrl+K L“). The letter never reaches the text or a box. Not while a prompt is open |
| Ctrl/Cmd+Shift+G | On an element or its neighbourhood: its graph (SR-111); on the graph: back to the element |
| Up, Down, Left, Right, Page Up, Page Down, Home, Enter, `+`, `-` (graph) | Follow a link up or down, go through a layer, from layer to layer, to the element; open the selected box as the current element; one level more or less |
| Up, Down, Left, Right, Page Up, Page Down, Home (metamodel) | Follow a curve up or down, go through a layer, from layer to layer, to the first type |
| Ctrl/Cmd+Shift+O | Follow agent: show the element an agent read or changed last through the API or MCP (SR-117); again: stop following |
| Ctrl/Cmd+J | On an element: its neighbourhood (SR-107); on the neighbourhood: back to the element |
| Ctrl/Cmd+T | On a list: show it as a traceability matrix (SR-125); on the matrix: back to the list; on a package page: its members as a matrix; on the metamodel: graph and text (SR-130), the selected type kept. On macOS only Cmd+T; the physical Ctrl+T stays CodeMirror's "transpose" in the text editor |
| Right, Left (matrix) | Step through the row element and the relations of the selected row; Enter or a click opens the element there |
| Right, Left | In the neighbourhood: open the tree row (shows its children), close it or go to the parent row |
| Up, Down, Page Up, Page Down, Home, End | Select a row (on a package page, Down on the page enters its elements). A fresh list has no row selected: the first Down selects the first row, and Enter opens the first row |
| Enter | Open the selected row (in a prompt: run the candidate) |
| Escape | End the prompt |
| Tab | In a prompt, the next candidate |
| Ctrl+N / Ctrl+P (the Ctrl key, also on macOS) | In an open prompt: the next / previous hit, like Down / Up (SR-122). The prompt takes these keys: Ctrl+P is not "Go to" while a prompt is open. In a list of the main window (overview, list, search result, matrix, package page, neighbourhood, result of a command): the next / previous row, like Down / Up; with no row selected Ctrl+N selects the first row and Ctrl+P is still "Go to" on Linux and Windows (on macOS it does nothing there). On a package page Ctrl+N enters its elements at the first one (Down enters at the row used last), and Ctrl+P on the first one goes back to the page. Cmd+N / Cmd+P do not move a selection |
| Alt+N / Alt+P (macOS ⌥N / ⌥P) | The next / previous buffer in the order the buffers were opened, after the last the first (actions "Next buffer" and "Previous buffer", SR-115 AK5). Also while typing in the text editor or a property box: the key types nothing there, so on a German Mac "~" (⌥N) is typed with the slash menu or pasted. In an open prompt the keys are the prompt's and type what the layout gives. With one buffer open the app does not take them: they switch nothing, and in the text editor on macOS they type what the layout gives (⌥N "~" on a German Mac) |
| Ctrl/Cmd+S | Save the text and the property boxes of the shown element now (action "Save element"; they are also saved one second after the last input and when the buffer is left, SR-105) |
| Ctrl/Cmd+Alt+A (macOS ⌥⌘A) | On an element, add a property it lacks (action "Add property", SR-104). Not Cmd+Shift+A: with text selected, macOS gives it to the service "Search man Page Index in Terminal". On Windows, Ctrl+Alt is AltGr: where AltGr+A types a letter (Polish ą), the letter wins and "Add property" is in the command prompt |
| Enter | On an element, put the cursor into the text (action "Edit text"; pressed while the element loads, once its text is shown); on a property box that has the focus, put it into the box, and on the box of a choice or relation property open the prompt for its value; on the field of the title, put the caret at the end of the title (action "Edit title"; a title that cannot be edited goes to the text); in the title, back to its field |
| Up, Down (on macOS also Ctrl+P, Ctrl+N) | In the text and in a property box at the first and last line: to the box before and after (from the first line of the text up into the title, or onto its field when it cannot be edited; from the title down into the text); on a field that has the focus: to the field before and after |
| Ctrl/Cmd+Enter | On an element, open the element of the inline reference at the cursor, or the first reference of the Markdown property box that has the focus; in a box, the reference at the caret; on a focused target link of a relation box or group, that target (action "Follow reference") |
| Ctrl/Cmd+Shift+Enter | On an element, the list of the elements with the value at the cursor, or the prompt "Elements with" among its values (action "List elements with this value", SR-132). On macOS only Cmd+Shift+Enter |
| Ctrl/Cmd+click on a value | On an element, the list of the elements with the value clicked in a property box (SR-132, #235). On macOS only Cmd+click |
| Ctrl/Cmd+Shift+C | On an element, copy the field with the cursor, else the ID, as text, one value per line (action "Copy field", SR-128). Every field also has a copy symbol at its right edge, seen on hover or focus |
| Escape | In the text, back to the element; in a property box, back to the box, and from the box to the element; in the title, back to its field |
| `/` | In the text, at the start of a line or after a space: the slash menu (SR-129) with the Markdown elements at the caret |
| (slash menu open) Down, Up, Tab, Ctrl+N / Ctrl+P, Enter, Escape | Choose, take the entry (one undo step), close the menu and leave the `/` as typed |
| `[[` | In the text and in a Markdown property box, outside code, links and addresses: the prompt "Insert reference" (SR-066); the pick replaces the `[[` with the reference, Escape leaves the `[[` as typed |

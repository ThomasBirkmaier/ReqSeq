# Tests

Part of the [`@reqseq/app` README](../README.md).

- Unit tests (`src/**/*.test.ts`, Vitest) use fake Electron objects, a Node `MessageChannel` and happy-dom for React. The `.ts` modules have an 80 % threshold for the package (ADR-0016, ThomasBirkmaier/ReqSeq-archive#752); React components (`.tsx`) have no coverage threshold, Playwright covers them (ADR-0016, ThomasBirkmaier/ReqSeq-archive#537). happy-dom animates (`Element.animate`), so the DOM tests start with "reduce motion" set (`scripts/test-support/reduced-motion.mjs`): a switch of buffers stands at once there. The tests of the motion turn it on (`buffer-slide.test.ts`, the SR-212 blocks of `buffer-cycle-app.test.ts` and `follow-app.test.ts`; `list-drawn.test.ts` checks when a list counts as drawn).
- `test/app.spec.ts` (Playwright, `_electron.launch`) runs the built app on fixture workspaces:
  - it starts and shows the status;
  - `invoke` gives what the CLI gives (`[SR-080/AK-bb1t]`);
  - the bridge offers the catalog commands, the events, `copyText`, `pasteText` and the recent workspaces, and no delete (`[SR-099/AK-nbg9]`);
  - the renderer has no Node;
  - the session cancels a non-local request, and the app makes none itself (`[SR-078/AK-tnbh]`);
  - `reqseq-file:` does not leave the repository;
  - navigation and new windows are denied;
  - a stopped core process is started again;
  - without a workspace, the app names the keys that open one (Ctrl/Cmd+O, Ctrl/Cmd+Shift+P; the menu bar is hidden on Windows and Linux) and saves a light screenshot `no-workspace-light.png`; a folder without a workspace, chosen in the folder dialog, names the key of "Initialise workspace" (`empty-folder-light.png`).

  The JUnit file is `test-results/junit-electron.xml` (CI jobs `electron-shard` and `electron-macos-shard` in two shards, `electron-windows-shard` in three, shard n of k with every k-th file (`ELECTRON_SHARD=1/2` runs shard 1 of 2 locally), under `xvfb-run` on Linux).

# Tests

Part of the [`@logreq/app` README](../README.md).

- Unit tests (`src/**/*.test.ts`, Vitest) use fake Electron objects, a Node `MessageChannel` and happy-dom for React. The `.ts` modules have an 80 % threshold for the package (ADR-0016, #752); React components (`.tsx`) have no coverage threshold, Playwright covers them (ADR-0016, #537).
- `test/app.spec.ts` (Playwright, `_electron.launch`) runs the built app on fixture workspaces:
  - it starts and shows the status;
  - `invoke` gives what the CLI gives (`[SR-080/AK2]`);
  - the bridge offers the catalog commands, the events, `copyText` and the recent workspaces, and no delete (`[SR-099/AK1]`);
  - the renderer has no Node;
  - the session cancels a non-local request, and the app makes none itself (SR-078);
  - `logreq-file:` does not leave the repository;
  - navigation and new windows are denied;
  - a stopped core process is started again;
  - without a workspace, the app says how to open one.

  The JUnit file is `test-results/junit-electron.xml` (CI jobs `electron-shard` on Ubuntu in two shards and `electron-platform`, under `xvfb-run` on Linux).

- `test/main-view.spec.ts` runs the main view on `fixtures/SR-069/filter` and compares it with the CLI: the list, the tree, a filter, the search and an element (`[SR-100/AK1]` checks that nothing but the buffer, the modeline and the minibuffer is permanently visible; the SR is verified by inspection, `verification/SR-100.md`).
- `test/editor.spec.ts` runs the editor on the built app (`[SR-065/AK1]` live preview and source on the cursor line, `[SR-065/AK2]` typed text saved and read back as CommonMark with GitHub extensions by micromark, undo, drafts saved when another buffer is shown (`[SR-105/AK1]`), no request). `test/autosave.spec.ts` checks saving without a save command on `fixtures/SR-069/filter`: `[SR-105/AK1]` the file a second after the last key and at once on leaving (another buffer, Go to, Close buffer, Close all buffers), `[SR-105/AK2]` undo and redo of the text, a text box and a choice after they were saved and after another buffer was shown, `[SR-105/AK3]` no save button and no dialog; it takes the screenshots of `not saved` in light and dark. `test/editor-screenshots.spec.ts` takes the screenshots of `verification/SR-065/`.

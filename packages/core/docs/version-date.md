# Version date (`src/model/version-date.ts`)

Part of the [`@reqseq/core` README](../README.md).

`versionDates({ workspace, layout, metamodel }, requests)` gives, for each (repository, file, element UUID, version), the committer date in UTC of the newest commit that started that version (the file held the element with it there, and no parent had it), or `null` (ADR-0005 "Version date": which commits count, starts, how embedded images count at an old commit, when there is no date). One walk per (repository folder, file, UUID) and HEAD lists the commits that changed the file or an image its texts embed, and the merges whose sides do not all lead to the same evaluated commit (`log` is asked for the folders of these paths, the paths are picked from its answer) (`fileHistory` again when a text embeds an image not walked yet; a request with the current `text` walks its images from the start, as `element.get` does). Versions are computed lazily, newest commit first in growing rounds, until the asked version's newest start is certain; each round is one `info` and one `read` for the texts and the same for the image blobs, on one `openObjectReader` per call. The walks are a workspace state (`version-dates`, reset with the metamodel and the layout; reset or close stops their git processes); they stay while `headFiles` gives the same stamp or HEAD the same commit, and a new HEAD replaces the walks of its repository. A walk git could not finish because it timed out, was stopped or is missing is dropped; one Git refused for another reason stays `null` until HEAD moves. A call waits for its walks (no time limit besides those of the git calls), so the same request gives the same answer at the same HEAD (D-029). `prepareVersionDates(context, walks)` starts the walks without waiting, so `element.get` with `versionDate` lets git read the history while it builds the view. A repository folder without a `.git` entry in it or above it starts no process; one below the top level of its work tree gets the dates of that repository (#377).

# Docs-site block (`src/docs-site/`)

The offline documentation site that ships with a delivery (SR-141, ADR-0017 "Offline build"). Exported as `@reqseq/core/docs-site`, imports only `node:*` and reads only, so every way in (`reqseq serve docs` through `startDocsServer` of `@reqseq/api`, later the app) serves the same bytes by the same rule. It is no catalog command: it serves fixed delivery files, not values of a workspace (ADR-0017).

- `openDocsSite(folder)`: the site in `folder` (symbolic links of the folder resolved), or `undefined` when it has no `index.html`. `respond(target)` answers a raw request target and never rejects.
- `siteSegments(target)`: the request target without query and fragment, decoded once, split at `/`. Refused (no file): a target not starting with `/`, a bad escape, an empty segment, `.`, `..`, a segment starting with `.`, and one with `\`, `:` or a control character (NUL too). A trailing `/`, or a last segment without extension, means its `index.html`.
- A file is served only when it lies below the root both lexically and after `realpath` (a link out of the site is refused), is a regular file, at most `MAX_DOCS_FILE_BYTES`, and has an extension of `DOCS_MEDIA_TYPES` (Pagefind's data files as `application/octet-stream`). Anything else gets `404.html` with status 404, or `Not found` as text when the site has none.
- Headers of every response (`docsHeaders`): `x-content-type-options: nosniff`, `content-security-policy`, `referrer-policy: no-referrer`, `cache-control: no-cache`. The CSP (`docsContentSecurityPolicy`) allows scripts, styles, images and fetches from the site only, `'wasm-unsafe-eval'` for Pagefind, `data:` images (Starlight's CSS), `style` attributes (Starlight sets CSS variables in them), and nothing for objects, frames, framing, forms and `<base>`. An HTML page's own inline scripts are allowed by their SHA-256 hashes, computed from the page served (`inlineScripts`), so a script put into the page later does not run.
- `commandPagePath(name)`: `reference/commands/<commandSlug(name)>/`, the page the generator (`packages/docs`) writes for a catalog command.

Tests: `src/docs-site/site.test.ts` on a fixture site (the traversal cases, a link out of the site, an unknown type, the size cap, the 404 page).

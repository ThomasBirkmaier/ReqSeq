# Graph block (`src/graph/`)

The graph of one element (SR-111) as `trace.graph` gives it, the words the app's graph shows, and the Mermaid text of the element and metamodel graphs (SR-151), which uses the same words. It sits above `evidence` and `hints`, because the marks and the verification of the nodes come from there.

- `elementGraphOf(workspace, input, command)` (`element.ts`): the output of `trace.graph` for its input without `withEvidence`, the walk, marks and verification as [trace](trace.md) "Graph" describes, with what the evidence summaries are read from; problems and errors name `command`, the command that asks. The evidence summaries are `trace.graph`'s own (`commands/trace/graph.ts`).
- Words (`words.ts`, `@reqseq/core/graph-words`, imports only types and `evidence/degree-text.ts`): `MARK_WORDS`, `statusOf`, `ringOf` and `verificationWords` (SR-136: "verification open 2 of 3", "verification 60 %"), `shownId` (SR-084 AK4), `typeName`, `relationNames`, `propertyNameKey`, `kindName` and `REFERENCE_NAME` (SR-154 AK1). The app imports them.
- Mermaid (`mermaid.ts`, commands `trace.mermaid` and `metamodel.mermaid`, catalog field `textOutput: mermaid`): `elementMermaid(graph, typeNames, kindNames)` writes `flowchart BT` (parents above, SR-111 AK1), one node `n0`, `n1`, … per node of the output in its order, labelled "<shown ID> · <type>", the title, and the marks and verification words when there are any; `classDef element stroke-width:3px` frames the element (D-062: no colour); one edge per edge of the output from the source to the target, labelled with `kindName` and "· outdated", inline references dashed. The evidence summaries are left out (SR-151 AK1). The first lines are `%% truncated: …` when `truncated` is set (AK6) and `%% incomplete: …` when `incomplete` is. `metamodelMermaid(output)` writes one node per box of `metamodelGraph` ("<name> (<prefix>)", then the properties with "(inherited)"; `any` for "Any type"), one edge per ordered pair with one `<br/>` line per `linkLabel` (AK2). `trace.mermaid` takes the names of the types and kinds from `metamodelOutput`; `metamodel.mermaid` gives the problems of `metamodel.get`, also while the metamodel is missing or faulty.
- Escaping (`nodeText`, `edgeText`): labels are quoted; in a node label `#` → `#35;` first, then `&`, `<`, `>`, `"`, `:` and `{` as Mermaid entities, and each node label holds a raw `<br/>` so Mermaid decodes them; in an edge label only `&`, `<` and `>`, and `"` becomes `'` (a `#word;` in the name of a kind or property shows as an entity: a known limitation). Control characters and line separators become one space. LF, no trailing spaces, a final newline: the same output gives the same bytes on every platform (AK4). The CLI prints the text alone (ADR-0009).

Tests: `src/graph/mermaid.test.ts` (AK1, AK2, AK6, the escaping), `src/graph/words.test.ts`, `src/metamodel/graph.test.ts`; `[SR-151/AK4]` in `packages/cli/test/cross-access.test.ts`.

**Ready for a first pilot project.**

- **Relations right away.** Set an element's relations when you create or change it, naming the target by its short ID or identifier. `reqseq:` links in the text find their target the same way.
- **Fields in one step.** On the command line, `--set key=value` sets any field, and `--text @file` takes the text from a file.
- **Numbered lists.** Lists such as acceptance criteria are numbered, so you can point to a single item.
- **Fewer needless changes.** Changing the verification method of a requirement no longer makes it a new version, so links to it stay current.
- **Your own types.** A new guide shows how to extend the metamodel.

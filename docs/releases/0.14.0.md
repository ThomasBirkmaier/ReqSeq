**The web UI shows more of what needs a look: the changes since the last baseline on the overview, and each element's problems and verification status on its page.**

- **Changes since the baseline on the overview.** The overview counts the changes since the newest baseline and opens their list with one click, also in a narrow window, next to the share of verified requirements.
- **Problems and verification on the element page.** The element page lists the element's problems, grouped by kind, and shows for each acceptance criterion whether it is verified. An opened group stays open while you edit the workspace.
- **Copy one criterion.** Each acceptance criterion has its own Copy button, which copies it with its reference; Copy all still copies all of them.
- **Desktop shell.** On Windows the shell no longer looks for a proxy at start, and when the web engine cannot open the window it ends with a reason instead of waiting silently. On macOS a hairline separates the title bar, and on every system the window no longer scrolls past its frame.
- **Faster in large workspaces on Windows.** Following a long chain of relations and the first open of an element after a start take less time with 50,000 elements.

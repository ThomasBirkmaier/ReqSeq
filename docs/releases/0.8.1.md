**Verification down to each acceptance criterion.**

- **Status per criterion.** Test results and manual checks can name the acceptance criteria they prove, and ReqSeq shows the verification status of each criterion, in baselines and in the traceability matrix too.
- **Grouped lists.** Group a list by type, status, package or any property, from the list itself or the command line.
- **Lists at a glance.** Lists stand in a quiet column under a heading, with the coverage of the shown elements above them. A package page can be filtered.
- **Tool info** shows the version, the build and the open workspace.
- **Readable terminal output.** The command line prints elements, lists, hints and problems in a clear layout.

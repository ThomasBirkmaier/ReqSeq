**Fixes after 0.11: the agent guide arrives in full, and the HTML export reads well on every page.**

- **Agent guide and skill file.** The app shows the agent guide in full instead of one cut-off line, and writes the skill file with one Enter. The MCP server sends the rules and points the agent to the guide, so a client that cuts long instructions loses nothing. The skill file now says that the project's own rules take precedence: write it again in an existing workspace to get this.
- **HTML export.** Lists have aligned headers, styled controls and badges, and fit a phone. Element pages show the baseline difference word by word and fold the evidence. Package pages show their elements with badges, baseline pages fit the window, and the variant comparison lists the requirements that stand in some variants only.
- **Answers.** Very long answers on the command line no longer end in an internal error, and answers name the elements of the input by their ID, also when the input gave a UUID.
- **Output page.** "Hints per kind" shows each count with the title of its kind.

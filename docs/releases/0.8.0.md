**Evidence where you need it, clearer messages and much faster large workspaces.**

- **Evidence along the chain.** The trace chain shows the test cases and test runs under each requirement, the requirement page lists its evidence, and the graph and the traceability matrix show tests and verification. A validation can be recorded as inconclusive, with its reason.
- **A stricter metamodel.** It can set how many relations of a kind an element must or may have, and how many entries a list may hold. The traceability matrix shows gaps only where a relation is expected.
- **Clearer messages.** Hints and problems start with the element they are about, faulty files are named with the field at fault, and all hints of one kind can be confirmed at once after a review.
- **Faster with many requirements.** Large workspaces react much faster after a change, and the command line starts faster.
- **Please update together.** This version stores the versions of linked requirements in a new form that ignores other links' version numbers, so elements that link to each other no longer keep each other outdated. Older versions of ReqSeq do not understand it, so everyone working on one workspace, and its pipeline, should update at the same time.

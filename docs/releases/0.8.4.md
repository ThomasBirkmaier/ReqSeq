**Right-click anywhere, and see progress at a glance.**

- **Context menus.** Right-click a word in the text, a field, an element, a list, the graph or the matrix to see what you can do there.
- **Progress in lists.** Each requirement in a list shows its verification status and a small progress ring. On the requirement page, older evidence that no longer counts is folded away.
- **Tidier lists.** Fold elements in chosen statuses, such as rejected or obsolete, to the end of a list.
- **Quicker writing.** The slash menu opens like the command line and inserts today's date or a date from a calendar. Tab folds and unfolds the section you are on, and the command line now also works with the mouse.
- **About ReqSeq** shows version and build in a window of its own, ready to copy.

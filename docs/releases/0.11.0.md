**Publish your requirements as a website, connect your AI agent in one step, and shape the metamodel with commands.**

- **HTML export.** One command writes the whole workspace as a static website that works offline, with a page per element showing its fields, criteria, evidence, open hints and neighbourhood, plus lists, package pages, baselines with their changes, and a search. ReqSeq's own spec is published this way with each release.
- **Get started and connect an AI agent.** Without a workspace, the app opens a start buffer with "Open workspace…", "Create workspace" and "Connect AI agent", which shows the ready-made MCP setup for your client to copy; a green dot in the modeline shows a connected agent. Workspace init writes the skill file and the evidence location, and the workspace check now warns when no evidence location is set and names the call that renews an older skill file.
- **Metamodel commands.** Add, change and remove types, properties, relation kinds and statuses in the app as in the CLI, API and MCP, step by step in the command prompt or from the metamodel graph; a definition stays while an element still uses it. A ReqIF import keeps the source's own types and attributes, and `reqif export --source-model` writes back in that model.
- **Answers first.** Every command output opens with its answer sentence, counts open as lists of their elements, and next steps run from the output page. A command can act on the elements another command's output gives, and "Show changes since baseline" and "Prepare baseline" cover the work around a baseline.
- **Search finds what is meant.** Words in quotes match as a phrase, a word is found inside longer words, and a search for a designation also finds elements that use another one, such as a synonym or translation the metamodel defines. Search also finds and names acceptance criteria.

**Publish your requirements as a website, connect your AI agent in one step, and shape the metamodel with commands.**

- **HTML export.** One command writes the whole workspace as a static website that works offline: an element page with every field, criterion, evidence and open hint, its neighbourhood of parents, children and incoming relations, lists, package pages, baselines with their changes, and a search. ReqSeq's own spec is published this way with each release.
- **Get started and connect an AI agent.** Without a workspace, the app opens a start buffer with Open, Create and Connect; Create sets up a workspace in one step. "Connect AI agent" shows the ready-made MCP setup for your client to copy, and a green dot in the modeline shows when an agent is connected. Workspace init writes the skill file and the evidence location, and the agent guide tells an agent how to work with ReqSeq from need to evidence.
- **Metamodel commands.** Add, change and remove types, properties, relation kinds and statuses in the app as in the CLI, API and MCP, step by step in the command prompt or from the context menu of the metamodel graph. A definition stays while an element still uses it, and the metamodel shows how many elements use each one. A ReqIF import keeps the source's own types and attributes, and `reqif export --source-model` writes back in that model.
- **Answers first.** Every command output opens with its answer sentence, then its problems; counts name their elements and open as lists, and "Show details" and "Copy as JSON" give the rest. Evidence status is an output page with the verification status below each row. Next steps of an output run from the output page, and the output of a command can be the selection of a list. "Show changes since baseline" and "Prepare baseline" cover the work around a baseline.
- **Search finds what is meant.** Words in quotes match as a phrase, a word is found inside longer words, other designations and synonyms count, hits only by type or status name come last, and search finds and names acceptance criteria.

**The documentation now travels with ReqSeq.**

- **Help without the internet.** Every download contains the documentation of its own version. Help in the menu or F1 opens it in your browser, and `reqseq serve docs` serves it on your own computer.
- **New guides.** Step-by-step guides on opening or creating a workspace, finding and filtering elements, reviewing and approving a requirement, managing a product variant, freezing a release and exchanging requirements through ReqIF, plus an overview of the app and of the command line, API and MCP.
- **Verification badges.** The requirement page shows the verification status of the core and of each variant as small badges.
- **A clearer start.** Without an open workspace, the app tells you which keys open one.

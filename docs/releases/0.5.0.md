**Product variants and baselines.**

- **Variants.** Create variants of your product that build on the core and exclude or replace single core requirements.
- **A view per variant.** Choose a variant in the app, and traces, coverage and verification show what holds for it. The requirement page names the variants that replace or exclude it.
- **Compare.** See what a variant changes against the core, side by side.
- **Baselines.** Freeze a selection as a baseline, see its verification status and compare it with today. Hints tell you when a core requirement changed since a variant's latest baseline.
- **Find by value.** Ctrl+click (Cmd+click on macOS) a value to list all elements with the same value.

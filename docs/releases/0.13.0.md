**A web UI in your browser or in a window of its own replaces the Electron app, and each operating system gets one archive with everything in it.**

- **Web UI with `reqseq ui`.** The command line starts the web UI on this computer only and opens it in your browser, with a new token on every start. It has the overview, lists with facets, saved filters and perspectives, element pages, trace graph, impact, trace matrix, changes since a baseline, the check before a baseline, variants, and forms to create and edit elements of every type. Workspaces are opened, created, checked and exported there, and ReqIF files imported; for a file of another tool you choose the mapping on the page.
- **Desktop shell.** `ReqSeq.app` on macOS, `ReqSeq.exe` on Windows and `ReqSeq` on Linux show the web UI in a window of their own, with the folder and file dialogs of the operating system. Closing the window ends its server. On Linux it needs the web engine WebKitGTK, package `libwebkit2gtk-4.1-0`.
- **One archive per operating system, without Electron.** Each archive holds the desktop shell, the command line with the MCP server and the web UI, and the Node they run on. The command line stays where it was, so your path line keeps working: swap the old folder or `ReqSeq.app` for the new one. On Windows, run `reqseq workspace connect-agent` again for each agent, because the setup of an earlier version started the removed app.
- **Sort by verification status or version date.** Lists sort by the verification status of their elements and by the date of each element's version, also in large workspaces.
- **Clearer command line.** For the most common wrong calls, the message names the right option or form.

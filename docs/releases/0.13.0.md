**A web UI in your browser or in a window of its own replaces the Electron app, and each system gets one archive with everything in it.**

- **Web UI with `reqseq ui`.** The command line starts the web UI on this computer only and opens it in your browser, with a new token on every start. It has the overview, lists with facets, saved filters and perspectives, element pages, trace graph, impact, trace matrix, changes since a baseline, the check before a baseline, variants, and forms to create and edit elements of every type. Workspaces are opened, created, checked, exported and imported there too; for a ReqIF file of another tool you choose the mapping on the page.
- **Desktop shell.** `ReqSeq.app` on macOS, `ReqSeq.exe` on Windows and `ReqSeq` on Linux show the web UI in a window of their own, with the folder and file dialogs of your system. Closing the window ends its server.
- **One archive per system, without Electron.** Each archive holds the desktop shell, the command line with the MCP server and the web UI, and the Node they run on. The command line stays where it was, so your path line and agent setups keep working: swap the old folder or `ReqSeq.app` for the new one.
- **Sort by verification status or version date.** Lists sort by the verification status of their elements and by the date of each element's version, also in large workspaces.
- **Clearer command line.** For the most common wrong calls, the message names the right option or form.

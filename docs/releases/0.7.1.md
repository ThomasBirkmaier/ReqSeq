**Improvements from the first pilot.**

- **Test results.** Tests can name their requirement with a name pattern where square brackets do not fit, results can be recorded for a variant, and tests without a reference are counted.
- **Gaps.** A requirement without a parent shows as a gap and a hint.
- **Baselines.** A baseline shows the evidence of each view and names records made later.
- **Metamodel.** It shows which properties count toward a requirement's version.
- **Links.** ReqSeq warns about a `reqseq:` reference that is not inside a Markdown link.

**Fixes from daily use: no freezes on long blanks, clearer messages, and fewer silent traps.**

- **No freeze on long blanks.** A text with a long run of spaces or tabs inside a line no longer freezes the app or a command that reads it.
- **Relations.** Giving a relation kind more than once on the command line, such as `--add-relations derives-from=A --add-relations derives-from=B`, now keeps every target. Adding a relation that is already there but outdated now returns its outdated hint and says that confirming the hint stores the current version, instead of answering "No problems".
- **Clearer messages.** A comma inside a reference or hint ID gets a message that says to give each value on its own. An unexpected error now names its cause, without absolute paths.
- **Where repositories are.** `workspace status` shows the full folder of each available repository on this machine, so two copies of a workspace can be told apart.

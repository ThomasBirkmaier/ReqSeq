**Fixes from daily use: clearer messages, and no more silent traps on the command line.**

- **No freeze on long blanks.** A text with a long run of spaces or blank lines no longer freezes the app or a command.
- **Relations on the command line.** Giving a relation kind more than once, such as `--add-relations derives-from=A --add-relations derives-from=B`, now keeps every target. Adding a relation that already exists but is outdated says so and names `hint confirm` to refresh it, instead of answering "No problems".
- **Clearer messages.** A comma inside a reference or hint ID gets a message that says to give each value on its own. An unexpected error now names its cause, without your local paths.
- **Where repositories are.** `workspace status` shows the full path of each linked repository.

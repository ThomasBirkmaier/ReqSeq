# SR-074: Oberfläche auf Englisch anzeigen

Verification method: Inspection. Record written by an agent (Claude Code) on 2026-11-05 for issue #81, branch `sr-074-english-ui`. Not confirmed yet: a human confirms it at stage acceptance (D-050).

> Gegeben App, Kommandozeile, API, MCP-Server und Dokumentation, wenn sie geprüft werden, dann sind alle Texte, Meldungen und Hilfen auf Englisch.

> Gegeben Elemente mit deutschem Inhalt, wenn sie angezeigt werden, dann zeigt das Tool den Inhalt unverändert.

## AK1: every text, message and help is in English

### How

1. Searched for German letters (ä, ö, ü, ß), for German glossary terms of the spec (Beleg, Prüfling, Durchführung, Begründung, Nachweis…, Fassung, Datensatz, Validierung, Gültigkeit, Anforderung, Abdeckung, Stand, Hinweis, Stellungnahme, Pflichtfeld, Wertart, Beziehungsart) and for common German words (nicht, und, oder), and for German nouns in parentheses beside an English word, in:
   - the command schemas and the file format schemas (`schemas/`), whose descriptions become the CLI help, the MCP tool descriptions, the API reference (`schemas/generated/`, `packages/core/src/generated/contracts.json`) and the format pages of the documentation;
   - the causes and remedies of the problem codes (`schemas/problem-codes.yaml`);
   - the string literals of all packages (`packages/*/src`: CLI messages and help, API and MCP errors, the app's renderer and main menus), leaving out tests and comments;
   - the user guide (`docs/guide`), `README.md` and the package READMEs.
2. A second agent searched the same places independently, including German words without umlauts, and found six more descriptions, which are fixed too.

### Result

- **Found and fixed in this branch:** 34 descriptions and titles in 12 schema files named a German term beside the English word or used it alone, for example "The item under test (Prüfling)", "Where the Beleg is", "the Nachweisgrad of a selection", "`inconclusive` (nicht beurteilbar)", "Data of a state (Stand)", "Value kind (Wertart)". They now read in English only. They were visible in the CLI help, the MCP tool descriptions, the API reference and the format pages.
- **Kept automated:** `scripts/contracts/user-text.test.mjs` ("texts for users in English") fails when a description, summary, title or read-only reason of the generated contracts or of a file format schema, or a cause or remedy of a problem code, holds a German letter or one of those words. User content under `examples` and `default` may be German and is skipped.
- **Nothing else found:** in the sources outside comments, the German text is limited to comments that quote the German spec (`„…“`), which no user sees. The user guide has no German. The app's labels, menus and messages are English string literals in `packages/app/src/renderer` and `packages/app/src/main`. The window title is "ReqSeq".
- **Not covered by the search:** a German word without an umlaut outside the lists. A person reading the app, the CLI help (`reqseq <group> <command> --help`) and the guide judges that at stage acceptance.

Record written by an agent (Claude Code) on 2026-11-23 for issue #2448, against `main` at `5c9e42ad`, for SR-074 in version `n2:111aed44b24dfa0e`, whose AK1 names the web UI. Earlier records: the confirmed records of 2026-11-06 (`spec/evidence/manual/2026-11-06-SR-7b8a0e-*inspection.md`, version `n2:d12c8ede5f9fd4d5`) point to this file as of `e3e293c`; the unconfirmed web UI record of #2397 in that text is replaced by this one.

> Das Tool muss alle Texte seiner Oberfläche, Meldungen und Dokumentation nur auf Englisch anbieten.

## AK1: every text, message and help is in English

> Gegeben Kommandozeile, API, MCP-Server, Web-Oberfläche und Dokumentation, wenn sie geprüft werden, dann sind alle Texte, Meldungen und Hilfen auf Englisch.

### How

The search pattern is `GERMAN` of `scripts/contracts/user-text.test.mjs` (German letters ä, ö, ü, ß, the German glossary terms and the words nicht, und, oder), extended by German articles, prepositions and verbs (der, die, das, mit, für, ein, eine, ist, wird, wenn, dann) and German UI words (Datei, Ordner, Fehler, Speichern, Abbrechen, Schließen, Öffnen, Suche, Zurück, Weiter).

1. **Sources.** A script searched the string literals of 805 files, outside comments and tests: `packages/*/src` (core, CLI, API, MCP, web UI, docs generator), `packages/web/index.html` and `public/`, the package READMEs, the hand-written pages of the documentation site, `docs/guide/` and `README.md`; the string literals of the desktop shell (`packages/shell/shell/src`, `launcher/src`, `tauri.conf.json`) were searched with `grep`.
2. **Generated texts.** `pnpm vitest run scripts/contracts/user-text.test.mjs`: 10 passed. It fails when a description, summary, title or read-only reason of the generated contracts or of a file format schema, or a cause or remedy of a problem code, holds German.
3. **CLI.** The help of `reqseq`, of every group and of every command of `schemas/commands/` (83), and of `mcp`, `ui`, `serve api` and `serve docs`: 5,336 lines.
4. **MCP server.** `reqseq mcp --workspace spec` over standard input: `initialize`, `tools/list` (81 tools, 2,871 strings outside `examples` and `default`), and an error answer of `element_get` for an unknown reference.
5. **API.** `reqseq serve api --workspace spec`: `GET /v1/commands` (16,362 strings outside `examples` and `default`), the answer without token, and an error answer of `element.get`.
6. **Web UI.** The built bundle in `packages/web/dist` searched for German letters; `reqseq ui --workspace spec` opened in headless Chrome (Playwright), the overview and the element page `#/e/SR-074` read as text.
7. **Documentation.** The user guide and README in step 1; the generated reference through the schemas and contracts of step 2.

### Result

- **CLI, API, MCP:** no German. The only match in the CLI help is the list of quote characters a search accepts (`"`, `„`, `“` or `”`). Messages read for example "No element has the identifier "NOPE-999"" and "Missing or wrong token; see api.json in the cache folder".
- **Web UI:** no German in its own texts. The source matches are the CSS class `der` (derivation edges) and the word "derivation"; the bundle's German letters are in the character tables of the KaTeX library, which no user reads as text. `index.html` has `lang="en"` and the title "ReqSeq". The overview shows "Inbox", "Evidence outdated", "Drafts to decide", "Lists", "Trace matrix", "New element"; German appears only where it is element content (package titles of the spec, AK2).
- **Desktop shell:** no German outside its tests (`tail.rs` tests a cut UTF-8 sequence with "Fehler: ü"). Its product name is "ReqSeq".
- **Documentation:** no German in the guide, the README and the package READMEs. The test kit's README (`packages/testkit/src/status-model/README.md`) quotes German; it is test code and is not delivered.
- **Not covered by the search:** a German word outside the lists. A person reading the pages of `reqseq ui` and the CLI help judges that at acceptance.

# Performance with 50,000 elements and 200,000 relations (N-036)

Verification method: Analyse. Record written by the performance job (`scripts/perf/report.mjs`, ADR-0011, ThomasBirkmaier/ReqSeq-archive#126). **Not confirmed.** A human confirms it at stage acceptance.

Workspace: generated by `generateLargeWorkspace` of `packages/testkit` (D-055) with seed 36: 50,000 elements of the standard model (needs, use cases, decisions, variants, packages, system requirements) in four repositories, 200,000 relation targets with valid versions. Tests: `packages/*/test/perf/` (`pnpm test:perf`).

The reference machine of the performance SRs has 4 cores, 16 GB and an SSD; compare the machine below. Tests tagged `[SR-xxx/AK-<key>]` fail when they exceed their threshold, untagged measurements only record, and a time over its threshold opens an issue labelled `perf` (ADR-0011). "Cold" means without the ReqSeq cache; the files were just written, so the operating system has them in its page cache.
